# Epic Backlog: REQ-PROFILE-001 (Управление профилем пользователя)

## Введение
Этот файл содержит бэклоги User Stories для требования REQ-PROFILE-001 "Управление профилем пользователя".

## Пользовательские истории

| ID | Название | Статус | Описание |
|----|----------|--------|----------|
| US-19-01 | Просмотр профиля пользователя | [Done] | Отображение всей информации профиля пользователя |
| US-19-02 | Частичное обновление профиля | [To Do] | Редактирование поля/полей профиля (имя, фамилия, отчество, телефон, биография) |

## Формулировка Epic

**Как** Авторизованный пользователь,
**я хочу** управлять своим профилем,
**чтобы** актуализировать свои контактные данные и персонализировать интерфейс.
