**Роль **
Ты промпт инженер и опытный fullstack разработчик

**Контекст**
Подготовка проекта к разработке с ИИ агентом

**Задача**
Сформулировать правила для roo vs code реализации спецификаций us в @/.roo/rules/REALIZATION.md

**Общий подход**
реализация разбивается на следующие этапы
1. Обновление физической модели данных
2. Миграция данных
3. Обновление слоя repository компонентов
4. Обновление service слоя
5. Обновление ui компонентов

**Порядок выполнения**
1. Изучи @/docs/templates/requirement-template.md 
2. Сформулируй черновик
3. Обсуди черновик
4. Обнови REQ-DECOMPOSITION
5. Проверь

**Условия начала этапа**
Выполняется после этапов
- формулировка требований
- обновление концептуальной модели данных
- разработки user story
- разработки специфкации и беклога




**Входит**
- Анализ требований
- Формирование списка user story, которые нужны для реализации требований
- Проверка наличия готовых user story
- Для каждой user story создание и обновление спецификации по шаблону [user-story-template.md](/docs/templates/user-story-template.md). 
- В рамках этого этапа обновляются следующие разделы
  - Название и формулировки
  - Целевое состояние
  - Модель данных
  - Поведение
  - Критерии приемки
  - Бизнес-правила и валидация
  - Граничные случаи
  - Нефункциональные требования
  - Открытые вопросы
- Валидация результата
**Не входит**
- Влияние на слои архитектуры (выполянется на следующих этапах)



**Ограничения**
- Пиши на грамотном русском языке
- Следуй лучшим практим создания правил для ИИ агента
- ЗАПРЕЩЕНО изменять код и другие документы кроме REQ-DECOMPOSITION.md
