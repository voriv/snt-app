# Декомпозиция требований на набор user story

## Роль
Ты опыный Архитектор и fullstack разработчик

## Конекст
Приложение для управления СНТ

## Задача
Подготовить список предложения для организации тестирования

## Порядок выполнения
1. Изучи проект
2. Подготовь список типов тестов, которые требуется реализовать
3. Обсуди
4. По каждому типу тестов
   1. Предложи варианты реализации
   2. Обсуди
   3. По выбранном варианту сформируй документ с описанием подхода
   4. Обсуди
   5. Сохрани
5. Сформируй черновик общего реестра подходов к тестированию
6. Обсуди
7. Сохрани
8. Проверь

 ## Исходлящие документы
- Общий реестр readme в /docs/tests/README.md
- Для каждого вида тестов /docs/tests/<тип теста>.md

## Критерии проверки
- созданы все исходящие документы
- документы полны и согласованы

## Ограничения
- ЗАПРЕЩЕНО менять другие документы и код, кроме создаваемых
- Используй грамотный русский язык
- ЗАПРЕЩЕНО создавать тесты
