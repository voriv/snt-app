# Декомпозиция требований на набор user story

## Роль
Ты опыный Архитектор и fullstack разработчик

## Конекст
Приложение для управления СНТ

## Задача
Подготовить шаблон плана реализации user story

## Порядок выполнения
1. Изучи проект
2. Подготовь черновик шаблона плана реализации user story
3. Обсуди
4. Создай шаблон
5. Подготовь изменение .roo/rules/SPEC.md с учетом шаблона
6. Обнови SPEC.md
7. Проверь

 ## Исходлящие документы
- шаблон плана реалиазции в /docs/templates/us-realization-plan.md
- правила разработки спецификации в  /.roo/rules/SPEC.md

## Критерии проверки
- созданы все исходящие документы
- документы полны и согласованы
- шаблон содержит набор задач, которые надло выполнить для реализации спецификации us
- в шаблоне предусмотрена возможность отслеживать состояние реализации плана ([TODO/IN progress/DONE])
- Шаблон можно давать ИИ агенту для разработки

## Ограничения
- ЗАПРЕЩЕНО менять другие документы и код, кроме шаблона плана и .roo/rules/SPEC.md
- Используй грамотный русский язык
