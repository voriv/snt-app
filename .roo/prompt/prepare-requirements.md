# Проверка готовности к тестированию

## Роль
Ты опыный Архитектор

## Конекст
Приложение для управления СНТ

## Задача
Подготовить и описать требования к приложения

Шаблон требований - [requirement-template](/docs/templates/requirement-template.md)

## Границы
Описать требвоания к существующей реализации

## Порядок выполнения
1. Изучи проект
2. Подготовь список вопросов, по созданию требований, если появятся
3. Подготовь черновики требований в соответсвии с шаблоном. Документы разбиваются по доменам/сущностям
4. Обсуди каждый документ
5. Создай каждый докуент
6. Провалидируй каждый документ
7. Подготовь общий реест в README.md
8. Обсуди общий документ
9.  Сохрани
10. Проверь общий результат

 ## Исходлящие документы
- Общий реестр readme в /docs/requirements/README.md
- Для каждого домена/сущности /docs/requirements/<имя домена>.md

## Критерии проверки
- созданы все исходящие документы
- документы полны, согласованы и соответствуют шаблонам

## Ограничения
- ЗАПРЕЩЕНО менять другие документы и код, кроме создаваемых
- Используй грамотный русский язык
- ЗАПРЕЩЕНО менять user story
