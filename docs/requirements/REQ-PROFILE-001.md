# REQ-PROFILE-001: Управление профилем пользователя

## 1. Бизнес-контекст и Цель

*Пользователи СНТ должны иметь возможность управлять своей личной информацией: просматривать и редактировать контактные данные, загружать аватар, настраивать тему оформления приложения.*

* **Бизнес-цель:** Обеспечить пользователей инструментами для актуализации персональных данных и персонализации интерфейса.
* **Стейкхолдеры / Пользователи:** Все авторизованные пользователи (член СНТ, администратор), администраторы приложения.

## 2. Бизнес-правила и Логика (Business Rules)

* **BR-01:** Профиль доступен только авторизованным пользователям
* **BR-02:** Все поля профиля опциональны при частичном обновлении
* **BR-03:** Имя и фамилия могут быть пустыми, но если указаны — должны содержать от 2 до 50 символов
* **BR-04:** Пустое значение для имени/фамилии трактуется как отсутствие значения
* **BR-05:** Email берётся из учётной записи пользователя и не редактируется через профиль
* **BR-06:** Аватар: максимальный размер файла 5 МБ, поддерживаемые форматы JPG, PNG, GIF
* **BR-07:** Тема оформления может быть одной из: светлая, тёмная, зелёная
* **BR-08:** Профиль автоматически создаётся при первом обращении, если не существует
* **BR-09:** В навигационной панели отображается имя пользователя (или email, если имя пустое) как ссылка на профиль

## 3. Функциональные требования

* **FR-01:** Система должна отображать профиль пользователя: имя, фамилия, отчество, email, телефон, аватар, биография, дата регистрации
* **FR-02:** Система должна поддерживать частичное обновление профиля — можно обновлять только указанные поля
* **FR-03:** Система должна поддерживать загрузку аватара
* **FR-04:** Система должна поддерживать удаление аватара (сброс к значению по умолчанию)
* **FR-05:** Система должна поддерживать смену темы оформления (светлая/тёмная/зелёная)
* **FR-06:** Система должна автоматически создавать профиль при первом обращении, если он не существует
* **FR-07:** Система должна отображать ссылку на профиль в навигационной панели авторизованного пользователя
* **FR-08:** Система должна валидировать данные перед сохранением

## 5. Нефункциональные требования (NFR) и Ограничения

* **Безопасность:**
  * Все операции с профилем требуют авторизации
  * Защита от XSS-атак при отображении пользовательского контента (биография)
  * Валидация всех входных данных на сервере
  * Ограничение размера загружаемых файлов (5 МБ)
* **Производительность:**
  * Загрузка профиля: < 300ms
  * Обновление профиля: < 500ms
  * Кэширование профиля: 5 минут
* **UX:**
  * Состояние загрузки: индикатор при сохранении данных
  * Валидация в реальном времени: подсветка ошибок при вводе
  * Адаптивная вёрстка: мобильные устройства и десктоп
* **Доступность:**
  * Поддержка скринридеров
  * Навигация с клавиатуры
  * Контрастность цветов в соответствии с WCAG 2.1

## 6. Исключения и Граничные кейсы (Edge Cases)

* **EC-01:** Пользователь не имеет связанной записи профиля — создаётся автоматически при первом редактировании
* **EC-02:** Попытка изменения email в профиле — не разрешено, email изменяется через отдельную процедуру
* **EC-03:** Загрузка некорректного изображения — показывается ошибка, текущий аватар без изменений
* **EC-04:** Ошибка при загрузке изображения на сервер — показывается уведомление об ошибке
* **EC-05:** Параллельное редактирование профиля с нескольких устройств — побеждает последнее сохранение
* **EC-06:** Пользователь деактивирован — профиль доступен только для просмотра

## 7. Критерии приёмки

1. Авторизованный пользователь может просмотреть свой профиль на странице профиля
2. Неавторизованный пользователь перенаправляется на страницу входа при попытке доступа к профилю
3. Пользователь может обновить имя, фамилию, отчество, телефон, биографию через частичное обновление
4. Пустое значение для имени/фамилии трансформируется в отсутствие значения
5. Аватар: при попытке загрузки файла более 5 МБ показывается ошибка
6. Аватар: при попытке загрузки файла неподдерживаемого формата показывается ошибка
7. Тема оформления может быть изменена через настройки профиля
8. В навигационной панели отображается имя пользователя как ссылка на страницу профиля
