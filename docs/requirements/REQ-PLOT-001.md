# REQ-PLOT-001: Управление участками

## 1. Бизнес-контекст и Цель

*Система управления СНТ требует функциональности для учёта земельных участков: создания, просмотра, редактирования, удаления и поиска участков.*

* **Бизнес-цель:** Обеспечить администраторов и членов СНТ инструментами для ведения реестра земельных участков с возможностью быстрого поиска и актуализации данных.
* **Стейкхолдеры / Пользователи:** Администраторы СНТ, члены СНТ, все авторизованные пользователи.

## 2. Бизнес-правила и Логика (Business Rules)

* **BR-01:** Номер участка не может быть изменён после создания — неизменяемое поле
* **BR-02:** Кадастровый номер должен быть уникальным, если указан — проверка при создании и обновлении
* **BR-03:** Номер участка должен содержать от 2 до 50 символов
* **BR-04:** Удаление участка необратимо — запись удаляется из системы
* **BR-05:** Поиск участков поддерживает частичное совпадение без учёта регистра по номеру, кадастровому номеру, адресу и примечанию
* **BR-06:** Список участков сортируется по номеру участка (по возрастанию) по умолчанию

## 3. Функциональные требования

* **FR-01:** Система должна отображать список всех участков в таблице с колонками: номер, кадастровый номер, площадь, адрес
* **FR-02:** Система должна поддерживать создание нового участка с валидацией уникальности номера и кадастрового номера
* **FR-03:** Система должна поддерживать редактирование участка: площадь, адрес, примечание, кадастровый номер (но НЕ номер участка)
* **FR-04:** Система должна поддерживать удаление участка
* **FR-05:** Система должна поддерживать поиск участков по фильтрам: номер, кадастровый номер, примечание
* **FR-06:** Система должна отображать сообщение при отсутствии участков
* **FR-07:** Система должна отображать индикатор загрузки при загрузке данных
* **FR-08:** Система должна отображать состояние ошибки с кнопкой "Повторить попытку"
* **FR-09:** Система должна отображать детальную информацию об участке на странице деталей участка
* **FR-10:** Система должна поддерживать пагинацию (на начальном этапе: полный список без пагинации, до 1000 записей)

## 5. Нефункциональные требования (NFR) и Ограничения

* **Безопасность:**
  * Все операции требуют авторизации
  * Ролевой доступ: создание/редактирование/удаление только для пользователей с соответствующими правами
  * Валидация всех входных данных на сервере
* **Производительность:**
  * Загрузка списка: < 500ms при до 1000 записей
  * Создание/обновление/удаление: < 300ms
  * Поиск: < 200ms
* **Доступность:**
  * Семантическая разметка таблиц
  * ARIA-метки для интерактивных элементов
* **Локализация:** Все сообщения на русском языке
* **Адаптивность:** Таблица горизонтально прокручивается на мобильных устройствах

## 6. Исключения и Граничные кейсы (Edge Cases)

* **EC-01:** Участок с пустыми полями (адрес, кадастровый номер) — отображается прочерк
* **EC-02:** Дубликат номера участка при создании — система сообщает "Участок с номером X уже существует"
* **EC-03:** Дубликат кадастрового номера при создании — система сообщает "Участок с кадастровым номером X уже существует"
* **EC-04:** Попытка редактирования номера участка — поле игнорируется (согласно BR-01)
* **EC-05:** Ошибка сети при загрузке — показывается сообщение "Ошибка загрузки. Повторить попытку."
* **EC-06:** Медленная сеть (более 3 секунд) — показывается индикатор загрузки, данные загружаются асинхронно
* **EC-07:** 0 участков в системе — показывается сообщение с предложением добавить участок

## 7. Критерии приёмки

1. Авторизованный пользователь может просмотреть список всех участков на странице списка участков
2. Таблица отображает все участки, отсортированные по номеру (по возрастанию)
3. Пустой список отображается с сообщцем о предложением добавить участок
4. Пользователь может создать участок с уникальными номером и кадастровым номером
5. При дубликате номера — система возвращает понятное сообщение
6. Пользователь может обновить площадь, адрес, примечание, кадастровый номер участка
7. Номер участка не может быть изменён
8. Пользователь может удалить участок (необратимо)
9. Поиск возвращает участки по частичному совпадению (без учёта регистра)
10. Участок показан на странице деталей участка
