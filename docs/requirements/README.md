## Нумерация требований

Формат идентификатора: `FR-XX-NNN`

| Элемент | Описание | Пример |
|---------|----------|--------|
| `FR` | Тип требования (Functional Requirement) | FR-01-001 |
| `XX` | Двузначный код домена (из реестра выше) | 01, 02, ... |
| `NNN` | Трёхзначный номер требования в домене | 001, 002, ... |

Для нефункциональных требований используется формат: `NFR-XX-NNN`

## Статусы требований

| Статус | Описание | Переходы |
|--------|----------|----------|
| **Черновик** | Инициальное описание, можно редактировать | → На обсуждении |
| **На обсуждении** | Требует проверки и согласования | → Черновик, Согласовано |
| **Согласовано** | Утверждено, готово к разработке | → В реализации |
| **В реализации** | Разрабатывается | → Завершено, На обсуждении |
| **Завершено** | Реализовано и проверено | → На обсуждении |
