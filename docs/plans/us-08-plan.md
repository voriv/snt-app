## 🎯 Целевое состояние

После завершения US-08 система должна поддерживать полный процесс выхода (logout) с:
- Кнопкой "Выйти" в навигационной панели для авторизованных пользователей
- API endpoint `/api/v1/auth/logout` для удаления сессии
- Перенаправлением на страницу входа после выхода
- Корректной обработкой состояний (loading, error)
