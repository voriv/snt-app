## 🎯 Целевое состояние

После завершения US-07 система должна поддерживать полную регистрацию новых пользователей через API `/api/v1/auth/register` с:
- Валидацией всех полей на сервере
- Автоматическим назначением роли GUEST
- Корректной обработкой ошибок (дубликаты, невалидные данные)
- Хешированием паролей через bcrypt
- Стандартизированным форматом ответа API
