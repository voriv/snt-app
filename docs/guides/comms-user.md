# Руководство пользователя: Вкладка «Общение»

## Обзор

Вкладка **«Общение»** — это единая точка входа для всех коммуникационных функций приложения СНТ «Берёзки-НТ». Здесь вы можете обмениваться личными сообщениями, участвовать в групповых чатах, читать официальные объявления и (для администраторов) модерировать содержимое.

---

## 1. Доступ к вкладке «Общение»

1. Войдите в приложение.
2. В навигационном меню выберите **«Общение»**.
3. При первом открытии вы будете автоматически перенаправлены на подраздел **«Личные сообщения»**.

### Вкладки внутри раздела

| Вкладка | Описание | Доступ |
|---------|----------|--------|
| **Личные сообщения** | Персональные диалоги с другими пользователями | Все авторизованные |
| **Групповые чаты** | Тематические и чаты по участкам | Все авторизованные |
| **Объявления** | Официальные объявления от правления | Все авторизованные |
| **Модерация** | Управление жалобами, блокировками, предупреждениями | ADMIN, SUPER_ADMIN |

---

## 2. Личные сообщения

### Начало диалога

1. Перейдите на вкладку **«Личные сообщения»**.
2. Нажмите кнопку **«Новый диалог»** или значок **«+»**.
3. Введите имя или email собеседника в поле поиска.
4. Выберите пользователя из списка результатов.

> **B-029 (US-21-38, US-21-39):** Если личный диалог с этим собеседником у вас **уже есть**, система не создаёт второй — вместо одной кнопки отображаются две в зависимости от ситуации:
>
> - **«Открыть диалог»** (стиль secondary) — показывается, если диалог с этим пользователем **уже существует** (список диалогов предзагружается при открытии страницы). Нажатие сразу открывает существующий диалог без обращения к API.
> - **«Написать»** (стиль primary) — показывается, если диалога ещё нет. Нажатие отправляет запрос на создание нового диалога (HTTP 201) и открывает его.
>
> Система гарантирует **один личный диалог на пару** — даже если два окна отправили запрос одновременно, будет создан только один диалог (второй запрос просто откроет уже существующий).

5. После выбора диалог откроется — вы можете сразу отправить сообщение. Если диалог уже существовал, вы будете перенаправлены в него (ошибка при этом не показывается).

### Отправка сообщения

1. Откройте нужный диалог из списка.
2. Введите текст в поле ввода внизу экрана.
3. Нажмите **«Отправить»** или клавишу **Enter**.

### Поиск по диалогам

В поле поиска вверху списка введите имя собеседника — список отфильтруется по совпадениям.

### Непрочитанные сообщения

- Количество непрочитанных сообщений отображается в виде бейджа на вкладке **«Личные сообщения»**.
- Общий счётчик непрочитанных виден рядом с пунктом **«Общение»** в навигационном меню.
- Бейдж исчезает автоматически после прочтения всех сообщений.

## 3. Групповые чаты

### Просмотр списка чатов

1. Переключитесь на вкладку **«Групповые чаты»**.
2. Список отобразит все чаты, в которых вы участвуете.
3. Каждый чат показывает название, последнее сообщение и счётчик непрочитанных.

### Создание чата

1. Нажмите кнопку **«Создать чат»**.
2. Введите название чата (3–100 символов).
3. Добавьте описание (необязательно).
4. Выберите участников из списка пользователей.
5. Нажмите **«Создать»**.

### Поиск по чатам

Введите ключевые слова в поле поиска — список отфильтруется по названию чата.

### Участие в чате

- **Отправка сообщения:** Введите текст и нажмите **«Отправить»**.
- **Упоминание пользователя:** Начните ввод с `@` и выберите пользователя из выпадающего списка.
- **Покинуть чат:** Откройте настройки чата и выберите **«Покинуть чат»**.

---

## 4. Объявления

### Просмотр объявлений

1. Переключитесь на вкладку **«Объявления»**.
2. Список отобразит все опубликованные объявления в хронологическом порядке.
3. Объявления категории **«Важное»** визуально выделены.

### Создание объявления (ADMIN/SUPER_ADMIN)

1. Нажмите кнопку **«Создать объявление»**.
2. Введите заголовок и содержание.
3. Выберите категорию: важное, плановое, техническое, информационное.
4. Включите опцию **«Обсуждение»**, если нужно позволить комментариям (автоматически создаётся чат).
5. Сохраните как черновик или опубликуйте.

### Категории объявлений

| Категория | Описание |
|-----------|----------|
| **Важное** | Критически важная информация, визуально выделена |
| **Плановое** | Планы работ, мероприятия |
| **Техническое** | Технические уведомления, ремонтные работы |
| **Информационное** | Общие сообщения |

## 5. Модерация (ADMIN/SUPER_ADMIN)

### Панель модерации

Доступна на вкладке **«Модерация»** и включает:

- **Жалобы** — список жалоб от пользователей на сообщения
- **Заблокированные пользователи** — список заблокированных с возможностью разблокировки
- **Предупреждения** — история выданных предупреждений

### Рассмотрение жалобы

1. Откройте вкладку **«Модерация» → «Жалобы»**.
2. Выберите жалобу для просмотра деталей.
3. Примите решение:
   - **Удалить сообщение** — сообщение будет удалено без возможности восстановления
   - **Заблокировать пользователя** — пользователь не сможет отправлять сообщения
   - **Выдать предупреждение** — пользователь получит уведомление о нарушении
4. Статус жалобы изменится на **«Рассмотрена»**.

### Блокировка пользователя

1. В панели модерации выберите **«Заблокировать пользователя»**.
2. Укажите причину блокировки.
3. Пользователь будет автоматически удалён из всех чатов и не сможет отправлять сообщения.

### Предупреждения

1. Выберите пользователя в панели модерации.
2. Нажмите **«Выдать предупреждение»**.
3. Укажите причину.
4. Пользователь получит уведомление.

## 6. Навигация и горячие клавиши

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| **Enter** | Отправить сообщение |
| **Tab** | Переход между элементами управления |

### Адаптивность

Интерфейс автоматически адаптируется под размер экрана:
- **Десктоп** — полная панель навигации и список чатов слева
- **Планшет** — сворачиваемая панель
- **Мобильный** — упрощённый интерфейс с жестами

## 7. Часто задаваемые вопросы

### Почему я не вижу вкладку «Модерация»?

Вкладка «Модерация» доступна только пользователям с ролью **ADMIN** или **SUPER_ADMIN**. Если вам нужен доступ, обратитесь к администратору СНТ.

### Почему я не могу создать второй личный диалог с одним и тем же человеком?

В системе установлено правило: между двумя пользователями существует **только один личный диалог**. Это сделано, чтобы переписка с каждым собеседником хранилась в одном месте и не дублировалась.

Если вы попытаетесь написать пользователю, с которым у вас уже есть диалог, система не создаст новый — кнопка будет называться **«Открыть диалог»**, и нажатие просто откроет вашу существующую переписку. Даже если вы зайдёте в раздел создания диалога повторно или откроете две вкладки одновременно, новый дубликат не появится.

### Почему при выборе пользователя меня сразу перенаправило в диалог?

Это нормальное поведение. Если диалог с выбранным собеседником уже существует, система сразу открывает его, не показывая ошибок и не создавая дубликата.

### Что значит счётчик на вкладке?

Счётчик показывает количество непрочитанных сообщений в соответствующем разделе. После открытия раздела и просмотра сообщений счётчик обнулится.

### Что произойдёт, если пользователь удалит аккаунт?

Сообщения удалённого пользователя сохранятся, но вместо имени будет отображаться **«Удалённый пользователь»**.
