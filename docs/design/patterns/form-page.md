# Паттерн: Страница с формой

> **Назначение:** Шаблон для страниц создания и редактирования сущностей.
> **Статус:** `[ACTIVE]`

---

## Компоненты

| Элемент | Компонент | Токен |
|---------|-----------|-------|
| Фон | — | `color.bg.secondary` |
| Навигация | `<Navbar>` | `color.nav.bg` |
| Кнопка "Отмена" | `<Button variant="secondary">` | `color.text.primary` |
| Кнопка "Сохранить" | `<Button variant="primary" isLoading={...}>` | `color.accent.default` |
| Карточка формы | `<Card>` | `color.bg.primary` |
| Заголовок | `<h1>` | `text.heading-1` |
| Поле ввода | `<Input>` | `color.input.*` |
| Выпадающий список | `<Select>` | `color.input.*` |
| Чекбокс | `<Checkbox>` | `color.accent.default` |
| Ошибка поля | `<p>` | `color.danger` |
| Общая ошибка | `<ErrorMessage>` | `color.danger` |

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Default | Форма готова к заполнению |
| Validation Error | `<ErrorMessage>` + красные границы полей + сообщения под полями |
| Submitting | Кнопка "Сохранить" заблокирована, спиннер |
| Success | Переход на страницу деталей |
| Error | `<ErrorMessage>` + данные формы сохранены |

## Валидация

| Поле | Правило | Сообщение об ошибке |
|------|---------|---------------------|
| Обязательное поле | Не пусто | "Поле обязательно для заполнения" |
| Email | Формат email | "Неверный формат email" |
| Уникальность | Проверка по API | "Такое значение уже существует" |
