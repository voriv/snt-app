# Паттерн: Страница деталей

> **Назначение:** Шаблон для страниц просмотра и редактирования одной сущности.
> **Статус:** `[ACTIVE]`

---

## Компоненты

| Элемент | Компонент | Токен |
|---------|-----------|-------|
| Фон | — | `color.bg.secondary` |
| Навигация | `<Navbar>` | `color.nav.bg` |
| Кнопка "Назад" | `<Button variant="ghost">` | `color.text.primary` |
| Кнопка "Редактировать" | `<Button variant="primary">` | `color.accent.default` |
| Карточка деталей | `<Card>` | `color.bg.primary` |
| Заголовок | `<h1>` | `text.heading-1` |
| Подзаголовок | `<p>` | `text.body-sm` + `color.text.secondary` |
| Бейджи статуса | `<Badge>` | `color.success` / `color.warning` |
| Секция "Участники" | `<Card>` | `color.bg.primary` |
| Секция "Документы" | `<Card>` | `color.bg.primary` |

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон: 1 большой блок + 2 средних блока |
| Error | `<ErrorMessage>` + кнопка "Повторить" + кнопка "Назад" |
| Not Found | `<EmptyState title="Не найдено" description="Элемент удалён или не существует" />` |
| Data | Макет выше |

## Адаптивность

| Breakpoint | Поведение |
|------------|-----------|
| Desktop (≥1024px) | Две колонки (основные данные + детали) |
| Tablet (≥768px) | Одна колонка, все секции |
| Mobile (<768px) | Одна колонка, компактные карточки |
