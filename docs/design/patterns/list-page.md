# Паттерн: Страница со списком

> **Назначение:** Шаблон для страниц с таблицей/списком данных, поиском и пагинацией.
> **Статус:** `[ACTIVE]`

---

## Структура

```ascii
┌─────────────────────────────────────────────────────────┐
│ [Лого]  [Навигация]                    [Белл] [Аватар ▼]│
├─────────────────────────────────────────────────────────┤
│                                                         │
│  +---+  +---+  +---+    [Поиск 🔍]  [+ Создать]        │
│  | TB1|  | TB2|  | TB3|                                    │
│  +---+  +---+  +---+                                    │
│                                                         │
│  ┌───────────────────────────────────────────────────┐  │
│  │ Фильтр: ▽  Сортировка: ▽        Найдено: 123     │  │
│  ├───────────────────────────────────────────────────┤  │
│  │ +──────────+ +──────────+ +──────────+            │  │
│  │ | Строка 1 | | Строка 2 | | Строка 3 |            │  │
│  │ +──────────+ +──────────+ +──────────+            │  │
│  │ +──────────+ +──────────+ +──────────+            │  │
│  │ | Строка 4 | | Строка 5 | | Строка 6 |            │  │
│  │ +──────────+ +──────────+ +──────────+            │  │
│  ├───────────────────────────────────────────────────┤  │
│  │              < 1 2 3 ... 10 >                     │  │
│  └───────────────────────────────────────────────────┘  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Компоненты

| Элемент | Компонент | Токен |
|---------|-----------|-------|
| Фон | — | `color.bg.secondary` |
| Навигация | `<Navbar>` | `color.nav.bg` |
| Вкладки | `<tabs>` | `color.accent.default` (active) |
| Поиск | `<Input>` | `color.input.*` |
| Кнопка создания | `<Button>` | `color.accent.default` |
| Фильтр/Сортировка | `<Select>` | `color.input.*` |
| Список | `<FeatureList>` | — |
| Пагинация | `<pagination>` | `color.accent.default` (active page) |

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон таблицы (5 строк, pulsing) |
| Error | `<ErrorMessage>` + кнопка "Повторить" |
| Empty | `<EmptyState title="Нет данных" description="Создайте первый элемент" />` |
| Data | Макет выше |

## Адаптивность

| Breakpoint | Поведение |
|------------|-----------|
| Desktop (≥1024px) | Полная таблица, сайдбар виден |
| Tablet (≥768px) | Упрощённая таблица, сайдбар скрыт |
| Mobile (<768px) | Карточки вместо таблицы, кнопки на всю ширину |
