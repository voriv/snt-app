# 🎨 Дизайн-система SNT App

> **Назначение:** Централизованное управление визуальным оформлением приложения.
> **Статус:** `[ACTIVE]`
> **Версия:** `v1.0`
> **Дата:** `2026-07-23`

---

## 📖 Введение

Дизайн-система SNT App определяет **один источник правды** для всех визуальных элементов приложения:

- **Токены** — базовые значения (цвета, шрифты, отступы, тени, радиусы)
- **Компоненты** — документация UI-компонентов с props, variants, states
- **Шаблоны** — паттерны страниц (list, detail, form)

### Как использовать

1. **UI Designer:** Смотри токены → создавай макеты → используй компоненты
2. **Разработчик:** Смотри токены → реализуй через CSS-переменные
3. **QA:** Сравнивай реализацию с токенами и компонентными spec

## 🎯 Принципы

| Принцип | Описание |
|---------|----------|
| **Один источник правды** | Токены = единственный источник значений |
| **Тема-агностичность** | Токены маппятся на CSS-переменные, а не на конкретные цвета |
| **Базовый слой** | Сейчас 1 слой токенов. Семантический добавится позже (>15 компонентов) |
| **Консистентность** | Один и тот же токен = один и тот же визуальный результат |

## 🔄 Поддержка тем

Дизайн-система поддерживает 3 темы оформления:

| Тема | Описание | Акцент |
|------|----------|--------|
| **Light** | Светлая (по умолчанию) | Синий `#3b82f6` |
| **Dark** | Тёмная | Фиолетовый `#8b5cf6` |
| **Green** | Зелёная | Зелёный `#10b981` |

Все токены автоматически переключаются между темами через CSS-переменные.

---

## 🚀 Расширение

Когда один из порогов достигнут, добавьте семантический слой:

| Критерий | Порог |
|----------|-------|
| Базовых UI-компонентов | >15 |
| Тем оформления | >5 |
| Реализованных фич | >5 |

**Порядок:** `color.button.primary.bg → color.accent.default → var(--theme-accent)`
