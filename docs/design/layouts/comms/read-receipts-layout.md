## 1. Обзор

Read receipts — визуальный индикатор статуса прочтения под отправленными пользователем сообщениями:

- **Личный диалог (DIRECT):** одна галочка (доставлено, серым) ✉ → две галочки (прочитано, акцентным) ✓✓
- **Групповой чат (GROUP):** компактный текст «Прочитано: N из M»
- Галочки/счётчик отображаются **только под сообщениями текущего пользователя** (`isCurrentUser`)
- Полностью темо-агностично через CSS-переменные `var(--theme-*)`

Индикатор рендерится внутри пузыря сообщения под контентом, выровнен по правому краю (для своих сообщений).

## 2. Компонент ReadReceiptIcon

### 2.1 Пропсы (из плана T5-2)

| Prop | Тип | По умолчанию | Описание |
|------|-----|-------------|----------|
| `isRead` | `boolean` | `false` | Прочитано ли сообщение (для DIRECT) |
| `readByCount` | `number?` | — | Сколько участников прочитали (для GROUP) |
| `totalParticipants` | `number?` | — | Всего получателей кроме автора (для GROUP) |
| `conversationType` | `'DIRECT' \| 'GROUP'` | `'DIRECT'` | Тип беседы |
| `className` | `string?` | — | Дополнительные CSS-классы |

| Состояние | Тип беседы | Условие | Визуал | aria-label |
|-----------|-----------|---------|--------|------------|
| **S-1: Доставлено** | DIRECT | `!isRead` | одна ✓, серый | `Доставлено` |
| **S-2: Прочитано** | DIRECT | `isRead` | две ✓✓, акцентный | `Прочитано` |

## 3. Экран: Личный диалог (DIRECT) — S-1 / S-2

> Встраивание в `MessageItem`. Схема справа-выравниваемых «своих» сообщений.

```ascii
┌──────────────────────────────────────────────────────────────────┐
│            [Сообщения (ConversationMessagesList)]                │
│                                                                │
│  ┌─────────────────────────────┐  ← сообщение собеседника        │
│  │ [Иван] 12:30                │     (БЕЗ галочек — AC-5)       │
│  │ Привет, как дела?           │                                │
│  └─────────────────────────────┘                                │
│                                                                │
│              ┌─────────────────────────────┐                    │
│              │ [ВЫ]   08:45                │                    │
│              │ Всё отлично, спасибо!      │                    │
│              │                         ✓   │ ← S-1: одна сер.    │
│              └─────────────────────────────┘                    │
│                                                                │
│              ┌─────────────────────────────┐                    │
│              │ [ВЫ]   08:46                │                    │
│              │ А ты как?                  │                    │
│              │                         ✓✓  │ ← S-2: две акцент.  │
│              └─────────────────────────────┘                    │
└──────────────────────────────────────────────────────────────────┘
```

### Позиционирование

- `ReadReceiptIcon` размещается в нижней строке пузыря `MessageItem`, выровнен по правому краю (`self-end`), справа от временной метки (или сразу после контента).
- Галочки — inline SVG (без внешних icon-библиотек), размер `w-3 h-3` (12px).

### Компоненты и токены

| Элемент | Компонент | Токен / класс | AC |
|---------|-----------|---------------|----|
| Контент сообщения | `[MessageItem]` | `bg-[var(--chat-bubble-own-bg)]` | — |
| Одна галочка (S-1) | `[ReadReceiptIcon]` | `color.text.secondary` / `text-[var(--theme-text-secondary)]` | AC-1 |
| Две галочки (S-2) | `[ReadReceiptIcon]` | `color.accent.default` / `text-[var(--theme-accent)]` | AC-2 |
| Размер галочки | — | `w-3 h-3` (≈ `space-3`) | — |
| Отступ индикатора | — | `mt-1` (≈ `space-1`) от контента | — |
| Выравнивание | — | `self-end` (правый край своих сообщений) | — |

### Состояния (DIRECT)

| Состояние | Поведение |
|-----------|-----------|
| Loading | read status ещё не загрузился → индикатор не рендерится, сообщения видны (EC-3 US-39-02) |
| Error (загрузка статуса) | Индикатор скрыт, сообщения остаются видимыми (BR-09, EC-6 US-39-02) |
| Empty (нет сообщений) | Индикаторов нет |
| Data: `!isRead` (S-1) | Одна серая галочка ✓ |
| Data: `isRead` (S-2) | Две акцентные галочки ✓✓ |

## 4. Экран: Групповой чат (GROUP) — S-3

> «Прочитано: N из M» текстом, компактно.

```ascii
┌──────────────────────────────────────────────────────────────────┐
│            [Сообщения (ConversationMessagesList)]                │
│                                                                │
│              ┌──────────────────────────────────┐               │
│              │ [ВЫ]   10:15                     │               │
│              │ Собрание в субботу в 11:00       │               │
│              │                          Прочитано: 3 из 6   │  │
│              └──────────────────────────────────┘               │
│                                                                │
│              ┌──────────────────────────────────┐               │
│              │ [ВЫ]   10:16                     │               │
│              │ Напомните, пожалуйста            │               │
│              │                          Прочитано: 0 из 6   │  │
│              └──────────────────────────────────┘               │
└──────────────────────────────────────────────────────────────────┘
```

### Правила отображения (S-3)

- Показывается всегда, включая 0 прочитавших: **«Прочитано: 0 из M»** (AC-6 US-39-02)
- `M = totalParticipants` (участники кроме автора, BR-07) — автор исключён из счётчика
- Без ограничения отображения при >100 участников: «Прочитано: 47 из 123» (EC-1 US-39-02)
- Не учитывается как «прочитанное» авторское сообщение самому себе (EC-3 US-39-02)

### Компоненты и токены

| Элемент | Компонент | Токен / класс | AC |
|---------|-----------|---------------|----|
| Текст «Прочитано: N из M» | `[ReadReceiptIcon]` | `text.body-xs` (`text-xs leading-tight`) | AC-3, AC-6 |
| Цвет текста счётчика | — | `color.text.secondary` / `text-[var(--theme-text-secondary)]` | AC-3 |
| Отступ | — | `mt-1` от контента | — |
| Выравнивание | — | `self-end` (правый край своих сообщений) | — |

### Состояния (GROUP)

| Состояние | Поведение |
|-----------|-----------|
| Loading | Счётчик не рендерится, сообщения видны |
| Error (загрузка) | Счётчик скрыт, сообщения видны (silent fail) |
| Empty | Индикаторов нет |
| Data: N=0 | «Прочитано: 0 из M» (AC-6) |
| Data: N>0 | «Прочитано: N из M» (AC-3) |

## 5. Встраивание в MessageItem (план T5-3)

`MessageItem` получает два новых пропса:

| Проп | Тип | Описание |
|------|-----|----------|
| `readStatus?` | `{ isReadByRecipient: boolean; readByCount?: number; totalParticipants?: number }` | Статус прочтения |
| `conversationType` | `'DIRECT' \| 'GROUP'` | Тип беседы |

**Логика рендера индикатора:**

```
MessageItem
└── if isCurrentUser  ← галочки ТОЛЬКО у своих сообщений (AC-5)
    └── <ReadReceiptIcon
           isRead={readStatus?.isReadByRecipient}
           readByCount={readStatus?.readByCount}
           totalParticipants={readStatus?.totalParticipants}
           conversationType={conversationType}
        />
```

### Изменения в существующем MessageItem

Текущая реализация `MessageItem` уже содержит блок «Статус сообщения» с одиночной SVG-галочкой внизу для `message.status` (sent/delivered/read). Реализация read receipts (T5-3):

- **[CHANGE]** Заменить одиночную SVG-галочку статуса на компонент `[ReadReceiptIcon]`.
- **[CHANGE]** Источник статуса меняется с `message.status` на `message.readStatus` (`isReadByRecipient` / `readByCount` / `totalParticipants`).
- **[KEEP]** Отображение только для `isCurrentUser`.
- **[KEEP]** Позиционирование `mt-1 flex items-end justify-end` в нижней части пузыря.
- **[CHANGE]** Цвет: `color.text.secondary` (непрочитано) → `color.accent.default` (прочитано) вместо текущего `color.info`.

### Согласование цветов (галочка прочитано)

| Аспект | Текущая реализация | After (read receipts) | Токен |
|--------|-------------------|-----------------------|-------|
| Галочка «прочитано» | `color.info` (синяя) | `color.accent.default` (акцентная) | `--theme-accent` |
| Галочка «доставлено» | `color.success` | `color.text.secondary` (серая) | `--theme-text-secondary` |
| Текст «Прочитано: N из M» | — (отсутств.) | `color.text.secondary` | `--theme-text-secondary` |

> **Обоснование:** Акцентный цвет является «фирменным» для темы (blue/volet/green) и лучше согласуется с единым визуальным шаблоном US-38-01, чем `color.info`. Серый для «доставлено» не конфликтует с семантикой «успех».

## 7. Индикация активного диалога / отметка прочитанных (US-39-01)

> Автоматическая отметка прочитанных при открытии диалога/чата (T6-1, T6-2) — логика, а не статичный UI. Визуальные последствия для UI:

| Триггер | Визуальное следствие | Компонент |
|---------|----------------------|-----------|
| Открытие `/messages/[conversationId]` | Свои сообщения обновляются: ✓ → ✓✓ (после refetch) | `[ReadReceiptIcon]` (S-2) |
| Открытие `/chats/[chatId]` | Счётчик прочитавших у своих сообщений увеличивается | `[ReadReceiptIcon]` (S-3) |
| Успех PATCH `/read` | Бейдж на карточке диалога/чата скрывается | `<Badge>` |
| Успех PATCH `/read` | Счётчики на вкладках обнуляются/уменьшаются | `[CommsTabs]` |
| Ошибка сети | Ничего не блокируется, статус обновится позже (silent fail) | — |

## 8. Темы оформления (Light / Dark / Green)

Все цвета индикатора задаются через CSS-переменные `var(--theme-*)`, поэтому автоматически переключаются между темами.

| Токен | Light | Dark | Green |
|-------|-------|------|-------|
| `--theme-text-secondary` (серая галочка, текст счётчика) | `#6b7280` | `#9ca3af` | `#6ee7b7` |
| `--theme-accent` (две акцентные галочки) | `#3b82f6` (синий) | `#8b5cf6` (фиолетовый) | `#10b981` (зелёный) |
| `--theme-bg-primary` (фон страницы) | `#ffffff` | `#111827` | `#064e3b` |

**Проверка переключателем:** при смене темы (US-19-05) галочки и текст счётчика обновляются без изменения разметки — только через CSS-переменные.

## 12. Примечания для Component Spec

1. **`[ReadReceiptIcon]`** — новый feature-компонент (T5-2), раскрыть в конкретный компонент:
   - inline SVG (без lucide), `w-3 h-3`
   - DIRECT: одна галочка (S-1, серый) / две галочки (S-2, акцентный)
   - GROUP: текст `<span>` «Прочитано: N из M`, `text-xs`
   - `aria-label` + `role="img"`, внутренние SVG `aria-hidden`
2. **`[MessageItem]`** — CHANGE (T5-3): заменить одиночную SVG-галочку `message.status` на `[ReadReceiptIcon]`, источник данных — `message.readStatus`; отображать только при `isCurrentUser`.
3. **`[ConversationMessagesList]`** — CHANGE (T5-4): тип сообщений → `MessageWithReadStatus`, проброс `readStatus` + `conversationType`.
4. **`<Badge variant="danger">`** — CHANGE (токенизация): `bg-[var(--theme-danger)]/10` + `text-[var(--theme-danger)]` вместо хардкода `bg-red-100 text-red-800` (см. `badge.md`).
5. **Темы** — только CSS-переменные `var(--theme-*)`, без хардкода цветов.
6. **Адаптивность** — индикатор не меняет поведения на mobile; `MessageItem` уже адаптивен (US-38-01/02/03). Дополнительная адаптивность не требуется.
