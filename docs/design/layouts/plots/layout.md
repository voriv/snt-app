## 3. Примечания

- **Адаптивность:** На мобильных (<768px) таблица горизонтально прокручивается (`overflow-x-auto` на обёртке)
- **Кнопка "Создать":** Видна только при роли ADMIN или CHAIRMAN (авторизация на уровне API)
- **TODO: Создать компонент `PlotListSkeleton`** — скелетон для состояния загрузки (5 строк × 4 колонки, pulsing animation)
- **Сортировка:** По умолчанию plotNumber ASC (BR-06), не отображать контролы сортировки на этом этапе
