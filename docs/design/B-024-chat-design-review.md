# B-024 Chat Design Review: Унификация дизайна чатов и личных диалогов

> **Тип:** Feature — UI унификация + CSS темизация
> **Дата:** 2026-07-31
> **Версия:** v1.0
> **Автор:** UI Designer
> **Статус:** Готов к утверждению
> **Зависит от:** B-023 (flex-цепочка + `.h-dvh-full`)

---

## 1. Анализ текущих различий

### 1.1 Сравнение структур страниц

| Аспект                 | Личный диалог (messages)                                              | Групповой чат (chats)                                             |
| ---------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Корневой layout**    | `ConversationDetailPage` — `flex flex-col h-full`                     | `page.tsx` — `max-w-4xl mx-auto px-4 ... h-full flex flex-col`    |
| **Заголовок**          | `flex-shrink-0`, `border-b`, `bg-[var(--theme-bg-primary)]`           | Нет `flex-shrink-0`, нет `border-b`, ограничен `max-w-4xl`        |
| **Список сообщений**   | `ConversationMessagesList` с IntersectionObserver + пагинация         | `MessageList` БЕЗ пагинации, просто `flex-1 overflow-y-auto mb-4` |
| **Фон зоны сообщений** | Inherits от `ConversationDetailPage` (`bg-[var(--theme-bg-primary)]`) | Inherits от страницы — фон не отличается                          |
| **Ограничение ширины** | Нет (`h-full`, без `max-w-4xl`)                                       | `max-w-4xl mx-auto` — сужает контент                              |

### 1.2 Проблемы, выявленные в дизайне

| #   | Область                    | Проблема                                                                                            | Влияние на UX                                |
| --- | -------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| P1  | Заголовок группового чата  | Нет `flex-shrink-0` — заголовок сжимается при скролле; нет `border-b` — нет визуального разделителя | Нарушение AC-4 (US-38-01), AC-6 (US-38-01)   |
| P2  | Ограничение `max-w-4xl`    | Групповой чат сужен, личный диалог — полная ширина                                                  | Нарушение AC-1 (US-38-01) — единая структура |
| P3  | Фон зоны сообщений         | Не отличается от фона страницы                                                                      | Нарушение AC-1 (US-38-02)                    |
| P4  | Пузырьки чужих сообщений   | Используют `bg-[var(--theme-bg-primary)]` — сливаются с новым `--chat-bg`                           | Нарушение AC-4 (US-38-02)                    |
| P5  | Отсутствие CSS-переменных  | Нет `--chat-bg`, `--chat-bubble-*` — невозможно темизировать                                        | Нарушение AC-2 (US-38-02)                    |
| P6  | Пагинация в групповом чате | `MessageList` без пагинации — все сообщения загружаются сразу                                       | Нарушение AC-5 (US-38-01)                    |

### 4.2 Значения CSS-переменных для 3 тем

#### Светлая тема (`[data-theme='light']`)

| Переменная                  | Значение  | Целевой элемент | Контраст с `--chat-bg`  |
| --------------------------- | --------- | --------------- | ----------------------- |
| `--chat-bg`                 | `#f0f2f5` | Зона сообщений  | —                       |
| `--chat-bubble-other-bg`    | `#ffffff` | Чужой пузырёк   | ✅ белый на светло-сером |
| `--chat-bubble-own-bg`      | `#1976d2` | Свой пузырёк    | ✅ синий на светло-сером |
| `--chat-bubble-other-color` | `#111827` | Текст чужого    | ✅ на белом              |
| `--chat-bubble-own-color`   | `#ffffff` | Текст своего    | ✅ на синем              |

**Визуальное обоснование:**
- `--chat-bg: #f0f2f5` — классический светло-серый фон мессенджеров (Telegram, WhatsApp)
- `--chat-bubble-other-bg: #ffffff` — белый пузырёк контрастирует с серым фоном
- `--chat-bubble-own-bg: #1976d2` — тёмно-синий (немного темнее `theme-accent: #3b82f6`), чтобы контрастировать и с серым фоном, и с белыми пузырьками
- Акцент `--theme-accent: #3b82f6` остаётся для других UI-элементов (кнопок, ссылок)

#### Тёмная тема (`[data-theme='dark']`)

| Переменная                  | Значение  | Целевой элемент | Контраст с `--chat-bg`       |
| --------------------------- | --------- | --------------- | ---------------------------- |
| `--chat-bg`                 | `#1a1a2e` | Зона сообщений  | —                            |
| `--chat-bubble-other-bg`    | `#2d2d44` | Чужой пузырёк   | ✅ темно-серый на тёмном фоне |
| `--chat-bubble-own-bg`      | `#7c3aed` | Свой пузырёк    | ✅ фиолетовый на тёмном фоне  |
| `--chat-bubble-other-color` | `#f9fafb` | Текст чужого    | ✅ светло-серый на тёмном     |
| `--chat-bubble-own-color`   | `#ffffff` | Текст своего    | ✅ белый на фиолетовом        |

**Визуальное обоснование:**
- `--chat-bg: #1a1a2e` — глубокий тёмно-фиолетовый оттенок, классический «тёмный режим» мессенджеров (сравните с `--theme-bg-primary: #111827`)
- `--chat-bubble-other-bg: #2d2d44` — чуть светлее фона, чтобы пузырёк выделялся
- `--chat-bubble-own-bg: #7c3aed` — фиолетовый (созвучен с `--theme-accent: #8b5cf6`), но темнее для лучшего контраста с белым текстом

#### Зелёная тема (`[data-theme='green']`)

| Переменная                  | Значение  | Целевой элемент | Контраст с `--chat-bg`            |
| --------------------------- | --------- | --------------- | --------------------------------- |
| `--chat-bg`                 | `#e8f5e9` | Зона сообщений  | —                                 |
| `--chat-bubble-other-bg`    | `#ffffff` | Чужой пузырёк   | ✅ белый на светло-зелёном         |
| `--chat-bubble-own-bg`      | `#2e7d32` | Свой пузырёк    | ✅ тёмно-зелёный на светло-зелёном |
| `--chat-bubble-other-color` | `#111827` | Текст чужого    | ✅ на белом                        |
| `--chat-bubble-own-color`   | `#ffffff` | Текст своего    | ✅ на тёмно-зелёном                |

**Визуальное обоснование:**
- `--chat-bg: #e8f5e9` — очень светлый зелёный, отличается и от фона страницы (`--theme-bg-primary: #064e3b`), и от фона заголовка
- На зелёной теме контраст максимальный: фон страницы **тёмно-зелёный**, фон сообщений **светло-зелёный**
- `--chat-bubble-other-bg: #ffffff` — белый максимально контрастирует со светло-зелёным фоном
- `--chat-bubble-own-bg: #2e7d32` — тёмно-зелёный, контрастирует со светло-зелёным фоном

### 4.3 Сравнение с фонами страниц (визуальный контраст)

| Тема  | `--theme-bg-primary` (страница) | `--theme-bg-secondary` (AppLayout) | `--chat-bg` (зона сообщений) | Различие                       |
| ----- | ------------------------------- | ---------------------------------- | ---------------------------- | ------------------------------ |
| Light | `#ffffff`                       | `#f9fafb`                          | `#f0f2f5`                    | Чат темнее страницы ✅          |
| Dark  | `#111827`                       | `#1f2937`                          | `#1a1a2e`                    | Чат имеет фиолетовый оттенок ✅ |
| Green | `#064e3b`                       | `#065f46`                          | `#e8f5e9`                    | Чат радикально светлее ✅       |

- MessageInput активен (пользователь может начать диалог)

### 5.4 Data (основное состояние)

См. ASCII/Text макет в разделе 2.1.

**Поведение:**
- ChatHeader: кнопка «Назад», название, опциональное описание, слот действий
- Зона сообщений: список сообщений через `MessageItem`
- MessageInput: активен, кнопка отправки
- Scroll to bottom при загрузке/отправке нового сообщения

**Edge cases:**

| Ситуация                          | Поведение                                                           |
| --------------------------------- | ------------------------------------------------------------------- |
| Длинное название                  | `truncate` на названии, `min-w-0` на контейнере                     |
| Нет сообщений                     | EmptyState (см. 5.3)                                                |
| Ошибка при пагинации              | Индикатор ошибки внизу списка (не блокирует существующие сообщения) |
| Быстрое переключение между чатами | ChatLayout сохраняет структуру, меняется контент через children     |
| Маленький экран/mobile            | ChatLayout растягивается на `h-full` за счёт flex-цепочки           |
