# Общая концепция приложения

## 1. Назначение приложения

Приложение предназначено для автоматизации деятельности СНТ.

## 2. Основные решаемые задачи

- Ведение информации о садовых участках, садоводах
- Публикация информации и документовдля садоводов, уведомление садоводов
- Автоматизация и учет бухгалтерского учета
- Проведение онлайн голосований
- Общение (форумы и чаты)

## Технологические ограничения

Необходимо минимизировать требования к ресурсам ( CPU, памяти и дискам)
Диск 10Gb
Память 500Mb-1Gb

## Технологический стек

- **Frontend + Backend** - Next.js (standalone): SSR + REST API (API Routes)
- **База данных** - PostgreSQL + Prisma ORM
- **WebSocket** - отдельный минисервер для чатов и уведомлений
- **UI** - TailwindCSS
- **Runtime** - pnpm
- **Деплой** - nginx (reverse proxy) + pm2

### Ресурсы VPS

- RAM: 1 GB
- Диск: 10 GB
