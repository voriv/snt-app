# US-21-14: Назначение чата системной категории

> Эпик: Система общения в СНТ (REQ-COMMS-001)

---

## Формулировка

**Как** администратор СНТ,
**я хочу** назначать системные категории чатам,
**чтобы** группировать чаты по темам или участкам для удобства навигации.

---

## Целевое состояние

После реализации администратор сможет открыть страницу чата и назначить ему системную категорию из выпадающего списка. Чат будет отображаться в соответствующей категории в списке чатов.

---

## Контекст

### Проблема
Администраторы не могут назначать категории чатам. Чаты не структурированы и трудно найти нужный.

### Решение
Добавить возможность назначения категорий чатам через административный интерфейс.

### Границы
- **Входит:** Назначение одной категории одному чату.
- **Исключено:** Назначение нескольких категорий одному чату, массовое назначение.

---

## Функциональные требования

### FR-REQ-COMMS-001-19: Назначение чата системной категории

Система должна позволять администраторам назначать системную категорию чату.

#### AC-14.1: Выбор категории
- **Дано:** Администратор на странице чата
- **Когда:** Администратор открывает «Назначить категорию»
- **Тогда:** Открывается выпадающий список всех корневых категорий

#### AC-14.2: Назначение категории
- **Дано:** Администратор выбрал категорию
- **Когда:** Администратор нажимает «Сохранить»
- **Тогда:** Чат назначается категории через `PATCH /api/v1/chats/:id`

#### AC-14.3: Смена категории
- **Дано:** Чат уже назначен категории
- **Когда:** Администратор меняет категорию
- **Тогда:** Старая категория снимается, новая назначается

#### AC-14.4: Удаление категории
- **Дано:** Чат назначен категории
- **Когда:** Категория удаляется
- **Тогда:** Чат автоматически перемещается в «Без категории»

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-14-01 | Роль | Только ADMIN и SUPER_ADMIN могут назначать | Проверка роли |
| BR-14-02 | Одна категория | Чат может иметь только одну категорию | Проверка перед назначением |
| BR-14-03 | Автоперемещение | При удалении категории чат перемещается в «Без категории» | Автоматически |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нет прав на назначение | Кнопка «Назначить категорию» не отображается |
| 2 | Чат уже назначен | Показывается текущая категория |
| 3 | Категория удалена | Чат автоматически перемещается в «Без категории» |
