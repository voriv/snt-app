# US-18: Поиск участков

## Контекст

**Проблема:** В большом реестре участков сложно быстро найти нужный участок по номеру, кадастровому номеру или примечанию.

**Решение:** Реализовать функциональность поиска участков с поддержкой частичного совпадения по нескольким полям.

**Границы:**
- Включает: поиск по номеру, кадастровому номеру, примечанию с частичным совпадением
- Исключает: сложную фильтрацию, экспорт результатов

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** искать участки по номеру, кадастровому номеру или примечанию,
**чтобы** быстро находить нужный участок в большом реестре.

## Функциональные требования

### FR-REQ-PLOT-001-05: Поиск участков

Система должна поддерживать поиск участков по фильтрам: номер, кадастровый номер, примечание.

#### AC-6.1: Поиск по номеру участка
- **Дано:** Пользователь открыл страницу списка участков с >10 участками
- **Когда:** Пользователь вводит "1" в поле "Номер"
- **Тогда:** Отображаются только участки, номер которых начинается с "1"

#### AC-6.2: Поиск по кадастровому номеру
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь вводит "50:20" в поле "Кадастровый номер"
- **Тогда:** Отображаются участки, кадастровый номер которых содержит "50:20"

#### AC-6.3: Поиск по примечанию
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь вводит "центр" в поле "Примечание"
- **Тогда:** Отображаются участки, в примечании которых есть слово "центр"

#### AC-6.4: Комбинированный поиск
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь вводит значения в несколько полей одновременно
- **Тогда:** Результаты фильтруются по всем полям одновременно (AND-логика)

#### AC-6.5: Сброс поиска
- **Дано:** Пользователь применил фильтры поиска
- **Когда:** Пользователь нажимает кнопку "Очистить фильтры"
- **Тогда:** Возвращается полный список всех участков

#### AC-6.6: Пустой поиск
- **Дано:** Все поля поиска пусты
- **Когда:** Пользователь открыл страницу списка участков
- **Тогда:** Отображается полный список всех участков

## Бизнес-правила

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-05 | Поиск участков поддерживает частичное совпадение без учёта регистра | ILIKE оператор PostgreSQL | Поиск case-insensitive |
| BR-06 | Список участков сортируется по номеру участка (по возрастанию) по умолчанию | ORDER BY plot_number ASC | Сортировка на уровне репозитория |

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Поиск по пустому запросу | Возвращается полный список участков |
| 2 | Нет результатов поиска | Отображается EmptyState |
| 3 | Поиск по очень длинной строке (>100 символов) | Обрезается до 100 символов |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации
- **Производительность:** Поиск < 200ms
- **Доступность:** ARIA-метки для полей поиска
- **Локализация:** Все сообщения на русском языке
