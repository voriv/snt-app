# US-21-07: Добавление участников в чат

> Эпик: Система общения в СНТ (REQ-COMMS-001)

---

## Формулировка

**Как** создатель чата или администратор,
**я хочу** добавлять участников в групповой чат,
**чтобы** расширить обсуждение.

---

## Целевое состояние

Пользователь со правами создателя или администратора сможет открыть список участников чата, найти других пользователей через поиск и добавить их в чат. Добавленные участники получат уведомление.

---

## Контекст

### Проблема

Пользователи не могут добавлять участников в существующие чаты. Чат остаётся с фиксированным составом после создания.

### Решение

Создать страницу управления участниками `/dashboard/chats/:chatId/participants` с возможностью поиска и добавления пользователей.

### Границы

- **Входит в US:** Добавление участников в чат.
- **Явно исключено:** Удаление участников (US-21-08), назначение ролей.

---

## Функциональные требования

### FR-REQ-COMMS-001-09: Добавление участников

Система должна позволять добавлять участников в чат.

#### AC-1.1: Проверка прав

- **Дано:** Пользователь открыл `/dashboard/chats/:chatId/participants`
- **Когда:** Страница загружается
- **Тогда:** Если пользователь не создатель или администратор, отображается ошибка 403

#### AC-1.2: Список текущих участников

- **Дано:** Пользователь имеет права
- **Когда:** Рендерится страница
- **Тогда:** Отображается текущий список участников с ролями и количеством

#### AC-1.3: Поиск пользователей

- **Дано:** Пользователь в списке участников
- **Когда:** Пользователь вводит текст в поиск (минимум 2 символа, debounce 300ms)
- **Тогда:** Список фильтруется по имени и email через `GET /api/v1/users/search?q=...`

#### AC-1.4: Добавление участника

- **Дано:** Пользователь выбрал участника
- **Когда:** Пользователь нажимает «Добавить»
- **Тогда:** Участник добавляется через `POST /api/v1/chats/:chatId/participants/:userId`

#### AC-1.5: Предотвращение дублирования

- **Дано:** Пользователь пытается добавить существующего участника
- **Когда:** Нажимается «Добавить»
- **Тогда:** Ошибка «Пользователь уже в чате»

#### AC-1.6: Ограничение по количеству

- **Дано:** В чате уже 50 участников
- **Когда:** Пользователь пытается добавить
- **Тогда:** Ошибка «Чат достиг максимального количества участников (50)»

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-01 | Авторизация и права | Только создатель/администратор | Проверка в сервисе |
| BR-02 | Уникальность участника | Один пользователь — один раз в чате | Проверка на уровне БД |
| BR-03 | Максимум участников | Максимум 50 участников | Проверка перед добавлением |
| BR-04 | Заблокированные пользователи | Нельзя добавить заблокированного | Исключение из списка поиска |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нет прав на добавление | Ошибка 403 «У вас нет прав на добавление участников» |
| 2 | Пользователь уже в чате | Кнопка «Добавить» не отображается, показывается «В чате» |
| 3 | Заблокированный пользователь | Исключён из списка поиска |
| 4 | Чат полный (50 участников) | Кнопка «Добавить» заблокирована, показывается сообщение «Максимум 50 участников» |
| 5 | Медленная сеть | Индикатор загрузки при добавлении |
