# US-16: Удаление участка

## Контекст

**Проблема:** В системе нет возможности удалять земельные участки, которые более не существуют или были ошибочно созданы.

**Решение:** Реализовать функциональность удаления участка с подтверждением действия для предотвращения случайного удаления.

**Границы:**
- Включает: удаление участка с подтверждением через ConfirmDialog
- Исключает: восстановление удалённых участков, массовое удаление

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** удалять земельные участки, которые более не существуют,
**чтобы** поддерживать актуальность реестра земельных участков СНТ.

## Функциональные требования

### FR-REQ-PLOT-001-04: Удаление участка

Система должна поддерживать удаление участка.

#### AC-4.1: Подтверждение удаления
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь кликнул кнопку "Удалить" на участке
- **Тогда:** Показывается ConfirmDialog с сообщением "Вы уверены, что хотите удалить участок №X? Это действие нельзя отменить."

#### AC-4.2: Подтверждение удаления
- **Дано:** Пользователь открыл диалог подтверждения удаления
- **Когда:** Пользователь нажал кнопку "Удалить"
- **Тогда:** Участок удаляется из системы и списка

#### AC-4.3: Отмена удаления
- **Дано:** Пользователь открыл диалог подтверждения удаления
- **Когда:** Пользователь нажал кнопку "Отмена" или закрыл диалог
- **Тогда:** Удаление отменяется, участок остаётся в списке

#### AC-4.4: Пессемистичное обновление
- **Дано:** Пользователь подтвердил удаление участка
- **Когда:** Удаление успешно выполнено
- **Тогда:** Данные страницы перегружаются

#### AC-4.5: Обработка ошибки удаления
- **Дано:** Произошла ошибка при удалении участка
- **Когда:** Пользователь подтвердил удаление
- **Тогда:** Показывается сообщение об ошибке, участок остаётся в списке

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Удаление несуществующего участка (404) | Показывается сообщение "Участок не существует или был удален ранее" |
| 2 | Ошибка сети при удалении | Показывается сообщение "Ошибка удаления участка. Попробуйте позже." |
| 3 | Отмена удаления | Участок остаётся в списке, диалог закрывается |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации, ролевой доступ (ADMIN, MANAGER)
- **Производительность:** Удаление < 300ms
- **Доступность:** ARIA-метки для диалога подтверждения
- **Локализация:** Все сообщения на русском языке
