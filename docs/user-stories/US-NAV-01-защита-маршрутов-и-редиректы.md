# US-NAV-01: Защита маршрутов и редиректы

---

## Формулировка

**Как** система,
**я хочу** защищать все маршруты дашборда от неавторизованного доступа и перенаправлять авторизованных пользователей с главной страницы на дашборд,
**чтобы** гарантировать, что только аутентифицированные пользователи имеют доступ к защищённым разделам, а неавторизованные получают понятный редирект на страницу входа.

---

## Контекст

### Проблема
Без централизованной защиты маршрутов неавторизованные пользователи могут получить доступ к данным дашборда. Авторизованные пользователи, заходящие на корневой маршрут `/`, видят landing page вместо дашборда.

### Решение
Middleware и клиентские guard-компоненты проверяют статус сессии при каждом переходе. Неавторизованные перенаправляются на `/auth/login`. Авторизованные с `/` перенаправляются на `/dashboard`.

### Границы
- **Включает:** Middleware-защиту `/dashboard/*`, редирект с `/` для авторизованных, редирект на `/auth/login` при истекшей сессии, индикатор загрузки при навигации, страницу ошибки с кнопкой «Повторить», сохранение адреса при редиректе
- **Исключает:** Навигационную панель (US-NAV-02), страницу 404 (US-NAV-03), вкладку «Общение» (US-NAV-04), боковое меню (US-NAV-05), хлебные крошки (US-NAV-06), мобильное меню (US-NAV-07)

---

## Целевое состояние

После реализации US система защищает все маршруты дашборда (`/dashboard/*`) от неавторизованного доступа:

1. **Неавторизованные пользователи** при попытке открыть любой маршрут `/dashboard/*` перенаправляются на `/auth/login` (через Next.js Middleware).
2. **Авторизованные пользователи** при заходе на корневой маршрут `/` перенаправляются на `/dashboard`.
3. **При истекшей сессии** во время навигации происходит редирект на `/auth/login`.
4. **При навигации и загрузке данных** отображается индикатор загрузки (progress-bar).
5. **При ошибке загрузки страницы** отображается страница ошибки с кнопкой «Повторить».
6. **Адрес назначения сохраняется** для редиректа после успешного входа (EC-01).

## Поведение (User Behavior)

### B-1: Неавторизованный пользователь на дашборде
Неавторизованный пользователь (гость) вводит URL дашборда в адресную строку браузера или переходит по прямой ссылке. Middleware проверяет отсутствие валидной сессии и перенаправляет пользователя на `/auth/login`.

### B-2: Авторизованный пользователь на главной
Авторизованный пользователь заходит на корневой маршрут `/`. Система определяет наличие валидной сессии и перенаправляет на `/dashboard`.

### B-3: Истекшая сессия
Сессия пользователя истекла во время работы в дашборде. При следующей навигации система определяет невалидность сессии и перенаправляет на `/auth/login`.

### B-4: Навигация с загрузкой
Пользователь инициирует навигацию между страницами дашборда. Система отображает индикатор загрузки (progress-bar) на время загрузки данных страницы.

### B-5: Ошибка загрузки страницы
При ошибке загрузки страницы дашборда (сетевая ошибка, ошибка сервера) отображается страница ошибки с кнопкой «Повторить». Пользователь может нажать кнопку для повторной попытки.

## Критерии приёмки

### AC-NAV-01-1: Главная страница для неавторизованных
- **Given** пользователь не авторизован (нет валидной сессии)
- **When** пользователь открывает корневой маршрут `/`
- **Then** отображается главная (landing) страница, редирект не происходит

### AC-NAV-01-2: Редирект авторизованного с главной на дашборд
- **Given** пользователь авторизован (есть валидная сессия)
- **When** пользователь открывает корневой маршрут `/`
- **Then** происходит редирект на `/dashboard` без лишних записей в browser history

### AC-NAV-01-3: Редирект неавторизованного с дашборда на вход
- **Given** пользователь не авторизован
- **When** пользователь пытается открыть любой маршрут `/dashboard/*`
- **Then** происходит редирект на `/auth/login`

### AC-NAV-01-4: Прямой доступ с сохранением адреса (EC-01)
- **Given** пользователь не авторизован
- **When** пользователь пытается открыть `/dashboard/plots`
- **Then** происходит редирект на `/auth/login` с сохранением адреса (`callbackUrl=/dashboard/plots`) для возврата после входа

### AC-NAV-01-5: Истекшая сессия (EC-04)
- **Given** сессия пользователя истекла (токен невалиден)
- **When** пользователь переходит на страницу дашборда
- **Then** происходит редирект на `/auth/login`

### AC-NAV-01-6: Индикатор загрузки при навигации (EC-05)
- **Given** пользователь авторизован и инициировал навигацию
- **When** страница загружается (данные запрашиваются)
- **Then** отображается индикатор загрузки (progress-bar)

### AC-NAV-01-7: Ошибка при загрузке страницы (EC-06)
- **Given** произошла ошибка при загрузке страницы дашборда
- **When** страница не может быть загружена
- **Then** отображается страница ошибки с кнопкой «Повторить»

### AC-NAV-01-8: Механизм защиты недоступен (EC-03)
- **Given** механизм защиты маршрутов (Middleware) недоступен
- **When** пользователь обращается к маршруту дашборда
- **Then** страница отображается без редиректа (graceful degradation)

## Бизнес-правила и валидация

| ID | Правило | Валидация |
|----|---------|-----------|
| BR-02 | Главная страница доступна всем без авторизации | Middleware: skip `/` если нет сессии |
| BR-03 | Страницы входа и регистрации доступны без авторизации | Middleware: public-маршруты |
| BR-04 | Все маршруты дашборда требуют авторизации | Middleware: редирект на `/auth/login` |
| BR-05 | Авторизованные пользователи перенаправляются с `/` на дашборд | Middleware/client: редирект на `/dashboard` |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Прямой доступ к странице списка участков без авторизации (EC-01) | Редирект на `/auth/login` с сохранением адреса в `callbackUrl` |
| 2 | Механизм защиты маршрутов недоступен (EC-03) | Страница отображается без редиректа (graceful degradation) |
| 3 | Сессия истекла во время навигации (EC-04) | Редирект на `/auth/login` при следующей навигации |
| 4 | Навигация при загрузке данных (EC-05) | Индикатор загрузки / прогресс-бар |
| 5 | Ошибка при загрузке страницы (EC-06) | Страница ошибки с кнопкой «Повторить» |
| 6 | Отключены куки в браузере | Редирект на `/auth/login` (токен не отправляется) |
| 7 | Ошибка сети при навигации | Отображается landing page или страница ошибки (fallback) |

## Нефункциональные требования

- **Производительность:** Проверка сессии через Middleware — быстрее 50ms; клиентская навигация без полной перезагрузки страницы; загрузка страниц дашборда < 1s
- **Безопасность:** Двойная защита: серверная (Middleware) + клиентская (guard-компоненты); проверка сессии на уровне компонентов
- **UX:** Плавные переходы между страницами; индикаторы загрузки при навигации; понятные сообщения об ошибках; кнопка «Повторить» при ошибке
- **Доступность:** Семантическая HTML-разметка; управление фокусом при навигации; атрибуты `aria-live` для индикаторов загрузки
