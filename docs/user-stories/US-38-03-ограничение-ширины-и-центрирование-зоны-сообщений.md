# US-38-03: Ограничение ширины и центрирование зоны сообщений в чатах

> Эпик: Система общения в СНТ (REQ-COMMS-002)

---

## Формулировка

**Как** зарегистрированный пользователь СНТ,
**я хочу** чтобы зона сообщений (список сообщений и поле ввода) на широких экранах была ограничена по ширине и центрирована по горизонтали, а заголовок чата занимал всю ширину страницы,
**чтобы** читать сообщения было комфортно независимо от размера экрана.

---

## Целевое состояние

После реализации:

1. **Заголовок чата** растягивается на всю ширину страницы во всех разрешениях — без изменений по сравнению с US-38-01.

2. **Зона сообщений** (список сообщений + поле ввода) на десктопных экранах (`≥1024px`) ограничена по ширине (например, `max-w-4xl` / 896px) и центрирована по горизонтали (`mx-auto`).

3. **На широких экранах** по бокам от центрированной зоны отображается фон страницы (`--theme-bg-primary`), который визуально отличается от фона зоны сообщений (`--chat-bg`).

4. **На мобильных устройствах** (`<1024px`) ограничение ширины не применяется — зона сообщений занимает всю доступную ширину экрана.

5. Поведение идентично для личных диалогов и групповых чатов, так как оба используют единый компонент `ChatLayout`.

---

## Контекст

### Проблема

После унификации дизайна чатов ([US-38-01](US-38-01-единый-визуальный-шаблон-чатов.md)) зона сообщений не имеет ограничения по ширине — на широких экранах сообщения растягиваются на всю ширину страницы, что ухудшает читаемость (строка текста становится слишком длинной).

### Решение

Добавить в компонент `ChatLayout` центрирующий контейнер с `max-width` для зоны сообщений. Заголовок остаётся full-width. Снаружи от центрированной зоны виден фон страницы.

### Границы

- **Входит в US:** центрирующий контейнер в `ChatLayout`, responsive-поведение (широкие экраны / мобильные), видимый фон страницы по бокам.
- **Явно исключено:** изменение фона зоны сообщений (US-38-02), изменение структуры заголовка (US-38-01), изменение пагинации (US-38-01), изменение поля ввода (US-21-03-02/US-21-09).

## Поведение (User Behavior)

### B-1: Просмотр чата на широком экране (десктоп)

Пользователь открывает личный диалог или групповой чат на десктопном мониторе (ширина ≥1024px). Заголовок чата растягивается на всю ширину окна. Зона сообщений отображается в центре экрана с ограничением ширины (например, 768px). По бокам от зоны сообщений виден фон страницы.

### B-2: Просмотр чата на мобильном устройстве

Пользователь открывает тот же чат на мобильном устройстве (ширина <1024px). Зона сообщений занимает всю доступную ширину экрана без ограничения. Заголовок также растягивается на всю ширину.

### B-3: Ресайз окна с десктопа на мобильный

Пользователь постепенно сужает окно браузера. При пересечении breakpoint `1024px` ограничение ширины плавно снимается — зона сообщений начинает занимать всю ширину. Обратное растягивание — ограничение восстанавливается.

## Критерии приёмки

### AC-1: Ограничение ширины на десктопе

- **Given:** Пользователь на странице личного диалога или группового чата
- **When:** Ширина окна ≥1024px
- **Then:** Зона сообщений (список сообщений и поле ввода) ограничена по ширине (например, `max-w-4xl`) и центрирована по горизонтали

### AC-2: Заголовок на всю ширину

- **Given:** Пользователь на странице чата
- **When:** Ширина окна ≥1024px
- **Then:** Заголовок чата (`ChatHeader`) растягивается на всю ширину страницы, не участвует в центрировании зоны сообщений

### AC-3: Видимый фон по бокам

- **Given:** Пользователь на странице чата с шириной окна ≥1024px
- **When:** Зона сообщений центрирована
- **Then:** По бокам от зоны сообщений виден фон страницы (`--theme-bg-primary`), который отличается от фона зоны сообщений (`--chat-bg`)

### AC-4: Полная ширина на мобильных

- **Given:** Пользователь на странице чата
- **When:** Ширина окна <1024px
- **Then:** Зона сообщений занимает всю доступную ширину экрана без ограничения

### AC-5: Единое поведение для обоих типов чатов

- **Given:** Пользователь открывает личный диалог и групповой чат при одинаковой ширине окна
- **When:** Обе страницы загружены
- **Then:** Поведение центрирования и ограничения ширины идентично на обеих страницах (обе используют `ChatLayout`)

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Планшет (768–1024px) | Зона сообщений занимает всю ширину (без ограничения) — планшет считается мобильным форматом |
| 2 | Очень широкий монитор (1920px+) | Зона сообщений ограничена тем же `max-w-3xl`, по бокам больше видимого фона страницы |
| 3 | Ресайз окна во время скролла сообщений | Центрирование и ограничение работают независимо от скролла — скролл не сбрасывается |
| 4 | Быстрое переключение между чатами | При переходе на другой чат центрирование сохраняется, так как `ChatLayout` переиспользуется |
| 5 | Узкое мобильное устройство (<360px) | Ограничение не применяется, зона сообщений на всю ширину |

## Реализация

### Изменение в ChatLayout.tsx

Текущая структура (строка 40–55):

```tsx
return (
  <div className="flex flex-col h-full">
    <ChatHeader ... />
    <div className="flex flex-col flex-1 min-h-0">
      {children}
    </div>
  </div>
);
```

Целевая структура:

```tsx
return (
  <div className="flex flex-col h-full w-full">
    <ChatHeader ... />
    <div className="flex-1 min-h-0 w-full flex justify-center">
      <div className="w-full lg:max-w-3xl mx-auto flex flex-col h-full">
        {children}
      </div>
    </div>
  </div>
);
```

**Пояснение:**
1. Внешний `div` — `w-full` обеспечивает растяжение на всю ширину
2. Внутренний центрирующий `div` — `flex justify-center` для центрирования дочернего контейнера
3. Контейнер `children` — `w-full` (мобильные: полная ширина) + `lg:max-w-3xl` (десктоп: ограничение) + `mx-auto` (центрирование)
4. Header остаётся full-width вне центрирующего контейнера (FR-10)

> **Примечание:** Конкретное значение `max-w-3xl` (768px) может быть скорректировано на этапе code review. Альтернативы: `max-w-2xl` (672px), `max-w-4xl` (896px).
