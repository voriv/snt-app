# US-17: Просмотр карточки участка

## Контекст

**Проблема:** На странице списка участков отображается только базовая информация (номер, кадастровый номер, площадь, адрес). Пользователям нужна детальная информация об участке с возможностью редактирования.

**Решение:** Реализовать страницу карточки участка с полной информацией и возможностью редактирования.

**Границы:**
- Включает: отображение полной информации об участке, редактирование через форму
- Исключает: создание, удаление, управление связями пользователь-участок (отдельные US)

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** просмотреть детальную информацию об участке,
**чтобы** ознакомиться со всеми характеристиками участка и отредактировать их при необходимости.

## Функциональные требования

### FR-REQ-PLOT-001-09: Детальная информация об участке

Система должна отображать детальную информацию об участке на странице деталей участка.

#### AC-5.1: Страница деталей участка
- **Дано:** Пользователь кликнул на номер участка в списке
- **Когда:** Пользователь перенаправлен на `/dashboard/plots/:id`
- **Тогда:** Отображается полная информация об участке

#### AC-5.2: Отображение всех полей участка
- **Дано:** Пользователь открыл страницу карточки участка
- **Когда:** Данные успешно загружены
- **Тогда:** Отображаются все поля: номер, кадастровый номер, площадь, адрес, примечание, даты создания и обновления

#### AC-5.3: Номер участка только для чтения
- **Дано:** Пользователь открыл страницу карточки участка
- **Когда:** Пользователь видит форму редактирования
- **Тогда:** Поле номера участка недоступно для редактирования

#### AC-5.4: Переход на страницу деталей
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь кликнул на номер участка в таблице
- **Тогда:** Пользователь перенаправляется на страницу `/dashboard/plots/:id`

#### AC-5.5: Обработка отсутствия участка
- **Дано:** Пользователь попытался открыть несуществующий участок
- **Когда:** Участок не найден (404)
- **Тогда:** Показывается сообщение "Участок не найден" с кнопкой "Вернуться к списку участков"

## Бизнес-правила

|----|---------|----------|-----------|
| BR-01 | Номер участка не может быть изменён после создания | Поле plotNumber только для чтения | В интерфейсе заблокировано |

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Участок не найден (404) | Показывается сообщение "Участок не найден" |
| 2 | Ошибка сети при загрузке | Показывается сообщение "Ошибка загрузки данных" |
| 3 | Медленная сеть (более 3 секунд) | Показывается индикатор загрузки |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации
- **Производительность:** Загрузка карточки < 500ms
- **Доступность:** Семантическая разметка, ARIA-метки
- **Локализация:** Все сообщения на русском языке
