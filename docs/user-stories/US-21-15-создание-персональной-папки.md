# US-21-15: Создание персональной папки

## Формулировка
**Как** пользователь системы чатов,
**я хочу** создавать собственные персональные папки для сортировки чатов,
**чтобы** структурировать свою переписку и быстрее находить нужные диалоги.

## Целевое состояние
Пользователь может создать новую персональную папку с уникальным именем. Пустые папки отображаются в интерфейсе фильтрации чатов.

### Границы
- Создание папки доступно только авторизованным пользователям.
- Имя папки должно быть уникальным для текущего пользователя.
- Имя папки не может содержать системные символы (например, `/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`).
- Система имеет ограничение на количество папок на одного пользователя (например, 50 шт).
- Папки создаются для одного пользователя (персональные), а не групповые.

## Функциональные требования

### FR-REQ-COMMS-001-15: Создание персональной папки

#### AC-15.1: Создание папки с корректным именем
- **Дано:** Пользователь авторизован и находится в интерфейсе управления чатами.
- **Когда:** Пользователь вводит уникальное имя папки (не пустое, корректные символы) и нажимает кнопку "Создать".
- **Тогда:**
  - Система создает новую персональную папку.
  - В списке папок появляется новая запись.
  - Пользователь видит уведомление об успешном создании.
  - Папка имеет статус "активная" по умолчанию.

#### AC-15.2: Валидация имени папки
- **Дано:** Пользователь пытается создать папку с некорректным именем.
- **Когда:** Пользователь вводит:
  - Пустое имя.
  - Имя, превышающее лимит символов (например, >50).
  - Имя, содержащее запрещенные символы.
  - Имя, которое уже существует у данного пользователя.
- **Тогда:**
  - Система отображает понятное сообщение об ошибке валидации.
  - Папка не создается.
  - Фокус остается в поле ввода имени.

#### AC-15.3: Отображение списка папок
- **Дано:** У пользователя есть созданные папки.
- **Когда:** Пользователь переходит в раздел чатов.
- **Тогда:**
  - Список персональной папки отображается в боковой панели или меню навигации.
  - Количество чатов в каждой папке отображается в скобках (или иконкой).

### FR-REQ-COMMS-001-16: Получение списка папок

#### AC-16.1: Загрузка списка папок
- **Дано:** Пользователь авторизован.
- **Когда:** Пользователь открывает список чатов.
- **Тогда:**
  - Система запрашивает список всех папок пользователя через API.
  - Отображается список с ID, именем и количеством чатов.
  - Если папок нет, отображается подсказка "Создайте первую папку".

### FR-REQ-COMMS-001-17: Проверка уникальности
- **Дано:** Пользователь пытается создать дублирующую папку.
- **Когда:** Отправляется запрос на создание папки с существующим именем.
- **Тогда:**
  - API возвращает ошибку 409 Conflict с сообщением "Папка с таким именем уже существует".
  - Интерфейс показывает ошибку пользователю.

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-15-01 | Уникальность имени | Имя папки должно быть уникальным для каждого пользователя | Проверка на `SELECT COUNT(*)` перед INSERT |
| BR-15-02 | Ограничение символов | Имя папки должно содержать только буквы, цифры, пробелы и базовые символы | Регулярное выражение валидации |
| BR-15-03 | Длина имени | Длина имени папки от 1 до 50 символов | Валидация длины строки |
| BR-15-04 | Лимит папок | Максимум 50 папок на одного пользователя | Проверка счетчика перед созданием |
| BR-15-05 | Системные папки | Пользователь не может создавать папки с именами зарезервированных системных категорий | Сравнение с белым списком системных имен |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Имя папки содержит только пробелы | Система удаляет пробелы или отклоняет запись как пустую |
| 2 | Попытка создать >50 папок | Блокировка создания, вывод сообщения о достижении лимита |
| 3 | Быстрое создание папок с одинаковым именем | Каждая попытка после первой должна возвращать ошибку конфликта |
| 4 | Отключение интернета во время создания | Обработка таймаута, показ сообщения о сети |
| 5 | Одновременное создание папки двумя устройствами | Серверная блокировка или проверка уникальности транзакцией |

## Нефункциональные требования
- **Производительность:** Запрос списка папок должен выполняться за < 200мс при наличии до 100 папок.
- **Безопасность:** Проверка, что пользователь создает папки только для своего `user_id`.
- **Локализация:** Все сообщения об ошибках на русском языке.
- **UI/UX:** Анимация появления новой папки в списке.

## Открытые вопросы
1. Нужно ли предусмотреть возможность иконок для папок в будущем? (Решение: отложить, реализовать базово без иконок).
