# US-21-03-02: Просмотр истории сообщений в личном диалоге

## Формулировка

**Как** зарегистрированный пользователь СНТ,
**я хочу** просматривать историю сообщений в личном диалоге,
**чтобы** общаться с другими пользователями и видеть всю переписку.

---

## Целевое состояние

После реализации пользователь сможет открыть страницу `/dashboard/messages/:conversationId` и увидеть полную историю сообщений личного диалога. Сообщения отображаются в хронологическом порядке (новые снизу), каждое сообщение показывает: текст, отправителя, время отправки, статусы (прочитано/не прочитано). Внизу страницы находится поле ввода нового сообщения. Страница поддерживает скроллинг истории и автоматическую прокрутку к новому сообщению.

---

## Контекст

### Проблема

Существует страница списка диалогов (US-21-01) и страница начала нового диалога (US-21-02), но отсутствует возможность просмотра истории сообщений внутри диалога. Пользователи не могут общаться, так как не видят переписку и не могут отправлять новые сообщения.

### Решение

Создать страницу `/dashboard/messages/:conversationId` с отображением истории сообщений и полем ввода нового сообщения. Реализовать базовую функциональность чата: загрузку истории сообщений, отображение в виде气泡 (bubbles), автопрокрутку, статусы сообщений.

### Границы

- **Входит в US:** Отображение истории сообщений в личном диалоге, поле ввода нового сообщения, базовые функции чата (скроллинг, статусы прочитано/не прочитано), отправка текстовых сообщений и эмодзи, удаление своего сообщения, отмена отправки (ESC).
- **Явно исключено:** Редактирование отправленных сообщений, групповые чаты (US-21-09), отправка файлов (US-21-04), реакция на сообщения (US-21-10), цитирование (US-21-11), звонки, видеоконференции.

## Функциональные требования

### FR-REQ-COMMS-001-03: История сообщений

Система должна поддерживать просмотр истории сообщений в личном диалоге.

#### AC-3.1: Загрузка истории сообщений

- **Дано:** Пользователь авторизован и перешёл на страницу `/dashboard/messages/:conversationId`
- **Когда:** Страница загружается
- **Тогда:** История сообщений загружается через `GET /api/v1/conversations/:conversationId/messages` и отображается в хронологическом порядке (новые снизу)

#### AC-3.2: Структура сообщения

- **Дано:** Сообщения успешно загружены
- **Когда:** Сообщение рендерится
- **Тогда:** Сообщение содержит: текст/эмодзи, имя отправителя (см. AC-3.11), время отправки, статус прочитано/не прочитано, кнопку удаления (только для своих сообщений)

#### AC-3.11: Отображение имени отправителя

- **Дано:** Сообщение рендерится в истории диалога
- **Когда:** Пользователь просматривает сообщение
- **Тогда:** Отображение имени зависит от того, кто отправил сообщение:
  - **Сообщение текущего пользователя:** всегда отображается «ВЫ»
  - **Сообщение собеседника:** отображается «Имя Фамилия» из `UserProfile`
  - **Fallback:** если имя и фамилия отсутствуют — отображается email из `User.email`
  - **Удалённый отправитель:** отображается «Удалённый пользователь»

#### AC-3.3: Сортировка по времени

- **Дано:** Загружено несколько сообщений
- **Когда:** История рендерится
- **Тогда:** Сообщения отсортированы по времени отправки (новые внизу)

#### AC-3.4: Скроллинг истории

- **Дано:** Более 20 сообщений в диалоге
- **Когда:** Пользователь скроллит вверх
- **Тогда:** При подходе к верху загружается предыдущая порция сообщений (пагинация/инфинити-скролл)

#### AC-3.5: Автопрокрутка к новому сообщению

- **Дано:** Пользователь открыл диалог с новыми неразсмотренными сообщениями
- **Когда:** Страница загружается
- **Тогда:** Автоматическая прокрутка к последнему неразсмотренному сообщению

---

### FR-REQ-COMMS-001-02: Отправка текстовых сообщений

Система должна позволять пользователю отправлять текстовые сообщения в личном диалоге.

#### AC-3.6: Поле ввода сообщения

- **Дано:** Пользователь на странице диалога
- **Когда:** Рендерится поле ввода
- **Тогда:** Поле ввода отображается внизу страницы, поддерживает ввод текста и эмодзи, кнопка отправки активна при наличии текста

#### AC-3.7: Отправка сообщения

- **Дано:** В поле ввода есть текст (минимум 1 символ, максимум 4000 символов)
- **Когда:** Пользователь нажимает кнопку отправки или Ctrl+Enter
- **Тогда:** Сообщение отправляется через `POST /api/v1/messages` и мгновенно отображается в чате

#### AC-3.8: Ограничения сообщения

- **Дано:** Пользователь вводит сообщение
- **Когда:** Сообщение отправляется
- **Тогда:** Система проверяет длину (1-4000 символов), эмодзи поддерживаются, пустые сообщения не отправляются

#### AC-3.9: Удаление своего сообщения

- **Дано:** Пользователь отправил сообщение 5 минут назад
- **Когда:** Пользователь нажимает кнопку удаления
- **Тогда:** Сообщение удаляется через `DELETE /api/v1/messages/:messageId` и исчезает из чата

#### AC-3.10: Отмена отправки (ESC)

- **Дано:** Пользователь начал вводить сообщение
- **Когда:** Пользователь нажимает ESC
- **Тогда:** Поле ввода очищается, фокус остаётся в поле

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-01 | Авторизация | Только авторизованные пользователи могут просматривать диалоги и отправлять сообщения | `auth()` в API, `useSession()` на странице |
| BR-02 | Приватность | Сообщения видны только участникам диалога | Фильтрация на уровне Repository по `conversation_participants` |
| BR-03 | Ограничение длины | Сообщение не может быть пустым или превышать 4000 символов | Zod-валидация в сервисе, клиентская валидация перед отправкой |
| BR-04 | Удаление своих сообщений | Пользователь может удалять только свои сообщения в течение 5 минут после отправки | Проверка `message.authorId === currentUserId` и `timestamp < now - 5min` |
| BR-05 | Статус прочитано | При открытии диалога все свои непрочитанные сообщения помечаются как прочитанные | Автоматический `PATCH /api/v1/messages/read` при загрузке страницы |
| BR-10 | Удалённый пользователь | При удалении пользователя сообщения сохраняются, отправитель — «Удалённый пользователь» | Проверка `userId === null` при рендере |

## Граничные случаи (Edge Cases)

| # | Ситуация | Описание | Ожидаемое поведение |
|---|----------|----------|---------------------|
| 1 | Нет сообщений в диалоге | Новый диалог без истории | Отображается `EmptyState` с текстом «Начните диалог, отправив первое сообщение» |
| 2 | Медленная сеть (>3 сек) | Задержка при загрузке истории | Показывается индикатор загрузки, текст «Загрузка сообщений...» |
| 3 | Ошибка загрузки истории | Сервер отвечает 500 | Отображается сообщение об ошибке с кнопкой «Повторить» |
| 4 | Ошибка отправки сообщения | Сеть недоступна или сервер 500 | Отображается ошибка с кнопкой «Повторить», сообщение не добавляется в чат |
| 5 | Попытка отправить пустое сообщение | Пользователь нажимает Enter с пустым полем | Сообщение не отправляется, фокус остаётся в поле, подсказка «Введите текст сообщения» |
| 6 | Попытка отправить сообщение длиннее 4000 символов | Пользователь вводит слишком длинный текст | Предотвращение отправки, подсказка «Максимум 4000 символов» |
| 7 | Попытка удалить чужое сообщение | Пользователь нажимает кнопку удаления чужого сообщения | Кнопка удаления не отображается для чужих сообщений |
| 8 | Попытка удалить сообщение старше 5 минут | Пользователь пытается удалить старое сообщение | Кнопка удаления не отображается для сообщений старше 5 минут |
| 9 | Собеседник заблокирован | Пользователь заблокировал собеседника | Диалог скрыт из списка, при прямом переходе — ошибка 403 |
| 10 | Собеседник удалён | Пользователь был удалён из системы | Вместо имени отображается «Удалённый пользователь», аватар — заглушка |
| 11 | Параллельная отправка | Два окна с одним диалогом | Каждое окно независимо отправляет сообщения, порядок сохраняется по `createdAt` |
| 12 | Сообщение с эмодзи | Пользователь отправляет эмодзи | Эмодзи корректно отображаются в чате |

## Нефункциональные требования

- **Безопасность:** Доступ к диалогу и сообщениям требует авторизации. Сообщения видны только участникам диалога. Удаление сообщений только автором в течение 5 минут.
- **Производительность:** 
  - Загрузка первой порции сообщений (< 50): < 500ms
  - Загрузка следующей порции (пагинация): < 300ms
  - Отправка сообщения: < 1 сек
- **Доступность:** 
  - Сообщения доступны с клавиатуры (tab-навигация, enter для отправки)
  - ARIA-метки для индикаторов загрузки и ошибок
  - Фокус в поле ввода при загрузке страницы
- **Локализация:** Все сообщения на русском языке.
- **Адаптивность:** Чат корректно отображается на мобильных устройствах, поле ввода закреплено внизу экрана.
