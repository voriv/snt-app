# US-13: Создание участка

## Контекст

**Проблема:** В системе нет возможности добавлять новые земельные участки в реестр СНТ.

**Решение:** Реализовать функциональность создания нового участка с валидацией уникальности номера и кадастрового номера.

**Границы:**
- Включает: создание участка с обязательными полями (номер, площадь) и опциональными (кадастровый номер, адрес, примечание)
- Исключает: редактирование, удаление (отдельные US)

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** создать новый земельный участок в системе,
**чтобы** вести учёт всех земельных участков СНТ.

## Функциональные требования

### FR-REQ-PLOT-001-02: Создание участка с валидацией

Система должна поддерживать создание нового участка с валидацией уникальности номера и кадастрового номера.

#### AC-2.1: Создание участока с минимальными данными
- **Дано:** Пользователь авторизован и имеет права на создание участков
- **Когда:** Пользователь заполняет форму создания участока с номером и площадью
- **Тогда:** Участок успешно создаётся и отображается в списке

#### AC-2.2: Валидация уникальности номера участка
- **Дано:** В системе уже существует участок с номером "100"
- **Когда:** Пользователь пытается создать участок с номером "100"
- **Тогда:** Система показывает ошибку "Участок с номером 100 уже существует"

#### AC-2.3: Валидация уникальности кадастрового номера
- **Дано:** В системе уже существует участок с кадастровым номером "50:20:0000000:100"
- **Когда:** Пользователь пытается создать участок с таким же кадастровым номером
- **Тогда:** Система показывает ошибку "Участок с кадастровым номером 50:20:0000000:100 уже существует"

#### AC-2.4: Валидация формата кадастрового номера
- **Дано:** Пользователь вводит кадастровый номер в неправильном формате
- **Когда:** Пользователь пытается создать участок
- **Тогда:** Система показывает ошибку формата кадастрового номера

### FR-REQ-PLOT-001-03: Редактирование участка

Система должна поддерживать редактирование участка: площадь, адрес, примечание, кадастровый номер (но НЕ номер участка).

#### AC-3.1: Редактирование участка
- **Дано:** Пользователь открыл страницу списка участков и кликнул "Редактировать" на участке
- **Когда:** Пользователь изменил площадь, адрес или примечание
- **Тогда:** Изменения сохраняются и отображаются в списке

#### AC-3.2: Номер участка неизменяем
- **Дано:** Пользователь открыл форму редактирования участка
- **Когда:** Пользователь пытается изменить номер участка
- **Тогда:** Поле номера заблокировано или игнорируется (согласно BR-01)

### FR-REQ-PLOT-001-04: Удаление участка

Система должна поддерживать удаление участка.

#### AC-4.1: Подтверждение удаления
- **Дано:** Пользователь кликнул "Удалить" на участке
- **Когда:** Показывается ConfirmDialog с сообщением "Вы уверены, что хотите удалить участок №X?"
- **Тогда:** Пользователь может подтвердить или отменить удаление

#### AC-4.2: Удаление участка
- **Дано:** Пользователь подтвердил удаление участка
- **Когда:** Подтверждение получено
- **Тогда:** Участок удаляется из системы и списка (оптимистичное обновление)

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-01 | Номер участка не может быть изменён после создания — неизменяемое поле | При обновлении поле plotNumber игнорируется | В сервисе исключается plotNumber из данных обновления |
| BR-02 | Кадастровый номер должен быть уникальным, если указан — проверка при создании и обновлении | Проверка через repository.existsByCadastralNumber | PlotDuplicateError при дубликате |
| BR-03 | Номер участка должен содержать от 2 до 50 символов | Валидация через Zod | PlotInvalidDataError при нарушении |
| BR-04 | Удаление участка необратимо — запись удаляется из системы | DELETE запрос в БД | Реальное удаление из БД |

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Попытка редактирования номера участка | Поле игнорируется (согласно BR-01) |
| 2 | Ошибка сети при загрузке | Показывается сообщение "Ошибка загрузки. Повторить попытку." |
| 3 | Медленная сеть (более 3 секунд) | Показывается индикатор загрузки, данные загружаются асинхронно |
| 4 | Участок уже удалён (404 при удалении) | Ошибка не показывается, диалог закрывается |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации, ролевой доступ (ADMIN, MANAGER)
- **Производительность:** Создание/обновление/удаление < 300ms
- **Доступность:** ARIA-метки для интерактивных элементов
- **Локализация:** Все сообщения на русском языке
