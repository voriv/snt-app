# US-12: Отображение списка участков

## Контекст

**Проблема:** Администраторы и члены СНТ не могут просматривать реестр земельных участков в удобном табличном виде.

**Решение:** Реализовать страницу со списком всех участков с возможностью быстрого поиска и навигации к деталям каждого участка.

**Границы:**
- Включает: отображение списка, сортировку, клик на номер для перехода к деталям
- Исключает: создание, редактирование, удаление участков (отдельные US)

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** просмотреть список всех земельных участков в таблице,
**чтобы** я мог быстро найти нужный участок и ознакомиться с его основными характеристиками.

## Функциональные требования

### FR-REQ-PLOT-001-01: Отображение списка участков в таблице

Система должна отображать список всех земельных участков в табличном виде с колонками: номер, кадастровый номер, площадь, адрес.

#### AC-1.1: Таблица отображает все участки
- **Дано:** Пользователь авторизован и имеет права доступа к списку участков
- **Когда:** Пользователь открывает страницу `/dashboard/plots`
- **Тогда:** Отображается таблица со всеми участками, отсортированными по номеру (по возрастанию)

#### AC-1.2: Таблица содержит обязательные колонки
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Данные успешно загружены
- **Тогда:** Таблица содержит колонки: "Номер", "Кадастровый номер", "Площадь (м²)", "Адрес"

#### AC-1.3: Номер участка кликабелен
- **Дано:** Таблица содержит хотя бы один участок
- **Когда:** Пользователь кликает на номер участка
- **Тогда:** Пользователь перенаправляется на страницу деталей участка `/dashboard/plots/:id`

### FR-REQ-PLOT-001-06: Отображение пустого состояния

Система должна отображать сообщение при отсутствии участков.

#### AC-1.4: Пустой список отображается корректно
- **Дано:** В системе нет участков
- **Когда:** Пользователь открывает страницу `/dashboard/plots`
- **Тогда:** Отображается EmptyState с заголовком "Участки не найдены" и предложением добавить участок

### FR-REQ-PLOT-001-07: Индикатор загрузки

Система должна отображать индикатор загрузки при загрузке данных.

#### AC-1.5: Показывается индикатор загрузки
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Данные загружаются из API
- **Тогда:** Отображается скелетон таблицы или индикатор "Загрузка..."

### FR-REQ-PLOT-001-08: Обработка ошибок

Система должна отображать состояние ошибки с кнопкой "Повторить попытку".

#### AC-1.6: Обработка ошибки сети
- **Дано:** Произошла ошибка при загрузке данных
- **Когда:** Пользователь открыл страницу списка участков
- **Тогда:** Отображается сообщение об ошибке с кнопкой "Повторить попытку"

## Бизнес-правила

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-06 | Список участков сортируется по номеру участка (по возрастанию) по умолчанию | Результаты всегда сортируются по plotNumber ASC | Сортировка на уровне репозитория |

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Участок с пустыми полями (адрес, кадастровый номер) | Отображается прочерк "-" |
| 2 | 0 участков в системе | Показывается EmptyState с предложением добавить участок |
| 3 | Ошибка сети при загрузке | Показывается сообщение "Ошибка загрузки. Повторить попытку." |
| 4 | Медленная сеть (более 3 секунд) | Показывается индикатор загрузки, данные загружаются асинхронно |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации
- **Производительность:** Загрузка списка < 500ms при до 1000 записей
- **Доступность:** Семантическая разметка таблиц, ARIA-метки для интерактивных элементов
- **Локализация:** Все сообщения на русском языке
- **Адаптивность:** Таблица горизонтально прокручивается на мобильных устройствах
