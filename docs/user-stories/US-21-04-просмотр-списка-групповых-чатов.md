# US-21-04: Просмотр списка групповых чатов

> Эпик: Система общения в СНТ (REQ-COMMS-001)

---

## Формулировка

**Как** зарегистрированный пользователь СНТ,
**я хочу** просматривать список групповых чатов, к которым я присоединён,
**чтобы** находить и переходить к нужным обсуждениям.

---

## Целевое состояние

Пользователь откроет страницу `/dashboard/chats` и увидит список групповых чатов в виде карточек. Каждая карточка показывает: название чата, превью последнего сообщения, время последнего сообщения, количество участников, бейдж непрочитанных. Переход по карточке открывает чат.

---

## Контекст

### Проблема

Пользователи не могут просматривать список групповых чатов. Отсутствует обзор чатов, к которым они присоединены.

### Решение

Создать страницу `/dashboard/chats` со списком групповых чатов, загружаемых через `GET /api/v1/chats`. Чаты сортируются по времени последнего сообщения (новые сверху).

### Границы

- **Входит в US:** Отображение списка чатов в виде карточек, превью последнего сообщения, счётчик непрочитанных, поиск по названию чата.
- **Явно исключено:** Создание чата (US-21-05), управление участниками (US-21-07), отправка сообщений (US-21-09).

---

## Функциональные требования

### FR-REQ-COMMS-001-13: Список групповых чатов

Система должна позволять отправлять текстовые сообщения в групповом чате.

#### AC-1.1: Загрузка списка чатов

- **Дано:** Пользователь авторизован
- **Когда:** Пользователь открывает `/dashboard/chats`
- **Тогда:** Список чатов загружается через `GET /api/v1/chats` и отображается в виде карточек

#### AC-1.2: Структура карточки чата

- **Дано:** Чаты успешно загружены
- **Когда:** Карточка рендерится
- **Тогда:** Карточка содержит: название чата, превью последнего сообщения (обрезанное), время последнего сообщения, количество участников, бейдж непрочитанных (если > 0)

#### AC-1.3: Переход к чату

- **Дано:** Пользователь видит список чатов
- **Когда:** Пользователь кликает на карточку
- **Тогда:** Пользователь переходит на страницу чата `/dashboard/chats/:chatId`

#### AC-1.4: Сортировка по времени

- **Дано:** Загружено несколько чатов
- **Когда:** Список рендерится
- **Тогда:** Чаты отсортированы по времени последнего сообщения (новые сверху)

#### AC-1.5: Поиск по чатам

- **Дано:** Пользователь вводит текст в поле поиска
- **Когда:** Введено минимум 2 символа
- **Тогда:** Список фильтруется по названию чата (debounce 300ms, фильтрация на клиенте)

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нет чатов | `EmptyState` с текстом «У вас пока нет чатов» и кнопкой «Создать чат» |
| 2 | Медленная сеть | Индикатор загрузки с текстом «Загрузка чатов...» |
| 3 | Ошибка загрузки | Сообщение об ошибке с кнопкой «Повторить» |

## Нефункциональные требования

- **Безопасность:** Только авторизованные. Чаты видны только участникам.

- **Доступность:** Карточки доступны с клавиатуры. ARIA-метки.
- **Локализация:** Все сообщения на русском языке.
