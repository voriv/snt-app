# US-21-32: Просмотр обсуждения объявления

## Формулировка

**Как** пользователь СНТ,
**я хочу** просматривать обсуждение объявления (чат, связанный с ним),
**чтобы** участвовать в дискуссии по важным вопросам и получать ответы от других членов СНТ.

## Целевое состояние

После реализации пользователь сможет:
- Просматривать сообщения в чате обсуждения любого объявления
- Отправлять сообщения в чат обсуждения (если чат создан)
- Просматривать историю сообщений с пагинацией
- Видеть статус сообщений (прочитано/не прочитано)

### Границы

**Входит:**
- Просмотр списка сообщений в чате обсуждения
- Пагинация сообщений (100 на страницу)
- Автообновление при появлении новых сообщений
- Индикация непрочитанных сообщений

**Не входит:**
- Создание чата обсуждения (создаётся при публикации объявления с опцией "включить обсуждение")
- Ограничение доступа к чату по ролям (открыт для всех авторизованных)
- Закрытие чата при архивации объявления

### FR-REQ-COMMS-021-01: Просмотр чата обсуждения

Пользователь должен иметь возможность просматривать сообщения в чате обсуждения объявления.

#### AC-32.1: Загрузка сообщений
- **Дано:** Пользователь авторизован
- **Дано:** Объявление имеет связанный чат обсуждения (`discussion_id`)
- **Когда:** Пользователь переходит по ссылке на обсуждение объявления
- **Тогда:** Отображается список сообщений с последними сверху

#### AC-32.2: Пагинация
- **Дано:** Чат содержит более 100 сообщений
- **Когда:** Пользователь загружает страницу обсуждения
- **Тогда:** Отображаются только первые 100 сообщений с опцией "Загрузить ещё"

#### AC-32.3: Идентификация отправителя
- **Дано:** Пользователь просматривает сообщения чата
- **Когда:** Отображается сообщение
- **Тогда:** Показывается имя и аватар отправителя

#### AC-32.4: Индикация непрочитанных
- **Дано:** У пользователя есть непрочитанные сообщения в чате
- **Когда:** Отображается список сообщений
- **Тогда:** Непрочитанные сообщения визуально выделяются

### FR-REQ-COMMS-021-02: Отправка сообщения в чат обсуждения

Пользователь должен иметь возможность отправлять сообщения в чат обсуждения объявления.

#### AC-32.5: Форма отправки
- **Дано:** Пользователь на странице обсуждения объявления
- **Когда:** Пользователь вводит текст в поле отправки
- **Тогда:** Появляется кнопка "Отправить"

#### AC-32.6: Отправка сообщения
- **Дано:** Пользователь ввёл текст в поле отправки
- **Когда:** Пользователь нажимает "Отправить"
- **Тогда:** Сообщение добавляется в чат, форма очищается

### FR-REQ-COMMS-021-03: Индикация статуса сообщений

Пользователь должен видеть статус своих сообщений в чате обсуждения.

#### AC-32.7: Статус "отправлено"
- **Дано:** Пользователь отправил сообщение
- **Когда:** Сообщение успешно отправлено на сервер
- **Тогда:** Появляется индикатор "Отправлено"

#### AC-32.8: Статус "прочитано"
- **Дано:** Другие пользователи прочитали сообщение
- **Когда:** Сообщение отображается в чате
- **Тогда:** Появляется индикатор "Прочитано" (галочка)

### FR-REQ-COMMS-021-04: Автосохранение черновика

Пользователь должен иметь возможность продолжить ввод при перезагрузке страницы.

#### AC-32.9: Сохранение черновика
- **Дано:** Пользователь начал вводить сообщение
- **Когда:** Пользователь закрывает страницу или перезагружает
- **Тогда:** Текст сохраняется в localStorage

#### AC-32.10: Восстановление черновика
- **Дано:** Пользователь ранее начинал писать сообщение
- **Когда:** Пользователь возвращается на страницу обсуждения
- **Тогда:** Текст восстанавливается из localStorage

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| **BR-01** | Чат доступен всем авторизованным | Любой авторизованный пользователь может читать и писать в чате | Проверка сессии, нет проверки ролей |
| **BR-02** | Максимальная длина сообщения | 1000 символов для текста | Валидация Zod, max(1000) |
| **BR-03** | Пагинация 100 сообщений | Отображается по 100 сообщений на странице | Проверка параметров пагинации |
| **BR-04** | Индикатор непрочитанных | Отслеживается последнее прочитанное сообщение | Хранение lastReadMessageId в localStorage |
| **BR-05** | Нет ограничений по времени | Можно отправлять сообщения в любое время | Нет временных ограничений |
| **BR-06** | Чат остаётся активным | При архивации/удалении объявления чат не закрывается | Логика сервиса не блокирует доступ |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| **EC-01** | Объявление без чата обсуждения | Кнопка "Обсуждение" скрыта, сообщение "Чат обсуждения не создан" |
| **EC-02** | Нет интернет-соединения | Сообщение "Нет соединения", автосоздание при восстановлении |
| **EC-03** | Чат заблокирован модератором | Сообщение "Чат закрыт для новых сообщений", только чтение |
| **EC-04** | Пользователь заблокирован | Недоступен доступ к странице чата, редирект |
| **EC-05** | Черновик больше 1000 символов | Отображается ошибка валидации, отправка блокируется |
| **EC-06** | Пустое сообщение | Отправка блокируется, индикатор ошибки |
| **EC-07** | Объявление архивировано | Чат остаётся доступным для чтения и записи |
| **EC-08** | Очень старое объявление (> 1 год) | Чат остаётся доступным, предупреждение о возрасте объявления |

## Модель данных

### Текущая схема `chats`

```prisma
model Chat {
  id            String      @id @default(cuid())
  name          String
  description   String?
  creator_id    String
  created_at    DateTime    @default(now())
  updated_at    DateTime    @updatedAt
}

model ChatMessage {
  id          String   @id @default(cuid())
  chat_id     String
  content     String
  sender_id   String
  created_at  DateTime @default(now())
  updated_at  DateTime @updatedAt
  deleted_at  DateTime?
  deleted_by  String?
  read_by     String[]
}
```

### Изменения в модели

```prisma
model Announcement {
  // ... поля выше ...
  
  discussion_id  String?  @map("discussion_id")
  
  @@index([discussion_id])
}

model ChatMessage {
  // ... поля выше ...
  
  read_by  String[]  // IDs пользователей, прочитавших сообщение
}
```

**Обоснование:**
- `discussion_id` связывает объявление с чатом
- `read_by` отслеживает прочитанные сообщения для каждого пользователя

### Конвенции именования

| Поле | Тип | Назначение |
|------|-----|------------|
| `discussion_id` | String? | ID чата обсуждения объявления |
| `read_by` | String[] | Массив ID пользователей, прочитавших сообщение |

## Влияние на слои архитектуры

### Types
- Расширение типа `Announcement` с полем `discussion: Chat?`
- Расширение типа `ChatMessage` с полем `isRead: boolean` (вычисляемое)

### Validators
- Валидация текста сообщения (1-1000 символов)
- Проверка авторизации для отправки

### Errors
- `ChatNotFoundError` — чат обсуждения не найден
- `MessageTooLongError` — сообщение превышает 1000 символов
- `EmptyMessageError` — сообщение не может быть пустым

### Repository
- Метод `findMessagesByChat(chatId: string, limit: number, offset: number): Promise<ChatMessage[]>`
- Метод `markMessagesAsRead(chatId: string, userId: string, messageId: string): Promise<void>`
- Метод `createMessage(chatId: string, content: string, senderId: string): Promise<ChatMessage>`

### Service
- Метод `getChatMessages(chatId: string, userId: string, limit: number, offset: number): Promise<PaginatedResponse<ChatMessage>>`
- Метод `sendMessage(chatId: string, content: string, userId: string): Promise<ChatMessage>`
- Метод `markMessageAsRead(chatId: string, userId: string, messageId: string): Promise<void>`

### DI
- Фабрика `createChatService()` (если не зарегистрирована)

### API
- **GET /api/v1/announcements/:id/discussion/messages**
  - Auth: required
  - Response: 200 `{ success: true, data: { messages: ChatMessage[], total: number, hasMore: boolean } }`
- **POST /api/v1/announcements/:id/discussion/messages**
  - Auth: required
  - Body: `{ content: string }`
  - Response: 200 `{ success: true, data: ChatMessage }`
- **POST /api/v1/chat-messages/:id/read**
  - Auth: required
  - Response: 200 `{ success: true }`

### UI
- **Компоненты:**
  - `DiscussionChat` — основной компонент чата
  - `MessageList` — список сообщений с пагинацией
  - `MessageItem` — отдельное сообщение
  - `MessageInput` — форма отправки
  - `PaginationControls` — пагинация
  - `UnreadIndicator` — индикатор непрочитанных
- **Страница:** `/dashboard/announcements/[id]/discussion`

### Pages
- Страница `/dashboard/announcements/[id]/discussion` — просмотр чата обсуждения

## Нефункциональные требования

- **Производительность:** Загрузка первых 100 сообщений < 500мс
- **Безопасность:** Проверка авторизации на уровне API
- **UX:** Индикатор отправки, автоскролл к последнему сообщению
- **Доступность:** ARIA-метки для кнопок и форм
- **Offline:** Черновик сохраняется в localStorage при потере соединения
