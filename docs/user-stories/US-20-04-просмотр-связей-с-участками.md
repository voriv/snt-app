# US-20-04: Просмотр связей с участками

> Эпик: Управление пользователями (REQ-USERS-001)

---

## Формулировка

**Как** Супер-администратор (SUPER_ADMIN),
**я хочу** просматривать связи пользователя с участками в карточке пользователя,
**чтобы** знать, на каких участках пользователь состоит и в какой роли.

---

## Целевое состояние

После реализации US-20-04 в карточке пользователя `/dashboard/users/[id]` появится новый раздел «Связи с участками», где администратор сможет увидеть таблицу всех участков, с которыми связан пользователь, включая номер участка, кадастровый номер и назначенную роль. Данные отображаются только для просмотра — редактирование связей вынесено в отдельный эпик.

---

## Контекст

### Проблема
Администратор не может видеть, с какими участками связан конкретный пользователь. Информация о связях пользователя с участками хранится в домене `plotUser`, но не агрегируется в карточке пользователя.

### Решение
Добавить в карточку пользователя новый раздел «Связи с участками», данные для которого загружаются через новый API `GET /api/v1/users/[id]/connections`. API использует существующий домен `plotUser` для получения связей.

### Границы
- **Входит в US:** Отображение списка связей пользователя с участками, пустое состояние, навигация к карточке участка.
- **Явно исключено:** Добавление/удаление связей (отдельный эпик), редактирование роли на участке.

---

## Функциональные требования

### FR-REQ-USERS-001-07: Отображение связей с участками

Система должна отображать связи пользователя с участками в карточке пользователя (только просмотр).

#### AC-1.1: Отображение списка связей
- **Дано:** У пользователя есть связи с участками
- **Когда:** Загружается карточка `/dashboard/users/[id]`
- **Тогда:** В разделе «Связи с участками» отображается таблица с номером участка, кадастровым номером и ролью пользователя на участке

#### AC-1.2: У пользователя нет связей с участками (EC-05)
- **Дано:** У пользователя нет связей с участками
- **Когда:** Загружается карточка `/dashboard/users/[id]`
- **Тогда:** В разделе «Связи с участками» отображается сообщение «Связи с участками отсутствуют»

#### AC-1.3: Навигация к карточке участка
- **Дано:** В таблице связей отображается участок
- **Когда:** Пользователь кликает на строку участка
- **Тогда:** Происходит переход на `/dashboard/plots/[plot_id]`

#### AC-1.4: Связи только для просмотра (BR-08)
- **Дано:** Отображается раздел «Связи с участками»
- **Когда:** Пользователь рассматривает раздел
- **Тогда:** Кнопки добавления/удаления/редактирования связей отсутствуют

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | У пользователя нет связей с участками (EC-05) | Раздел «Связи с участками» содержит сообщение «Связи с участками отсутствуют» |

## Нефункциональные требования

- **Безопасность:** Доступ к `GET /api/v1/users/[id]/connections` требует роли SUPER_ADMIN.
- **Производительность:** Загрузка связей: < 300ms.
- **Доступность:** Таблица связей доступна с клавиатуры. Ссылки на участки имеют aria-label.
- **Локализация:** Все сообщения на русском языке.
- **Адаптивность:** Раздел связей корректно отображается на мобильных устройствах.
