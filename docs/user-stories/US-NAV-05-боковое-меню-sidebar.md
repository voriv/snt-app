# US-NAV-05: Боковое меню (sidebar)

---

## Формулировка

**Как** авторизованный пользователь,
**я хочу** видеть боковое меню (sidebar) с навигацией по разделам дашборда,
**чтобы** иметь быстрый доступ ко всем разделам системы с любой страницы.

---

## Контекст

### Проблема
В текущей реализации навигация представлена только top-navbar. На экранах с большим разрешением боковое меню обеспечивает более удобную навигацию и позволяет разместить больше пунктов меню без переполнения верхней панели.

### Решение
Добавить боковое меню (sidebar) слева от основного контента. Sidebar содержит ролевые пункты меню, активное состояние, иконки и подписи. На мобильных устройствах sidebar скрывается (используется гамбургер-меню из US-NAV-07).

### Границы
- **Включает:** Sidebar с ролевыми пунктами меню, иконками, активным состоянием, адаптивным скрытием на мобильных
- **Исключает:** Top-navbar (US-NAV-02), хлебные крошки (US-NAV-06), мобильное меню (US-NAV-07), содержимое страниц

---

## Целевое состояние

После реализации US:

1. Слева от основного контента дашборда отображается **боковое меню (sidebar)**.
2. Sidebar содержит **ролевые пункты меню** — набор пунктов зависит от роли пользователя.
3. Каждый пункт меню содержит **иконку и текстовую подпись**.
4. **Активный пункт** визуально выделен.
5. На **мобильных устройствах** sidebar скрыт (вместо него отображается гамбургер-меню из US-NAV-07).
6. Ширина sidebar — фиксированная (например, 240px) с возможностью коллапса до иконок (опционально).

## Поведение (User Behavior)

### B-1: Навигация через sidebar
Пользователь кликает на пункт «Участки» в sidebar. Происходит клиентский переход на `/dashboard/plots`. Пункт «Участки» подсвечивается как активный.

### B-2: Ролевые пункты
Пользователь с ролью ADMIN видит все пункты: «Участки», «Пользователи», «Документы», «Общение», «Платежи», «Профиль». MEMBER видит только «Участки», «Общение», «Документы», «Профиль». GUEST — минимальный набор.

### B-3: Адаптивное скрытие
Пользователь открывает дашборд на мобильном устройстве (ширина < 768px). Sidebar скрыт. Вместо него отображается иконка гамбургера (в top-navbar), при клике на которую открывается выезжающее меню (US-NAV-07).

## Критерии приёмки

### AC-NAV-05-1: Отображение sidebar на дашборде
- **Given** пользователь авторизован
- **When** страница дашборда загружается на desktop (ширина >= 768px)
- **Then** слева от контента отображается sidebar с пунктами меню

### AC-NAV-05-2: Ролевые пункты меню в sidebar
- **Given** пользователь имеет роль ADMIN
- **When** sidebar рендерится
- **Then** отображаются все пункты меню, доступные для роли ADMIN

### AC-NAV-05-3: Активное состояние пункта
- **Given** пользователь находится на `/dashboard/plots`
- **When** sidebar рендерится
- **Then** пункт «Участки» подсвечен как активный

### AC-NAV-05-4: Иконки у пунктов меню
- **Given** пользователь видит sidebar
- **When** пункты меню отображаются
- **Then** каждый пункт содержит иконку слева от текстовой подписи

### AC-NAV-05-5: Скрытие на мобильных устройствах
- **Given** пользователь открывает дашборд на устройстве с шириной < 768px
- **When** страница загружается
- **Then** sidebar скрыт (не отображается)

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Очень длинное название пункта меню | Текст обрезается (truncate) с многоточием, полное название в `title` |
| 2 | Пользователь без роли | Sidebar отображается с минимальным набором пунктов |
| 3 | Много пунктов меню (более 10) | Sidebar прокручивается (scroll), содержимое не выходит за границы |
| 4 | Collapsed state (опционально) | Sidebar сворачивается до иконок, текст скрыт |
| 5 | Роль изменена во время сессии | Пункты меню обновляются после перезагрузки сессии |

## Нефункциональные требования

- **Производительность:** Sidebar рендерится на клиенте, данные ролей из сессии; без дополнительных API-запросов
- **UX:** Иконки ускоряют визуальный поиск; активное состояние показывает текущий раздел; адаптивное скрытие на мобильных
- **Доступность:** Семантическая разметка (`<nav>`); `aria-current="page"`; навигация с клавиатуры; фокус на первый пункт при открытии
