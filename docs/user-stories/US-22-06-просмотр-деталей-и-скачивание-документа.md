# US-22-06: Просмотр деталей и скачивание документа

> Эпик: Управление документами (REQ-DOCS-001)

---

## Формулировка

**Как** пользователь СНТ,
**я хочу** просматривать детали документа и скачивать его,
**чтобы** ознакомиться с содержимым документа.

---

## Целевое состояние

После реализации пользователь на странице `/dashboard/documents/:id` видит карточку документа с метаданными (название, описание, категория, тип, дата создания, автор, теги, статус). Для PDF и изображений — встроенный предпросмотр. Кнопка «Скачать» позволяет загрузить файл на устройство. Доступ проверяется по роли пользователя (FR-14).

---

## Модель данных

| Сущность | Описание | Ссылка на модель |
|----------|----------|------------------|
| Document | Основной документ | Будет создана |
| DocumentCategory | Категория | Будет создана |
| DocumentTag | Тег | Будет создана |

---

## Поведение (User Behavior)

### B-1: Открытие карточки документа
Пользователь кликает на документ в списке (`/dashboard/documents`). Открывается страница `/dashboard/documents/:id` с метаданными и предпросмотром.

### B-2: Предпросмотр PDF
Для PDF-файлов отображается встроенный предпросмотр (iframe/embed).

### B-3: Предпросмотр изображения
Для изображений (JPG, PNG и др.) отображается встроенный предпросмотр (img tag).

### B-4: Скачивание файла
Пользователь нажимает кнопку «Скачать». Файл загружается на устройство с исходным именем.

### B-5: Отказ в доступе
Пользователь без прав пытается открыть документ. Система возвращает 403 Forbidden.

---

## Критерии приёмки

### AC-1: Отображение метаданных
- **Given** пользователь имеет доступ к документу
- **When** пользователь открывает `/dashboard/documents/:id`
- **Then** отображаются: название, описание, категория, тип, дата создания, автор, теги, статус

### AC-2: Предпросмотр PDF
- **Given** документ — PDF-файл
- **When** пользователь открывает карточку
- **Then** отображается встроенный предпросмотр PDF

### AC-3: Предпросмотр изображения
- **Given** документ — изображение (JPG/PNG)
- **When** пользователь открывает карточку
- **Then** отображается встроенный предпросмотр изображения

### AC-4: Скачивание файла
- **Given** пользователь имеет доступ к документу
- **When** пользователь нажимает «Скачать»
- **Then** файл скачивается с оригинальным именем (originalName)

### AC-5: Проверка доступа (403)
- **Given** документ доступен только ADMIN
- **When** пользователь с ролью MEMBER открывает `/dashboard/documents/:id`
- **Then** система возвращает 403 Forbidden; на клиенте — страница «У вас нет доступа к этому документу»

### AC-6: Черновик не виден не-ADMIN
- **Given** документ в статусе draft
- **When** пользователь с ролью MEMBER открывает `/dashboard/documents/:id`
- **Then** система возвращает 403 Forbidden

### AC-7: Доступ к архивированному документу (только просмотр)
- **Given** документ в статусе archived
- **When** пользователь с соответствующей ролью открывает карточку
- **Then** документ виден; кнопка редактирования скрыта (BR-08)

## Бизнес-правила и валидация

| ID | Правило | Валидация |
|----|---------|-----------|
| BR-04 | Видимость по ролям | Runtime: проверка visibleRoles при каждом запросе (FR-14) |
| BR-07 | Draft не виден не-ADMIN | Runtime: проверка status + role |
| BR-08 | Archived недоступен для редактирования | Runtime: UI — скрытие кнопок редактирования |

### Примеры валидаций
- **Проверка доступа**: middleware/interceptor — `visibleRoles @> [userRole] AND (status != 'draft' OR userRole = 'ADMIN')`

---

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Документ не найден | 404 Not Found |
| 2 | Документ без прав доступа (EC-03) | 403 Forbidden |
| 3 | Файл отсутствует в хранилище (storagePath = null) | Предпросмотр скрыт; кнопка «Скачать» отключена с подсказкой |
| 4 | DOCX-файл (без встроенного предпросмотра) | Метаданные видны; предпросмотр не отображается; кнопка «Скачать» активна |
| 5 | Архивированный документ | Просмотр разрешён; редактирование запрещено |

## Нефункциональные требования

- **Производительность**: загрузка страницы деталей — < 500ms (без скачивания)
- **Безопасность**: проверка доступа на каждом запросе (FR-14); защита от директного доступа к файлам
- **UX**: `EmptyState` при отсутствии доступа; загрузка файла с прогрессом; сообщения на русском
