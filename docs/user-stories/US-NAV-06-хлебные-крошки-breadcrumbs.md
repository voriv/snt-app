# US-NAV-06: Хлебные крошки (breadcrumbs)

---

## Формулировка

**Как** авторизованный пользователь,
**я хочу** видеть хлебные крошки (breadcrumbs) на страницах дашборда,
**чтобы** понимать текущее местоположение в структуре приложения и быстро возвращаться к родительским разделам.

---

## Контекст

### Проблема
При переходе на глубоко вложенные страницы (например, `/dashboard/comms/messages/:conversationId`) пользователь может потерять ориентацию — непонятно, где он находится относительно корня дашборда.

### Решение
Добавить компонент breadcrumbs в верхней части контентной области (под top-navbar, над заголовком страницы). Breadcrumbs автоматически генерируются на основе текущего маршрута.

### Границы
- **Включает:** Компонент breadcrumbs на всех страницах дашборда, авто-генерацию по пути, кликабельные ссылки для родительских уровней, разделитель между уровнями
- **Исключает:** Top-navbar (US-NAV-02), sidebar (US-NAV-05), мобильное меню (US-NAV-07), кастомные breadcrumbs для специфических страниц

---

## Целевое состояние

После реализации US:

1. В верхней части **контентной области** (под top-navbar или sidebar-header) отображается строка **breadcrumbs**.
2. Breadcrumbs **автоматически генерируются** на основе текущего маршрута.
3. Каждый уровень — **кликабельная ссылка** (кроме последнего — текущая страница).
4. Между уровнями отображается **разделитель** (например, `/` или `›`).
5. На **корневых страницах дашборда** (например, `/dashboard/plots`) breadcrumbs показывают только один элемент — текущую страницу (некликабельный).
6. **Максимальная глубина** — 4 уровня (страницы глубже отображаются как последний уровень).

## Поведение (User Behavior)

### B-1: Просмотр breadcrumbs на вложенной странице
Пользователь находится на странице чата: `/dashboard/comms/chats/5`. Breadcrumbs отображают: **Дашборд › Общение › Групповые чаты › Чат #5**. Пользователь может кликнуть на «Групповые чаты», чтобы вернуться к списку чатов.

### B-2: Просмотр breadcrumbs на корневой странице
Пользователь находится на `/dashboard/plots`. Breadcrumbs отображают: **Дашборд › Участки**. Текущий элемент «Участки» не кликабелен.

### B-3: Навигация через breadcrumbs
Пользователь кликает на «Общение» в breadcrumbs. Происходит клиентский переход на `/dashboard/comms`.

## Критерии приёмки

### AC-NAV-06-1: Отображение breadcrumbs на страницах дашборда
- **Given** пользователь находится на странице дашборда (например, `/dashboard/comms/chats/5`)
- **When** страница загружается
- **Then** отображается строка breadcrumbs под top-navbar/sidebar-header

### AC-NAV-06-2: Авто-генерация по пути
- **Given** пользователь на `/dashboard/plots/3/edit`
- **When** breadcrumbs генерируются
- **Then** отображается последовательность: Дашборд › Участки › Участок #3 › Редактирование

### AC-NAV-06-3: Кликабельные ссылки
- **Given** пользователь видит breadcrumbs с уровнями
- **When** пользователь кликает на уровень «Участки»
- **Then** происходит клиентский переход на `/dashboard/plots`

### AC-NAV-06-4: Последний уровень не кликабелен
- **Given** пользователь на странице `/dashboard/plots`
- **When** breadcrumbs отображаются
- **Then** последний элемент «Участки» отображается как текст (не ссылка)

### AC-NAV-06-5: Разделитель между уровнями
- **Given** breadcrumbs отображаются с несколькими уровнями
- **When** элементы рендерятся
- **Then** между уровнями отображается разделитель (например, `›`)

### AC-NAV-06-6: Максимальная глубина
- **Given** маршрут глубже 4 уровней (например, `/dashboard/a/b/c/d/e`)
- **When** breadcrumbs генерируются
- **Then** отображаются первые 3 уровня + последний уровень (глубиной не более 4)

## Бизнес-правила и валидация

| ID | Правило | Валидация |
|----|---------|-----------|
| — | Breadcrumbs генерируются автоматически на основе маршрута | Runtime: функция `generateBreadcrumbs(pathname)` |
| — | Последний элемент не является ссылкой | UI: `<span>` вместо `<Link>` |

---

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Очень длинное название сегмента пути | Название обрезается (truncate) с многоточием |
| 2 | Маршрут глубже 4 уровней | Отображаются только первые 3 уровня + последний |
| 3 | Числовой сегмент (например, ID) | Отображается как «Чат #5» или просто номер |
| 4 | Путь содержит query-параметры | Breadcrumbs игнорируют query-параметры |
| 5 | Breadcrumbs на странице 404 | Не отображаются (404 — не страница дашборда) |

## Нефункциональные требования

- **Производительность:** Генерация breadcrumbs на клиенте без API-запросов; навигация по ссылкам через `next/link`
- **UX:** Понятная навигация; быстрый возврат к родительским разделам; визуально не загромождает страницу
- **Доступность:** Семантическая разметка (`<nav aria-label="Breadcrumb">`); `aria-current="page"` для последнего элемента; навигация с клавиатуры
