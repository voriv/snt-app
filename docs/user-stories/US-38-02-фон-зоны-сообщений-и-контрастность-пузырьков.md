# US-38-02: Фон зоны сообщений и контрастность пузырьков

> Эпик: Система общения в СНТ (REQ-COMMS-001, REQ-COMMS-002)

---

## Формулировка

**Как** зарегистрированный пользователь СНТ,
**я хочу** видеть визуально выделенную зону сообщений с контрастными пузырьками в каждом типе чата,
**чтобы** легко отличать область переписки от остального интерфейса и комфортно читать сообщения.

---

## Целевое состояние

После реализации:

1. **Зона сообщений** на страницах личного диалога и группового чата имеет **собственный фон**, визуально отличающийся от фона страницы и фона заголовка.

2. **Значения фона** определены для каждой темы оформления (Светлая, Тёмная, Зелёная) и автоматически изменяются при переключении темы без перезагрузки страницы.

3. **Пузырьки сообщений:**
   - **Чужие сообщения** контрастируют с фоном зоны сообщений
   - **Свои сообщения** контрастируют с фоном зоны сообщений и сохраняют акцентный цвет

4. **Компонент списка сообщений** (`MessageList`) применяет собственный фон зоны сообщений для обоих типов чатов.

5. **При переключении темы** фон зоны сообщений мгновенно обновляется без перезагрузки страницы.

---

## Контекст

### Проблема

Текущий дизайн не различает фон страницы и фон зоны сообщений — пользователь не чувствует визуальной границы между чатом и остальным интерфейсом. Пузырьки сообщений сливаются с окружением, что затрудняет чтение. При переключении темы оформления фон зоны сообщений не обновляется согласованно.

### Решение

Добавить CSS-переменные для фона зоны сообщений в каждой теме, применить их к компоненту `MessageList` и пузырькам сообщений. Обеспечить реактивное обновление при смене темы через CSS-кастомные свойства (custom properties) или JS-контекст темы.

### Границы

- **Входит в US:** CSS-переменные фона для каждой темы, фон зоны сообщений, контраст пузырьков (своих и чужих), адаптация `MessageList`, обновление при смене темы.
- **Явно исключено:** Изменение структуры страниц (US-38-01), изменение заголовка (US-38-01), пагинация (US-38-01), изменение поведения поля ввода (US-21-03-02/US-21-09), WCAG-аудит контрастности.

## Поведение (User Behavior)

### B-1: Просмотр чата со светлой темой

Пользователь использует светлую тему. Зона сообщений имеет светло-серый фон (например, `#f0f2f5` или аналогичный), отличный от белого фона страницы. Чужие пузырьки — белые на сером фоне. Свои пузырьки — акцентного цвета (например, `#1976d2`) на сером фоне.

### B-2: Переключение на тёмную тему

Пользователь переключает тему на тёмную в настройках профиля. Фон зоны сообщений мгновенно меняется на тёмно-серый (например, `#1e1e1e`), пузырьки перекрашиваются соответственно — чужие становятся тёмно-серыми, свои — акцентного цвета тёмной темы. Страница не перезагружается.

### B-3: Переключение на зелёную тему

Пользователь переключает тему на зелёную. Фон зоны сообщений меняется на соответствующий зелёной теме. Контраст пузырьков сохраняется.

### B-4: Сравнение личного диалога и группового чата

Пользователь открывает сначала личный диалог, затем групповой чат. Фон зоны сообщений идентичен на обеих страницах.

## Критерии приёмки

### AC-1: Фон зоны сообщений отличается от фона страницы

- **Given:** Пользователь на странице личного диалога или группового чата
- **When:** Зона сообщений отображается
- **Then:** Фон зоны сообщений визуально отличается от фона страницы (разница в цвете/оттенке)

### AC-2: Фон определён для каждой темы

- **Given:** Пользователь использует тему «Светлая», «Тёмная» или «Зелёная»
- **When:** Страница чата загружается
- **Then:** Фон зоны сообщений соответствует текущей теме (значение определено в CSS-переменных темы)

| Тема | Фон страницы | Фон зоны сообщений (пример) |
|------|-------------|---------------------------|
| Светлая | Белый `#ffffff` | Светло-серый `#f0f2f5` |
| Тёмная | Тёмный `#121212` | Тёмно-серый `#1e1e1e` |
| Зелёная | Зелёный `#e8f5e9` | Светло-зелёный `#f1f8e9` |

*Конкретные значения утверждаются дизайном.*

### AC-3: Автоматическое обновление при смене темы

- **Given:** Пользователь на странице чата
- **When:** Пользователь переключает тему оформления
- **Then:** Фон зоны сообщений мгновенно обновляется без перезагрузки страницы

### AC-4: Контраст чужих пузырьков

- **Given:** В зоне сообщений отображаются чужие сообщения
- **When:** Сообщение рендерится
- **Then:** Чужой пузырёк визуально контрастирует с фоном зоны сообщений (например, белый пузырёк на светло-сером фоне)

### AC-5: Контраст своих пузырьков

- **Given:** В зоне сообщений отображаются свои сообщения
- **When:** Сообщение рендерится
- **Then:** Свой пузырёк контрастирует с фоном зоны сообщений и имеет акцентный цвет текущей темы

### AC-6: Единый фон для обоих типов чатов

- **Given:** Пользователь открывает личный диалог и групповой чат в одной теме
- **When:** Обе страницы загружены
- **Then:** Фон зоны сообщений идентичен на обеих страницах

### AC-7: Компонент списка сообщений применяет фон

- **Given:** Компонент `MessageList` рендерится
- **When:** Он отображается на странице любого чата
- **Then:** Компонент применяет CSS-класс/переменную для фона зоны сообщений

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Пользователь с кастомной темой (не из стандартных) | Применяется значение фона зоны сообщений для ближайшей стандартной темы или значение по умолчанию |
| 2 | Переключение темы во время загрузки сообщений | Фон обновляется после завершения переключения темы (нет race condition) |
| 3 | Очень длинный список сообщений | Фон применяется ко всей скроллируемой области, а не к каждому пузырьку отдельно |
| 4 | Пустая зона сообщений (нет сообщений) | EmptyState имеет тот же фон зоны сообщений |
| 5 | Быстрое переключение темы (несколько раз подряд) | Фон стабильно обновляется до последнего выбранного значения без мерцания |
| 6 | Заголовок и поле ввода на мобильных устройствах | Только зона сообщений имеет специальный фон; заголовок и поле ввода сохраняют фон страницы |

## Нефункциональные требования

- **Производительность:** Изменение CSS-переменных при переключении темы — не более 16ms (1 frame)
- **Доступность:** Контрастность текста пузырьков с фоном зоны сообщений — не ниже WCAG AA (4.5:1 для обычного текста, 3:1 для крупного)
- **UX:** Плавное изменение фона при переключении темы (CSS transition, 200-300ms)
- **Консистентность:** Оба типа чатов используют одни и те же CSS-переменные
