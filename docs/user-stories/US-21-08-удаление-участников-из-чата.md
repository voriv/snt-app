# US-21-08: Удаление участников из чата

> Эпик: Система общения в СНТ (REQ-COMMS-001)

---

## Формулировка

**Как** создатель чата или администратор,
**я хочу** удалять участников из группового чата,
**чтобы** контролировать состав участников.

---

## Целевое состояние

Пользователь со правами создателя или администратора сможет открыть список участников чата и удалить участника. При удалении пользователь получает уведомление. Создателя чата удалить нельзя.

---

## Контекст

### Проблема

Пользователи не могут удалять участников из существующих чатов. Состав участников не контролируется после создания.

### Решение

Создать страницу управления участниками с возможностью удаления.

### Границы

- **Входит в US:** Удаление участников из чата.
- **Явно исключено:** Блокировка пользователя (US-21-20), удаление чата.

---

## Функциональные требования

### FR-REQ-COMMS-001-09: Удаление участников

Система должна позволять удалять участников из чата.

#### AC-1.1: Проверка прав

- **Дано:** Пользователь открыл `/dashboard/chats/:chatId/participants`
- **Когда:** Страница загружается
- **Тогда:** Если пользователь не создатель или администратор, отображается ошибка 403

#### AC-1.2: Удаление участника

- **Дано:** Пользователь имеет права, участника можно удалить
- **Когда:** Пользователь нажимает «Удалить» на участнике
- **Тогда:** Участник удаляется через `DELETE /api/v1/chats/:chatId/participants/:userId`

#### AC-1.3: Защита создателя

- **Дано:** Пользователь пытается удалить создателя чата
- **Когда:** Нажимается «Удалить»
- **Тогда:** Ошибка «Создателя чата нельзя удалить»

#### AC-1.4: Подтверждение удаления

- **Дано:** Пользователь нажимает «Удалить»
- **Когда:** Открывается ConfirmModal
- **Тогда:** Удаление происходит только после подтверждения

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нет прав на удаление | Кнопка «Удалить» не отображается |
| 2 | Попытка удалить создателя | Кнопка «Удалить» заблокирована, показывается «Создатель» |
| 3 | Удаление себя | Уведомление «Вы покинули чат» с кнопкой «Вернуться к списку чатов» |
| 4 | Ошибка удаления | Ошибка «Не удалось удалить участника» с кнопкой «Повторить» |
