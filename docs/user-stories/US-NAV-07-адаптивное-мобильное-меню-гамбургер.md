# US-NAV-07: Адаптивное мобильное меню (гамбургер)

---

## Формулировка

**Как** пользователь мобильного устройства,
**я хочу** иметь доступ к навигационным пунктам через гамбургер-меню, которое открывается при клике на иконку,
**чтобы** удобно перемещаться по разделам системы на узких экранах.

---

## Контекст

### Проблема
Top-navbar скрывается на мобильных устройствах (`hidden sm:` в Tailwind), но альтернативный способ навигации отсутствует. Пользователи мобильных устройств не могут переключаться между разделами дашборда.

### Решение
Добавить иконку гамбургера (три горизонтальные линии) в top-navbar на мобильных устройствах. При клике на иконку открывается выезжающая панель (drawer) с навигационными пунктами. При клике вне панели или на пункт меню — панель закрывается.

### Границы
- **Включает:** Иконку гамбургера в top-navbar на мобильных, выезжающую панель (drawer) с пунктами меню, закрытие по клику вне панели/по Escape/по клику на пункт, анимацию открытия/закрытия
- **Исключает:** Top-navbar (US-NAV-02), sidebar (US-NAV-05), хлебные крошки (US-NAV-06), desktop-навигацию

---

## Целевое состояние

После реализации US:

1. На **мобильных устройствах** (ширина < 768px) в top-navbar отображается **иконка гамбургера**.
2. При клике на иконку открывается **выезжающая панель (drawer)** слева, содержащая навигационные пункты.
3. Drawer содержит те же **ролевые пункты меню**, что и sidebar/desktop-navbar.
4. Drawer **закрывается** при:
   - Клике на пункт меню (выполняется навигация)
   - Клике вне панели (overlay)
   - Нажатии клавиши Escape
5. Открытие/закрытие сопровождается **плавной анимацией**.
6. При открытии drawer’а **основной контент затемняется** (overlay).
7. **Фокус** перемещается внутрь drawer’а при открытии и возвращается при закрытии.

## Поведение (User Behavior)

### B-1: Открытие мобильного меню
Пользователь на мобильном устройстве (ширина < 768px) открывает дашборд. В top-navbar видна иконка гамбургера. Пользователь кликает на иконку. Слева выезжает панель с навигационными пунктами. Основной контент затемняется (overlay).

### B-2: Навигация через мобильное меню
Пользователь кликает на пункт «Участки» в drawer’е. Drawer закрывается, происходит навигация на `/dashboard/plots`.

### B-3: Закрытие по overlay
Пользователь открыл drawer, но передумал переходить. Кликает на затемнённую область (overlay) справа от drawer’а. Drawer закрывается плавно.

### B-4: Закрытие по Escape
Пользователь открыл drawer. Нажимает клавишу Escape на клавиатуре. Drawer закрывается. Фокус возвращается на иконку гамбургера.

## Критерии приёмки

### AC-NAV-07-1: Отображение гамбургера на мобильных
- **Given** пользователь открывает дашборд на устройстве с шириной < 768px
- **When** top-navbar рендерится
- **Then** отображается иконка гамбургера (три горизонтальные линии)

### AC-NAV-07-2: Открытие drawer
- **Given** пользователь видит иконку гамбургера
- **When** кликает на иконку
- **Then** слева выезжает панель с навигационными пунктами, основной контент затемняется

### AC-NAV-07-3: Закрытие по клику на пункт меню
- **Given** drawer открыт
- **When** пользователь кликает на пункт меню
- **Then** drawer закрывается, происходит навигация на соответствующий маршрут

### AC-NAV-07-4: Закрытие по клику вне drawer
- **Given** drawer открыт
- **When** пользователь кликает на overlay (затемнённую область)
- **Then** drawer закрывается

### AC-NAV-07-5: Закрытие по Escape
- **Given** drawer открыт
- **When** пользователь нажимает клавишу Escape
- **Then** drawer закрывается, фокус возвращается на иконку гамбургера

### AC-NAV-07-6: Плавная анимация
- **Given** drawer открывается или закрывается
- **When** анимация выполняется
- **Then** drawer плавно выезжает/заезжает (например, transition 300ms)

### AC-NAV-07-7: Ролевые пункты
- **Given** drawer открыт
- **When** пункты меню отображаются
- **Then** состав пунктов соответствует роли пользователя (аналогично sidebar)

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Повторный клик на гамбургер при открытом drawer | Drawer закрывается |
| 2 | Медленная анимация — пользователь кликает несколько раз | Обработчик игнорирует клики во время анимации (debounce) |
| 3 | Drawer открыт, произошёл редирект | Drawer закрывается при навигации |
| 4 | Размер экрана меняется с мобильного на desktop при открытом drawer | Drawer автоматически закрывается |
| 5 | Контент drawer’а длиннее экрана | Drawer прокручивается (scroll), заголовок фиксирован |
| 6 | Пользователь использует скринридер | Drawer использует `aria-expanded`, `aria-controls`, `role="dialog"` |
| 7 | Пользователь tab'ом вышел за пределы drawer’а при открытом overlay | Фокус циклически возвращается в drawer (focus trap) |

## Нефункциональные требования

- **Производительность:** Анимация через CSS transitions (GPU-accelerated); lazy-rendering содержимого drawer; debounce на множественные клики
- **UX:** Плавная анимация; затемнение контента фокусирует внимание на меню; закрытие по клику вне/Escape — интуитивно понятно
- **Доступность:**
  - `aria-expanded` на кнопке гамбургера
  - `aria-controls` для связи кнопки с drawer'ом
  - `role="dialog"` на drawer
  - `aria-modal="true"` при открытом drawer
  - Focus trap — циклический фокус внутри drawer
  - Возврат фокуса на кнопку гамбургера при закрытии
