# US-10: Перенаправление с главной страницы для авторизованных

## 1. Контекст

### Проблема
Текущая главная страница (`/`) является публичной landing page. Авторизованные пользователи, заходящие на `/`, видят информацию о системе вместо dashboard. Это создаёт плохой пользовательский опыт.

### Решение
Автоматически перенаправлять авторизованных пользователей с главной страницы (`/`) на dashboard (`/dashboard`) при входе в систему.

### Границы
**Входит в область:**
- Проверка сессии на главной странице
- Перенаправление на `/dashboard` для авторизованных пользователей
- Оставление публичной страницы для неавторизованных
- Использование хука `useSession` для проверки сессии

**Исключено:**
- Изменение dashboard layout
- Изменение middleware
- Кастомные роуты для авторизованных пользователей

---

## 2. Пользовательская история

**Как** авторизованный пользователь,
**я хочу** при посещении главной страницы `/` автоматически перенаправляться на dashboard,
**чтобы** не видеть landing page и сразу получать доступ к функционалу системы.

---

## 3. Функциональные требования

### FR-REQ-AUTH-010-01: Перенаправление на dashboard

Система должна перенаправлять авторизованных пользователей с главной страницы на dashboard.

#### AC-10.1.1: Перенаправление авторизованного пользователя
- **Дано:** Пользователь авторизован (имеет активную сессию)
- **Когда:** Пользователь переходит на главную страницу `/`
- **Тогда:**
  - Происходит автоматическое перенаправление на `/dashboard`
  - Сессия пользователя сохраняется
  - Навигация в browser history не создаёт лишних записей

#### AC-10.1.2: Оставление landing page для неавторизованных
- **Дано:** Пользователь не авторизован
- **Когда:** Пользователь переходит на главную страницу `/`
- **Тогда:**
  - Отображается landing page
  - Кнопка "Войти в систему" доступна
  - Перенаправление не происходит

---

### FR-REQ-AUTH-010-02: Обработка ошибок перенаправления

Система должна корректно обрабатывать ошибки при перенаправлении.

#### AC-10.2.1: Обработка ошибки сети
- **Дано:** Произошла ошибка сети при проверке сессии
- **Когда:** Система пытается определить статус сессии
- **Тогда:**
  - Отображается landing page (fallback поведение)
  - Пользователь может попробовать войти через кнопку

#### AC-10.2.2: Обработка истёкшего токена
- **Дано:** Токен сессии истёк
- **Когда:** Система проверяет сессию
- **Тогда:**
  - Пользователь перенаправляется на `/login` через next-auth callback
  - Или отображается landing page с возможностью входа

## 4. Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-10-01 | Сессия должна быть активной | Перенаправление происходит только при активной сессии | Проверка через `useSession` |
| BR-10-02 | Фолбэк на landing page | При ошибках сессии показывается landing page | Обработка ошибок |
| BR-10-03 | История браузера | Перенаправление не создаёт лишних записей в history | Использование router.replace |

---

## 5. Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нет подключения к интернету | Отображается landing page |
| 2 | Сессия в процессе загрузки | Отображается landing page до завершения загрузки |
| 3 | Токен истёк | Перенаправление на `/login` через next-auth |
| 4 | Пользователь использует кнопки назад/вперёд | Сохраняется корректная навигация |
| 5 | Глубокая вложенность URL (например, `/dashboard?tab=plots`) | Перенаправление только на корневой `/dashboard` |

---

## 6. Нефункциональные требования (NFR)

### Производительность
- **NFR-10-01:** Перенаправление должно происходить менее чем за 200ms после загрузки страницы

### Безопасность
- **NFR-10-02:** Нельзя перенаправлять без проверки сессии
- **NFR-10-03:** Нельзя раскрывать информацию о сессии в публичном коде

### Доступность
- **NFR-10-04:** Перенаправление должно быть обнаруживаемо screen readers
- **NFR-10-05:** Фолбэк (landing page) должен быть доступен для всех пользователей

## 8. Типовая реализация

```typescript
'use client';

import { useEffect } from 'react';
import { useRouter } from 'next/navigation';
import { useSession } from '@/hooks/useSession';

export default function LandingPage() {
  const router = useRouter();
  const { data: session, loading } = useSession();

  useEffect(() => {
    if (!loading && session) {
      router.replace('/dashboard');
    }
  }, [session, loading, router]);

  if (loading) {
    return <div>Загрузка...</div>;
  }

  // Landing page для неавторизованных
  return (
    // ... текущая верстка landing page
  );
}
```
