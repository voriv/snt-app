# US-15: Редактирование участка

## Контекст

**Проблема:** В системе нет возможности изменять данные существующих земельных участков.

**Решение:** Реализовать функциональность редактирования участка с сохранением неизменяемости номера участка.

**Границы:**
- Включает: редактирование площади, адреса, примечания, кадастрового номера
- Исключает: изменение номера участка, создание, удаление (отдельные US)

## Пользовательская история

**Как** Администратор СНТ,
**я хочу** редактировать данные существующего участка,
**чтобы** актуализировать информацию о земельных участках.

## Функциональные требования

### FR-REQ-PLOT-001-03: Редактирование участка

Система должна поддерживать редактирование участка: площадь, адрес, примечание, кадастровый номер (но НЕ номер участка).

#### AC-3.1: Начало редактирования
- **Дано:** Пользователь открыл страницу списка участков
- **Когда:** Пользователь кликнул кнопку "Редактировать" на участке
- **Тогда:** Открывается форма редактирования с предзаполненными данными

#### AC-3.2: Обновление данных участка
- **Дано:** Пользователь открыл форму редактирования участка
- **Когда:** Пользователь изменил площадь, адрес или примечание и сохранил
- **Тогда:** Данные успешно обновляются и отображаются в списке

#### AC-3.3: Номер участка неизменяем
- **Дано:** Пользователь открыл форму редактирования участка
- **Когда:** Пользователь видит номер участка в форме
- **Тогда:** Поле номера заблокировано для изменения (только для чтения)

#### AC-3.4: Валидация при обновлении
- **Дано:** Пользователь вводит невалидные данные (отрицательная площадь, неверный формат кадастра)
- **Когда:** Пользователь пытается сохранить изменения
- **Тогда:** Система показывает сообщение об ошибке валидации

#### AC-3.5: Проверка уникальности кадастрового номера при обновлении
- **Дано:** В системе существует другой участок с кадастровым номером "50:20:0000000:100"
- **Когда:** Пользователь пытается установить этот кадастровый номер для другого участка
- **Тогда:** Система показывает ошибку "Участок с кадастровым номером 50:20:0000000:100 уже существует"

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-01 | Номер участка не может быть изменён после создания | Поле plotNumber не доступно для редактирования | В сервисе исключается из данных обновления |
| BR-02 | Кадастровый номер должен быть уникальным | Проверка через repository.existsByCadastralNumberExcludingId | PlotDuplicateError при дубликате |
| BR-03 | Номер участка должен содержать от 1 до 50 символов | Валидация через Zod | PlotInvalidDataError при нарушении |

## Исключения и Граничные кейсы (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Попытка редактирования номера участка | Поле игнорируется (согласно BR-01) |
| 2 | Участок не найден (404) | Показывается сообщение "Участок не найден" |
| 3 | Дубликат кадастрового номера | Сообщение "Участок с кадастровым номером X уже существует" |

## Нефункциональные требования

- **Безопасность:** Все операции требуют авторизации, ролевой доступ (ADMIN, MANAGER)
- **Производительность:** Обновление < 300ms
- **Доступность:** ARIA-метки для формы редактирования
- **Локализация:** Все сообщения на русском языке
