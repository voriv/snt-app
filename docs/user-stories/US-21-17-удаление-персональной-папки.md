# US-21-17: Удаление персональной папки

## Формулировка
**Как** пользователь системы чатов,
**я хочу** удалять свои персональные папки,
**чтобы** освобождать место в интерфейсе и очищать устаревшие категории.

## Целевое состояние
Пользователь может удалить одну или несколько своих персональных папок. При удалении папки все ассоциированные чаты автоматически перемещаются в папку "Все чаты" (без категории).

### Границы
- Удаление доступно только для собственных папок (не чужих, не системных).
- Пользователь не может удалить системные папки (например, "Входящие", "Отправленные").
- При удалении папки чаты не удаляются — они перемещаются в папку по умолчанию.
- Требуется подтверждение удаления (ConfirmModal) перед выполнением операции.
- Если папка пуста или содержит чаты — удаление выполняется одинаково.

## Функциональные требования

### FR-REQ-COMMS-001-17: Удаление персональной папки

#### AC-17.1: Удаление пустой папки
- **Дано:** Пользователь авторизован и имеет пустую персональную папку.
- **Когда:** Пользователь нажимает кнопку "Удалить", подтверждает в диалоге ConfirmModal.
- **Тогда:**
  - Папка удаляется из базы данных.
  - В списке папок она исчезает.
  - Пользователь видит уведомление "Папка '{name}' удалена".

#### AC-17.2: Удаление папки с чатами
- **Дано:** Пользователь имеет персональную папку с одним или несколькими чатами.
- **Когда:** Пользователь удаляет папку через ConfirmModal.
- **Тогда:**
  - Папка удаляется из базы данных.
  - Все чаты из папки перемещаются в папку "Все чаты" (null folder_id).
  - Пользователь видит уведомление "Папка '{name}' удалена, чаты перемещены во 'Все чаты'".

#### AC-17.3: Подтверждение удаления
- **Дано:** Пользователь пытается удалить папку.
- **Когда:** Система открывает ConfirmModal с вопросом "Вы уверены, что хотите удалить папку '{name}'?".
- **Тогда:**
  - Опция "Отмена" закрывает модальное окно без изменений.
  - Опция "Удалить" вызывает API для удаления папки.
  - При отмене имя папки отображается в тексте вопроса.

### FR-REQ-COMMS-001-18: Защита от удаления системных папок

#### AC-18.1: Блокировка удаления системной папки
- **Дано:** У пользователя есть системная папка (например, "Входящие").
- **Когда:** Пользователь нажимает кнопку "Удалить" на системной папке.
- **Тогда:**
  - Кнопка "Удалить" не отображается (или заблокирована).
  - При прямом API-вызове возвращается ошибка 403 Forbidden.

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-17-01 | Право владельца | Удалять может только владелец папки | Проверка `user_id` перед DELETE |
| BR-17-02 | Защита системных папок | Системные папки не могут быть удалены | Проверка полей `is_system` или reserved names |
| BR-17-03 | Перемещение чатов | Чаты из удаленной папки перемещаются в папку по умолчанию | UPDATE `chat_folders` с `folder_id = NULL` |
| BR-17-04 | Требуется подтверждение | Удаление выполняется только после ConfirmModal | Клиентская проверка перед вызовом API |
| BR-17-05 | Каскадное удаление | Чаты не удаляются, только перемещаются | DELETE из `user_folders`, UPDATE из `chat_folders` |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Быстрое удаление одной папки на двух устройствах | Серверная блокировка или оптимистичное управление состоянием |
| 2 | Отключение сети во время удаления | Обработка таймаута, показ сообщения о проблеме сети |
| 3 | Удаление папки, которая уже была удалена на сервере | API возвращает 404, UI обновляется корректно |
| 4 | Конфликт при одновременном удалении несколькими пользователями | Серверная блокировка, второй запрос получает ошибку |
| 5 | Удаление единственной папки пользователя | Разрешено, пользователь видит только системные папки и "Все чаты" |
| 6 | Попытка удалить папку с 1000+ чатами | Асинхронная операция с индикатором загрузки (опционально) |

## Модель данных

Удаление сущности `user_folders` и перемещение чатов:

```sql
-- DELETE из user_folders
DELETE FROM user_folders WHERE id = ? AND user_id = ?;

-- UPDATE для перемещения чатов
UPDATE chat_folders SET folder_id = NULL WHERE folder_id = ?;
```

## Нефункциональные требования
- **Производительность:** Удаление папки с до 100 чатами < 500мс.
- **Безопасность:** API-эндпоинт проверяет, что `userId` совпадает с сессией.
- **Доступность:**
  - Кнопка удаления имеет `aria-label="Удалить папку"`.
  - ConfirmModal имеет фокус на кнопке "Удалить" по умолчанию.
- **Атомарность:** Операция удаления папки и перемещения чатов должна быть атомарной (transaction).

## Открытые вопросы
1. Нужно ли предусматривать возможность "корзины" для временного восстановления папок? (Решение: Нет, в рамках US-21-17 не требуется — физическое удаление).
2. Как обрабатывать удаление папок с тысячами чатов — асинхронно или синхронно? (Решение: Синхронно, с индикатором загрузки; при >1000 чатов — асинхронно, но это отдельная оптимизация).
3. Нужна ли поддержка массового удаления папок (выбор нескольких и удаление одним кликом)? (Решение: Нет, в рамках US-21-17 — только удаление одной папки).
