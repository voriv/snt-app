# US-21-05: Создание группового чата

> Эпик: Система общения в СНТ (REQ-COMMS-001)

---

## Формулировка

**Как** зарегистрированный пользователь СНТ,
**я хочу** создавать групповые чаты и добавлять участников,
**чтобы** организовать обсуждение с другими пользователями.

---

## Целевое состояние

Пользователь откроет форму создания чата с полем названия, описанием и выбором участников из списка пользователей. После создания чат будет доступен всем выбранным участникам и отображаться в списке чатов.

---

## Контекст

### Проблема

Пользователи не могут создавать групповые чаты. Отсутствует механизм организации групповых обсуждений.

### Решение

Создать страницу `/dashboard/chats/new` с формой создания чата: название, описание, выбор участников (минимум 2).

### Границы

- **Входит в US:** Создание чата с названием, описанием и участниками.
- **Явно исключено:** Редактирование чата (US-21-06), удаление чата (US-21-08), управление категориями (US-21-11..US-21-14).

---

## Функциональные требования

### FR-REQ-COMMS-001-08: Создание чата

Система должна позволять администраторам создавать тематические чаты.

#### AC-1.1: Открытие формы создания

- **Дано:** Пользователь авторизован и находится на `/dashboard/chats`
- **Когда:** Пользователь нажимает кнопку «Создать чат»
- **Тогда:** Пользователь переходит на `/dashboard/chats/new` с формой создания

#### AC-1.2: Название чата

- **Дано:** Пользователь в форме создания чата
- **Когда:** Пользователь вводит название
- **Тогда:** Название обязательно, минимум 2, максимум 100 символов

#### AC-1.3: Описание чата

- **Дано:** Пользователь в форме создания чата
- **Когда:** Пользователь вводит описание
- **Тогда:** Описание опционально, максимум 500 символов

#### AC-1.4: Выбор участников

- **Дано:** Пользователь в форме создания чата
- **Когда:** Пользователь выбирает участников из списка
- **Тогда:** Минимум 2 участника (включая себя), максимум 50 участников

#### AC-1.5: Создание чата

- **Дано:** Форма заполнена корректно
- **Когда:** Пользователь нажимает «Создать»
- **Тогда:** Чат создаётся через `POST /api/v1/chats` и пользователь переходит к новому чату `/dashboard/chats/:chatId`

#### AC-1.6: Создание своего имени в чате

- **Дано:** Пользователь создаёт чат
- **Когда:** Чат создан
- **Тогда:** Пользователь получает имя «Создатель» в списке участников и права администратора чата

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Выбраны заблокированные пользователи | Они не показываются в списке участников |
| 2 | Дублирование названия | Ошибка «Чат с таким названием уже существует» |
| 3 | Выбрано < 2 участников | Кнопка «Создать» заблокирована |
| 4 | Выбрано > 50 участников | Кнопка выбора заблокирована, показывается ошибка |
