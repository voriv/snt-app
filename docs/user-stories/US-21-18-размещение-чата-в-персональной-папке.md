# US-21-18: Размещение чата в персональной папке

## Формулировка
**Как** пользователь системы чатов,
**я хочу** назначать папки для своих чатов,
**чтобы** структурировать переписку и быстро находить диалоги по категориям.

## Целевое состояние
Пользователь может выбрать одну из своих персональных папок для конкретного чата. Чат отображается в выбранной папке и в фильтре по папкам.

### Границы
- Назначение папки доступно только для персональных чатов (диалогов).
- Системные чаты (например, "Общие объявления") нельзя перемещать в персональные папки.
- Один чат может принадлежать только одной папке одновременно.
- Папка должна быть создана пользователем (не может быть назначена несуществующая или чужая папка).
- Для групповых чатов может быть другое правило назначения папок (не рассматривается в этой истории).

## Функциональные требования

### FR-REQ-COMMS-001-18: Назначение папки для чата

#### AC-18.1: Перемещение чата в папку
- **Дано:** Пользователь авторизован и имеет созданные папки.
- **Когда:** Пользователь открывает меню управления чатом, выбирает "Переместить в папку", выбирает папку из списка и подтверждает.
- **Тогда:**
  - Чат перемещается в выбранную папку.
  - В списке чатов чат отображается только при фильтре по этой папке.
  - Пользователь видит уведомление "Чат перемещен в папку '{name}'".

#### AC-18.2: Перемещение чата в "Все чаты" (без папки)
- **Дано:** Пользователь имеет чат, назначенный в персональную папку.
- **Когда:** Пользователь выбирает опцию "Удалить из папки" или "Переместить во 'Все чаты'".
- **Тогда:**
  - Чат перемещается в папку по умолчанию (null folder_id).
  - Чат отображается в общем списке всех чатов.
  - Пользователь видит уведомление "Чат перемещен во 'Все чаты'".

#### AC-18.3: Список доступных папок
- **Дано:** Пользователь имеет созданные персональные папки.
- **Когда:** Пользователь открывает меню "Переместить в папку".
- **Тогда:**
  - Отображается список всех персональных папок пользователя.
  - Текущая папка чата отмечена как активная.
  - Папка "Все чаты" доступна для удаления из категории.

### FR-REQ-COMMS-001-19: Валидация назначения папки

#### AC-19.1: Проверка прав доступа
- **Дано:** Пользователь пытается назначить чат чужой папке.
- **Когда:** Отправляется запрос с `folder_id`, который принадлежит другому пользователю.
- **Тогда:**
  - API возвращает ошибку 403 Forbidden.
  - Пользователь видит сообщение "Недостаточно прав для этой операции".

#### AC-19.2: Проверка существования папки
- **Дано:** Пользователь пытается назначить чат несуществующей папке.
- **Когда:** Отправляется запрос с некорректным `folder_id`.
- **Тогда:**
  - API возвращает ошибку 404 Not Found.
  - Пользователь видит сообщение "Папка не найдена".

#### AC-19.3: Защита системных чатов
- **Дано:** Пользователь имеет системный чат (например, "Общие объявления").
- **Когда:** Пользователь пытается переместить чат в персональную папку.
- **Тогда:**
  - Операция запрещена, возвращается 403 Forbidden.
  - В UI кнопка "Переместить" скрыта или заблокирована.

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-18-01 | Право владельца чата | Перемещать может только владелец чата | Проверка `user_id` в контексте чата |
| BR-18-02 | Уникальность папки | Один чат может принадлежать только одной папке | UPDATE `chat_folders` с одним `folder_id` |
| BR-18-03 | Проверка папки | Назначенная папка должна существовать и принадлежать пользователю | `SELECT` с проверкой `user_id` и `id` |
| BR-18-04 | Защита системных чатов | Системные чаты нельзя перемещать | Проверка поля `is_system` или `type` |
| BR-18-05 | Атомарность операции | Перемещение чата должно быть атомарным | Использование транзакции при необходимости |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Чат был переименован во время перемещения | Операция выполняется успешно, чат перемещается с новым именем |
| 2 | Папка была удалена во время перемещения чата | Чат перемещается в "Все чаты", система предупреждает пользователя |
| 3 | Одновременное перемещение чата двумя устройствами | Серверная блокировка, второй запрос получает ошибку |
| 4 | Отключение сети во время перемещения | Обработка таймаута, показ сообщения о проблеме сети |
| 5 | Перемещение чата в папку, которую затем удалили | Чат автоматически перемещается в "Все чаты" |
| 6 | Перемещение группового чата в персональную папку | Операция запрещена, возвращается 403 |

## Модель данных

Изменение модели `chat_folders` (или таблицы чатов) для хранения ссылки на папку:

```prisma
model ChatFolder {
  id        String   @id @default(cuid())
  chatId    String   @map("chat_id")
  folderId  String?  @map("folder_id") // NULL = "Все чаты"
  userId    String   @map("user_id")
  
  @@unique([chatId, folderId]) // Один чат в одной папке
  @@index([userId])
  @@index([folderId])
}
```

## Нефункциональные требования
- **Производительность:** Перемещение чата < 200мс.
- **Безопасность:** API-эндпоинт проверяет, что `userId` совпадает с сессией.
- **Доступность:**
  - Меню перемещения имеет `aria-label="Переместить чат в папку"`.
  - Список папок доступен с клавиатуры (стрелки, Enter).
- **Анимация:** Плавное перемещение чата в интерфейс (при использовании WebSocket или опционально).

## Открытые вопросы
1. Нужна ли поддержка массового перемещения нескольких чатов? (Решение: Нет, в рамках US-21-18 — только один чат за раз).
2. Требуется ли история перемещений чата между папками? (Решение: Нет, в рамках US-21-18 не требуется).
3. Как обрабатывать перемещение чата, когда папка была удалена — автоматически в "Все чаты"? (Решение: Да, при загрузке чатов с несуществующей папкой — автоматически в null).
4. Нужно ли поддерживать несколько папок для одного чата? (Решение: Нет, один чат — одна папка).
