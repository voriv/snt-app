# US-21-28: Создание объявления

## Формулировка
**Как** модератор или администратор СНТ,
**я хочу** создавать новые объявления,
**чтобы** информировать участников сообщества о важных событиях, изменениях и новостях.

## Целевое состояние
Модератор создает черновик нового объявления с заголовком и содержанием. Объячение сохраняется как черновик и не публикуется автоматически.

### Границы
- Создавать объявления могут только модераторы и администраторы.
- Объявление создается как черновик (не публикуется автоматически).
- Заголовок обязателен, содержание может быть опциональным (но рекомендуется).
- Максимальная длина заголовка: 200 символов.
- Максимальная длина содержания: 5000 символов.

## Функциональные требования

### FR-REQ-COMMS-001-28: Создание объявления

#### AC-28.1: Создание объявления с заголовком и содержанием
- **Дано:** Модератор авторизован и имеет права на создание объявлений.
- **Когда:** Модератор заполняет форму заголовка и содержания, нажимает "Сохранить как черновик".
- **Тогда:**
  - Объячение создается с статусом "Draft".
  - Объявление не публикуется (недоступно пользователям).
  - Модератор получает уведомление "Объявление сохранено как черновик".
  - Объявление появляется в списке черновиков автора.

#### AC-28.2: Валидация заголовка
- **Дано:** Модератор пытается создать объявление.
- **Когда:** Модератор вводит:
  - Пустой заголовок.
  - Заголовок >200 символов.
- **Тогда:**
  - Система отображает сообщение об ошибке валидации.
  - Объявление не создается.
  - Фокус остается в поле заголовка.

#### AC-28.3: Валидация содержания
- **Дано:** Модератор пытается создать объявление.
- **Когда:** Модератор вводит содержание >5000 символов.
- **Тогда:**
  - Система отображает сообщение о превышении лимита символов.
  - Объявление не создается.
  - Поле содержания подсвечивается красным.

#### AC-28.4: Сохранение как черновик
- **Дано:** Модератор заполнил форму объявления.
- **Когда:** Модератор нажимает "Сохранить как черновик".
- **Тогда:**
  - Объявление сохраняется в статусе "Draft".
  - Объявление доступно только автору и модераторам для редактирования.
  - Опция "Опубликовать" доступна для дальнейшего использования.

## Бизнес-правила и валидация

| ID | Правило | Описание | Валидация |
|----|---------|----------|-----------|
| BR-28-01 | Право создания | Создавать могут только модератор/администратор. | Проверка роли в API. |
| BR-28-02 | Заголовок обязателен | Объявление не может быть создано без заголовка. | Валидация `title` как обязательного поля. |
| BR-28-03 | Лимит заголовка | Максимальная длина заголовка — 200 символов. | `string.max(200)` в валидаторе. |
| BR-28-04 | Лимит содержания | Максимальная длина содержания — 5000 символов. | `string.max(5000)` в валидаторе. |
| BR-28-05 | Статус по умолчанию | Новое объячение создается в статусе "Draft". | `status = 'draft'` по умолчанию. |

## Граничные случаи (Edge Cases)

| # | Ситуация | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Создание объявления без содержания | Объявление создается, но предупреждается "Содержание опционально". |
| 2 | Создание объявления с special characters | Special characters поддерживаются (HTML-теги, эмодзи). |
| 3 | Создание объявления во время сетевой ошибки | Объяжение не сохраняется, пользователь получает ошибку. |
| 4 | Дублирование заголовка | Дублирование разрешено (каждое объявление уникально по ID). |
| 5 | Создание объявления с очень длинным содержанием | Поле содержания имеет счетчик символов с визуальной обратной связью. |
| 6 | Создание объявления модератором, который вышел из системы | Операция отклоняется, требуется повторная авторизация. |

## Модель данных
Добавление/обновление таблицы `announcements` для поддержки черновиков.

**Таблица: `announcements`**
```prisma
model Announcement {
  id           String   @id @default(cuid())
  title        String   @map("title") @size(200)
  content      String?  @map("content") @size(5000)
  authorId     String   @map("author_id")
  status       String   @default("draft") // draft, published, archived
  publishedAt  DateTime? @map("published_at")
  archivedAt   DateTime? @map("archived_at")
  isImportant  Boolean  @default(false) @map("is_important")
  viewCount    Int      @default(0) @map("view_count")
  createdAt    DateTime @default(now()) @map("created_at")
  updatedAt    DateTime @updatedAt @map("updated_at")

  @@index([authorId])
  @@index([status])
  @@index([publishedAt])
}
```
