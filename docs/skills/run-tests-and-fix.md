# Skill: Запуск тестов и исправление (Run Tests and Fix)

> **Исполнитель:** `debug` mode
> **Вход:** `src/`, `tests/`
> **Выход:** Исправленный код в `src/` и `tests/`

---

## Алгоритм

1. **Запустить тесты:** `npm test`
2. **Если все зелёные** — сообщи и заверши
3. **Если есть падения:**
   - Прочитай логи ошибок
   - Найди корневую причину
   - Исправь в `src/` или `tests/`
   - Перезапусти тесты
   - Повторяй пока все не пройдут
4. **Если ошибка архитектурная** — предложи вернуться к planner
5. **Составить отчёт** — какие ошибки были, как исправлены
6. **Запросить approve**

## Правила

- Исправляй только то, что сломано — не добавляй новый функционал
- Минимальные изменения — точечные фиксы
- После фикса — убедись, что старые тесты тоже проходят
