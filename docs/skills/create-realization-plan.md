# Skill: Создание плана реализации (Create Realization Plan)

> **Исполнитель:** `planner` mode
> **Вход:** `docs/user-stories/US-{NN}-{slug}.md`, `docs/model/entities/*.md`
> **Выход:** `docs/plans/{US-id}-realization-plan.md`

---

## Алгоритм

1. **Прочитать US** — открой User Story
2. **Прочитать модель** — изучи связанные сущности
3. **Создать план** — по шаблону [`docs/templates/us-realization-plan.md`](docs/templates/us-realization-plan.md)
4. **Заполнить секции:**
   - Метаданные (ID, название, версия, зависимости)
   - Ссылки на US, REQ, модель
   - Дерево файлов (что будет создано/изменено)
   - Задачи по слоям (типы → валидаторы → ошибки → репозиторий → сервис → API → UI)
   - Чеклист проверки
5. **Запросить approve**

## Правила

- Каждая задача должна начинаться с `[TODO]`
- Ссылайся на конкретные строки существующего кода при изменениях
- Если план > 20 задач — предложи разбить на этапы
