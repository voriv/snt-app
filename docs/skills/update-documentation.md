# Skill: Обновление документации (Update Documentation)

> **Исполнитель:** `tech-writer` mode
> **Вход:** Все артефакты (REQ, US, код)
> **Выход:** Обновлённый `README.md`, обновления в `docs/`

---

## Алгоритм

1. **Прочитать изменения** — изучи что было реализовано (REQ, US, код)
2. **Прочитать README.md** — пойми текущую структуру и стиль
3. **Обновить README.md:**
   - Добавь новые функции в описание
   - Обнови навигацию по проекту
   - Обнови API-документацию если нужно
   - Обнови структуру директорий
4. **Обновить связанные docs/ файлы** при необходимости
5. **Запросить approve**

## Правила

- Только .md файлы
- Сохраняй существующий стиль и тон
- Не изменяй код или тесты
- Обнови дату последнего обновления
