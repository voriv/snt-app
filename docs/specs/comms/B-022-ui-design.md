|---|:----:|:------:|-----------|

## 2. Обзор дизайн-решений

| # | R-ID | Дизайн-решение | Визуальный эффект | Элемент макета |

## 3. Блок 1 (R-18 / T1): Единый размер аватара `ConversationCard`

### 3.1 Назначение

Устранить неравномерную высоту аватара: `img` и fallback `div` в `[ConversationCard]` были `h-12 w-12` (48px), тогда как остальные аватары COMMS — `h-10 w-10` (40px).

### 3.2 Дизайн-решение (токенизация)

| Элемент аватара | Было (класс) | Стало (класс) | Токен |
|-----------------|--------------|---------------|-------|
| Аватар-картинка (`img`) | `h-12 w-12` | `h-10 w-10` | `space-10` (40px) |
| Fallback-блок (инициал) | `h-12 w-12` | `h-10 w-10` | `space-10` (40px) |
| Радиус аватара | `rounded-full` | `rounded-full` (неизменно) | `radius`·full |

> **Правило:** аватар всегда квадрат `h-10 w-10` + `rounded-full`, скругление централизованное (radius-full). Цвет фона fallback — `color.bg.secondary`, цвет инициала — `color.text.primary` (наследование от существующего вида, не менять).

### 3.3 ASCII-эскиз (аватар 40px)

```ascii
БЫЛО (48px, R-18):                    СТАЛО (40px, единый стандарт):
┌──────┐  ┌──────┐                    ┌────┐  ┌────┐
│      │  │  И   │  48×48            │    │  │  И │  40×40
│  img │  │      │                    │img │  │    │
└──────┘  └──────┘                    └────┘  └────┘

            [ConversationCard] ←→ [MessageItem]
             h-10 w-10       ==       w-10 h-10
```

## 4. Блок 2 (R-21 / T2): Перенос ChatList + ChatCard

### 4.1 Назначение

Привести расположение COMMS-компонентов к единому стандарту: все компоненты поддомена общения должны находиться в `features/comms/`, а не быть разбросанными в `features/chats/`.

### 4.2 Дизайн-решение

| Компонент | Было | Стало |
|-----------|------|-------|
| `[ChatList]` | `src/components/features/chats/ChatList/` | `src/components/features/comms/ChatList/` |
| `[ChatCard]` | `src/components/features/chats/ChatCard/` | `src/components/features/comms/ChatCard/` |
| Старая директория `features/chats/` | — | Удаляется |

> **ВАЖНО:** это **чисто структурная** правка. **Визуальный вид карточек чата не изменяется ни на пиксель.** Все классы, токены, layout-порядок `[ChatCard]`/`[ChatList]` остаются прежними — меняется только путь импорта. Никаких дизайн-решений по внешнему виду здесь не принимается.

### 4.3 Визуальный эффект

- **Ноль.** Единственное observable изменение — корректная работа импортов после переезда (продакшн + тестовые `vi.mock`). Для пользователя ничего не меняется.

### 4.4 ASCII-эскиз (консистентность пространства)

```ascii
features/comms/                         features/chats/
├── ChatList/  (🆕 перенесено)          ├── ChatList/   (🗑️ удалено)
├── ChatCard/  (🆕 перенесено)          └── ChatCard/   (🗑️ удалено)
├── ConversationCard/
├── MessageItem/
└── ... остальные COMMS-компоненты

Видимый результат для пользователя: БЕЗ ИЗМЕНЕНИЙ.
```

## 5. Блок 3 (R-24 / T3): Отказ от визуального акцента isLastMessage

### 5.1 Назначение

Убрать яркое фоновое выделение последнего сообщения в диалоге (`bg-[var(--theme-info)]/10`), которое отвлекало и создавало лишний визуальный шум.

### 5.2 Дизайн-решение

| Было (класс) | Стало (класс) | Эффект |
|--------------|---------------|--------|
| `bg-[var(--theme-info)]/10 -mx-2 px-2 py-1 rounded-lg` | *(удалено из `cn()`)* | No фонового акцента |
| — | `animate-fade-in` (остаётся) | Плавное появление сообщения |

> **Правило:** последнее сообщение не должно визуально отличаться по фону или цвету от остальных. Единственное допустимое поведение — мягкое появление через `animate-fade-in`. Проп `isLastMessage` остаётся в интерфейсе компонента (используется как scroll-якорь), но **перестаёт влиять на стили пузырька**.

### 5.3 ASCII-эскиз

```ascii
БЫЛО (с акцентом isLastMessage):        СТАЛО (нейтрально):
  ┌──────────────┐                        ┌──────────────┐
  │ сообщение 1  │                        │ сообщение 1  │
  └──────────────┘                        └──────────────┘
  ┌──────────────┐   ←── акцент           ┌──────────────┐
  │█████████████ │   bg-info/10           │ последнее    │  ←── только
  └──────────────┘   (выделено)           └──────────────┘  animate-fade-in
```

## 6. Блок 4 (R-28 / T4): Состояние «чат не найден» в edit-странице

### 6.1 Назначение

Ранее при отсутствии чата страница показывала только `<p>Чат не найден</p>` — без заголовка и возможности вернуться. Требуется полноценный fallback-экран, согласованный с существующим блоком `loadError`.

### 6.2 Дизайн-решение

Fallback-экран строится из трёх элементов:

| Элемент | Компонент | Токен/класс | Поведение |
|---------|-----------|-------------|-----------|
| Кнопка «Назад» | `[Button]` → `variant="ghost"` | `size`·md, `color.text.primary`, hover `color.bg.secondary` | `router.push('/dashboard/comms/chats')` |
| Заголовок | `[PageHeading]` h1 | `text.heading-2` (2xl bold), `color.text.primary` | «Редактирование чата» |
| Сообщение об ошибке | `[ErrorMessage]` | `color.danger` (bg opacity-10 + text), `radius-sm`, `p-3×4`, `role="alert"` | `message="Чат не найден"` |

**Компоновка контейнера** (единый шаблон страницы):

| Область | Класс | Токен |
|---------|-------|-------|
| Контейнер | `max-w-2xl mx-auto px-4 sm:px-6 lg:px-8 py-8` | `space-8` (py), `space-4/6/8` (px) |
| Шапка | `flex items-center gap-4 mb-6` | `space-4` (gap), `space-6` (mb) |

### 6.3 ASCII-эскиз (состояние «чат не найден»)

```ascii
┌───────────────────────────────────────────────────────────┐
│  ←  [Button ghost]          Редактирование чата          │  ← h1 heading-2
│     <Назад>                 (заголовок)                  │
│                                                           │
│  ┌─────────────────────────────────────────────────┐     │
│  │ ⚠  Чат не найден                                 │     │  ← [ErrorMessage]
│  │    color.danger bg/10 + text-danger              │     │     role=alert
│  └─────────────────────────────────────────────────┘     │
└───────────────────────────────────────────────────────────┘
```

> Согласовано с блоком `loadError` (строки 167–197 в `edit/page.tsx`): та же шапка с кнопкой «Назад» + заголовок, тот же тип `[ErrorMessage]`. Отличие — текст «Чат не найден».

## 7. Блок 5 (R-29 / T5): Иконка-стрелка и hover в ConversationCard

### 7.1 Назначение

Добавить явный визуальный CTA (направление перехода) на карточку диалога и оживить hover-отклик.

### 7.2 Дизайн-решение

| Элемент | Класс | Токен | Поведение |
|---------|-------|-------|-----------|
| Корень карточки | `group` (добавить) | — | Обеспечивает `group-hover:*` |
| Контейнер стрелки | `flex-shrink-0` | `space-0` | Не сжимается при длинном превью |
| SVG `chevron-right` | `h-4 w-4 text-[var(--theme-text-secondary)] transition-transform group-hover:translate-x-0.5` | `space-4` (h/w), `color.text.secondary`, `space-0.5` (сдвиг) | Сдвиг вправо на hover |
| Hover карточки (существующий) | `hover:bg-[var(--theme-bg-secondary)]` | `color.bg.secondary` | Не меняется, дополняется сдвигом стрелки |

**Характеристика стрелки:**
- размер `h-4 w-4` (16px, `space-4`);
- цвет `color.text.secondary` (`var(--theme-text-secondary)`) — ненавязчивый индикатор;
- `fill="none" stroke="currentColor" strokeWidth={1.5}`, контурный path `M8.25 4.5l7.5 7.5-7.5 7.5`;
- `transition-transform` + `group-hover:translate-x-0.5` (сдвиг 2px вправо при наведении на карточку).

### 7.3 ASCII-эскиз (карточка диалога со стрелкой)

```ascii
БЫЛО (без CTA):                          СТАЛО (со стрелкой + hover):
┌────────────────────────────────────┐   ┌─────────────────────────────────────┐
│ ┌──┐  Имя чата        │            │   │ ┌──┐  Имя чата              ▸ │    │
│ └──┘  последнее сообщ│            │   │ └──┘  последнее сообщение      │    │
└────────────────────────────────────┘   └─────────────────────────────────────┘
   hover: только смена фона                hover: смена фона + стрелка ▸ → ▸ (сдвиг 2px)

    [ConversationCard] = group
    └── chevron-right: h-4 w-4, color.text.secondary, flex-shrink-0
        transition-transform group-hover:translate-x-0.5
```

## 8. Чек-листы визуальной проверки (3 темы)

> Тема переключается через профиль (`/dashboard/settings`): Light, Dark, Green. Проверять каждый экран в каждой теме. Переход к экранам COMMS: `/dashboard/comms/chats`, `/dashboard/comms/chats/[chatId]`, `/dashboard/comms/chats/[chatId]/edit`.

### 8.1 Аватар карточки диалога (R-18 / T1)

- [ ] Аватар в `[ConversationCard]` = 40×40 px (а не 48) во всех 3 темах.
- [ ] Аватар карточки диалога совпадает по размеру с аватаром `[MessageItem]` (оба 40px).
- [ ] И `img`, и fallback-блок с инициалом имеют одинаковый размер 40×40.
- [ ] Аватар остаётся круглым (`rounded-full`) и не «плющится» в Green-теме.
- [ ] Нет перекрытия/обрезки аватара при длинном имени чата.

### 8.2 Перенос ChatList/ChatCard (R-21 / T2)

- [ ] Список чатов на `/dashboard/comms/chats` выглядит **идентично** до и после переноса (нет регрессии layout).
- [ ] `[ChatCard]` — те же отступы, радиус, hover, цвета во всех 3 темах.
- [ ] Нет `import` из `@/components/features/chats/` в продакшн-коде (grep по `src/` → 0).
- [ ] Тесты страниц COMMS проходят после обновления `vi.mock` (re-export не сломан).

### 8.3 Отсутствие акцента isLastMessage (R-24 / T3)

- [ ] Последнее сообщение в диалоге **не** выделено фоном/цветом во всех 3 темах.
- [ ] Последнее сообщение не имеет фоновых «подушек» (`px/py`/`rounded`), которых нет у остальных.
- [ ] Сообщение плавно появляется через `animate-fade-in` (aнимация не сломана).
- [ ] Никакие другие сообщения не получили нежелательного выделения.

### 8.4 Состояние «чат не найден» (R-28 / T4)

- [ ] Переход по несуществующему/недоступному chatId на edit-страницу показывает fallback-экран.
- [ ] Присутствует заголовок «Редактирование чата» (`heading-2`) во всех 3 темах.
- [ ] Присутствует кнопка «Назад» (→ `/dashboard/comms/chats`), кликабельна, видима во всех темах.
- [ ] Присутствует `[ErrorMessage]` с текстом «Чат не найден» (danger-стиль, `role="alert"`).
- [ ] Кнопка «Назад» работает: возвращает на список чатов.
- [ ] Layout fallback-экрана согласован с блоком `loadError` (та же шапка/заголовок).

### 8.5 Иконка-стрелка и hover (R-29 / T5)

- [ ] На карточке диалога присутствует иконка `chevron-right` слева направо справа от контента.
- [ ] Стрелка имеет цвет `color.text.secondary` и не перекрывается при длинном превью (`flex-shrink-0`).
- [ ] При наведении на карточку стрелка сдвигается вправо на 2px (`group-hover:translate-x-0.5`).
- [ ] Hover-смена фона карточки (`color.bg.secondary`) по-прежнему работает в 3 темах.
- [ ] Иконка не искажается (пропорции `h-4 w-4`) и не «вылезает» из границ карточки.
- [ ] Сдвиг стрелки заметен, но не дёргается (smooth `transition-transform`).

### 8.6 Регрессия 3 тем (общая)

- [ ] Переключение Light/Dark/Green не «прыгает» и не ломает layout на изменённых экранах.
- [ ] Нет белых/нечитаемых областей в тёмных темах (Dark/Green).
- [ ] Навигация по карточке диалога работает (переход в беседу).
- [ ] Бизнес-логика не изменена: сообщения, чаты, редактирование отображаются корректно.

## 10. Ограничения

| # | Ограничение | Детали |
|---|-------------|--------|
| 1 | **Не менять логику/загрузку** | Все правки косметические: загрузка, API, `useEffect`/`useState`, обработчики, пропсы — не изменяются |
| 2 | **Не создавать компоненты** | Используются существующие `[Button]`, `[ErrorMessage]`; новый визуал (стрелка) — inline SVG-декор, не отдельный UI-компонент |
| 3 | **R-21 — только структура** | Перенос не меняет ни одного визуального параметра `[ChatCard]`/`[ChatList]` |
| 4 | **R-24 — не трогать проп isLastMessage** | Проп остаётся (scroll-якорь), но перестаёт влиять на стили пузырька |
| 5 | **Токены — единственный источник** | Все цвета через `var(--theme-*)` (`color.text.secondary` и т.д.); запрещён хардкод в затрагиваемых блоках |
| 6 | **Тема-агностичность** | Каждое изменение проверяется во всех 3 темах; не вводить `dark:`-префиксы |
