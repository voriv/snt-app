**Архитектура centring-контейнера:**

Двухуровневая структура wrapper-элементов:

| Уровень | Классы | Назначение |
|---|---|---|
| **Внешний** | `flex-1 min-h-0 w-full flex justify-center` | Обеспечивает centring дочернего элемента по горизонтали через `flex justify-center`; занимает всё доступное пространство (`flex-1 min-h-0`); необходим для работы `justify-center` |
| **Внутренний** | `w-full lg:max-w-4xl mx-auto flex flex-col h-full` | Ограничивает ширину до `max-w-4xl` (896px) при `≥1024px`; полная ширина (`w-full`) при `<1024px`; `mx-auto` — дополнительное центрирование; `flex flex-col h-full` — корректный flex-layout для children |

**Tailwind-классы:**

| Элемент | Классы | Назначение |
|---|---|---|
| Корневой div | `flex flex-col h-full w-full` | Основной layout + явная `w-full` |
| Внешний centring div | `flex-1 min-h-0 w-full flex justify-center` | Flex-центровка по горизонтали |
| Внутренний max-width div | `w-full lg:max-w-4xl mx-auto flex flex-col h-full` | Ограничение ширины + flex-column layout |

**Responsive поведение:**

| Ширина экрана | Поведение | AC |
|---|---|---|
| `<1024px` (mobile/tablet) | `w-full` — зона сообщений на всю ширину; `lg:max-w-4xl` не применяется | AC-4 |
| `≥1024px` (desktop) | `lg:max-w-4xl` — зона сообщений ограничена до 896px и центрирована | AC-1, AC-3 |
| `≥1920px` (wide monitor) | То же `max-w-4xl`; больше фона страницы по бокам | AC-3 |

**Почему `max-w-4xl` (896px):**

- `max-w-4xl` (896px = 56rem) обеспечивает комфортную ширину чтения на десктопе
- `max-w-3xl` (768px) может быть слишком узким для широких мониторов
- Выбрано пользователем как близкое к ~1024px значение из стандартной сетки Tailwind
- Breakpoint `lg` (1024px) соответствует FR-12: `<1024px` — без ограничения
