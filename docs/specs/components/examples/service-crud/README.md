# Пример: CRUD Service

Пример демонстрирует стандартный паттерн CRUD-сервиса в архитектуре проекта `snt-app`.

## Архитектурные слои

```
┌─────────────────────────┐
│   plot.service.ts       │  ← Сервис: бизнес-логика, валидация, транзакции
├─────────────────────────┤
│  plot.input.schemas.ts  │  ← Zod-схемы валидации входных данных
├─────────────────────────┤
│     plot.types.ts       │  ← TypeScript типы (DTO, input/output) + mapToDTO
└─────────────────────────┘
         │
         ▼ импортирует интерфейс
┌─────────────────────────┐
│  repository/            │  ← Отдельный пример: Repository паттерн
│  plot.repository.       │     (интерфейс + реализация + ошибки)
│  interface.ts           │
└─────────────────────────┘
```

## Ключевые паттерны

| Паттерн | Реализация |
|---------|-----------|
| **DI через конструктор** | Сервис получает репозиторий через конструктор (`constructor(private repository: PlotRepository)`) |
| **Валидация** | Zod-схемы валидируют входные данные перед вызовом бизнес-логики |
| **Классы ошибок** | Domain-specific ошибки (`NotFoundError`, `ConflictError`, `ValidationError`) |
| **DTO маппинг** | `mapToDTO()` преобразует Prisma-модель в безопасный DTO |
| **JSDoc** | Все публичные методы документированы |
