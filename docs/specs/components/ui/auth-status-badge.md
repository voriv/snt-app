# UI Component: AuthStatusBadge

## Статус: На обсуждении

---

## 1. Описание

Индикатор статуса авторизации. Показывает имя/роль авторизованного пользователя или кнопку "Войти" для гостей. Предоставляет кнопку "Выйти" для авторизованных.

## 2. Публичный API

### Props

Нет (компонент использует `useSession` из next-auth внутри).

### Условный рендеринг

| Условие | Отображаемое |
|----------|--------------|
| Загрузка сессии | Spinner |
| Не авторизован | Кнопка "Войти" (ссылка на /auth/login) |
| Авторизован (MEMBER) | Аватар + имя, ссылка на /profile, кнопка "Выйти" |
| Авторизован (ADMIN) | Аватар + имя + бейдж "Админ", ссылка на /profile, кнопка "Выйти" |

## 3. Примеры использования

```tsx
// В Header или HomePage
<AuthStatusBadge />
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `Avatar` | UI Client | Аватар пользователя |
| `Badge` | UI Client | Бейдж роли |
| `Button` | UI Client | Кнопки "Войти", "Выйти" |
| `Spinner` | UI Client | Индикатор загрузки |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `next-auth` | ^5.x | `useSession()`, `signOut()` |

## 5. Стилизация

- Горизонтальный layout: аватар → имя → кнопки
- Компактный вид для header
- Dropdown с действиями на мобильных

## 6. Доступность (a11y)

- `aria-label` для кнопки "Войти" / "Выйти"
- `aria-label="Статус авторизации"` для контейнера
- Клавиатурная навигация

## 7. Адаптивность

- Mobile: компактный вид с dropdown
- Desktop: полный вид с аватаром и кнопками
