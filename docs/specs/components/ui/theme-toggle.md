# UI Component: ThemeToggle

## Статус: На обсуждении

---

## 1. Описание

Компонент переключения темы оформления. Поддерживает 3 темы: Светлая, Тёмная, Садовая.

## 2. Публичный API

### Props

Нет (компонент использует ThemeContext внутри).

### Отображение

| Элемент | Описание |
|---------|----------|
| Кнопка/иконка | Текущая тема с выпадающим меню |
| Светлая | ☀️ Иконка солнца |
| Тёмная | 🌙 Иконка луны |
| Садовая | 🌿 Иконка листа |

### Доступные темы

| Значение | Название | Описание |
|----------|----------|----------|
| `light` | Светлая | Белый фон, тёмный текст |
| `dark` | Тёмная | Тёмный фон, светлый текст |
| `garden` | Садовая | Зелёные оттенки, натуральные тона |

## 3. Примеры использования

```tsx
// Внутри layout или header
<ThemeToggle />
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `ThemeContext` | Context | Контекст текущей темы |
| `Dropdown` | UI Client | Выпадающее меню выбора |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `lucide-react` | ^0.x | Иконки Sun, Moon, Leaf |

## 5. Стилизация

- Кнопка-иконка текущей темы
- Выпадающее меню с 3 вариантами
- Активная тема отмечена галочкой или подчёркиванием

## 6. Доступность (a11y)

- `aria-label="Переключить тему"`
- `aria-expanded` для выпадающего меню
- Keyboard: Enter/Space для выбора, Esc для закрытия
- `role="menu"` для выпадающего списка

## 7. Адаптивность

- Одинаковое отображение на всех размерах экрана
