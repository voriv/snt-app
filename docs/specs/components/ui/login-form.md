# UI Component: LoginForm

## Статус: На обсуждении

---

## 1. Описание

Форма входа по email/password. Используется на странице авторизации. Поддерживает валидацию, отображение ошибок и ссылку на сброс пароля.

## 2. Публичный API

### Props

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|----------|-----|--------------|--------------|----------|
| onSuccess | `(result: LoginResult) => void` | нет | — | Callback после успешного входа |
| redirectUrl | `string` | нет | `/` | URL для редиректа после входа |

### Events (Callbacks)

| Событие | Параметры | Описание |
|---------|-----------|----------|
| onSuccess | `(result: LoginResult)` | Успешная авторизация |

### Состояния

| Состояние | Отображаемое |
|-----------|--------------|
| idle | Форма с пустыми полями |
| loading | Spinner + disabled кнопка |
| error | Красный Alert с текстом ошибки |
| success | Редирект на redirectUrl |

## 3. Примеры использования

```tsx
<LoginForm
  onSuccess={(result) => router.push(redirectUrl)}
  redirectUrl="/profile"
/>
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `Button` | UI Client | Кнопка "Войти" |
| `Input` | UI Client | Поля email и password |
| `Alert` | UI Client | Отображение ошибок |
| `Spinner` | UI Client | Индикатор загрузки |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `next-auth` | ^5.x | `signIn()` |
| `react-hook-form` | ^7.x | Управление формой |
| `zod` | ^3.x | Валидация |
| `@hookform/resolvers` | ^3.x | Zod resolver для RHF |

## 5. Стилизация

- Центрированная форма, max-w-md
- Поля с label и placeholder
- Кнопка "Войти" на всю ширину
- Ссылка "Забыли пароль?" под кнопкой

## 6. Доступность (a11y)

- `aria-label="Форма входа"` для формы
- `aria-describedby` для ошибок валидации
- `aria-invalid` для невалидных полей
- Enter для отправки формы

## 7. Адаптивность

- Mobile: полная ширина с отступами
- Desktop: max-w-md по центру
