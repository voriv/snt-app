# UI Component: HomePage

## Статус: На обсуждении

---

## 1. Описание

Стартовая страница приложения. Содержит общую информацию о садовом товариществе, статус авторизации пользователя, навигацию по модулям и фон с садовой тематикой.

## 2. Публичный API

### Props

Нет (страница верхнего уровня, Server Component).

### Данные

Компонент получает данные через `getServerSession()`:

| Данные | Тип | Описание |
|--------|-----|----------|
| session | Session \| null | Сессия текущего пользователя |

### Условный рендеринг

| Условие | Отображаемое |
|----------|--------------|
| Пользователь не авторизован | Кнопка "Войти", приветственный текст |
| Пользователь авторизован | Имя пользователя, роль, кнопка "Выйти", ссылка на профиль |
| Пользователь авторизован | ThemeToggle для смены темы |

## 3. Примеры использования

```tsx
// src/app/page.tsx — Server Component
import { getServerSession } from 'next-auth'
import { authOptions } from '@/lib/auth'
import { ThemeToggle } from '@/components/ui/theme-toggle'
import { AuthStatusBadge } from '@/components/ui/auth-status-badge'

export default async function HomePage() {
  const session = await getServerSession(authOptions)
  // ...
}
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `ThemeToggle` | UI Client | Переключение темы |
| `AuthStatusBadge` | UI Client | Индикатор статуса авторизации |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `next-auth` | ^5.x | `getServerSession` |

## 5. Стилизация

- Tailwind CSS, mobile-first
- Фоновое изображение/градиент с садовой тематикой
- Карточки модулей с hover-эффектом

## 6. Доступность (a11y)

- Семантические элементы: `<main>`, `<section>`, `<nav>`
- `aria-label` для навигации
- Контрастность текста на фоновом изображении

## 7. Адаптивность

- Mobile: одна колонка карточек
- Tablet (md): две колонки
- Desktop (lg): три колонки
