# UI Component: ProfilePage

## Статус: На обсуждении

---

## 1. Описание

Страница профиля пользователя. Отображает данные профиля и позволяет их редактировать. Доступна только авторизованным пользователям.

## 2. Публичный API

### Props

Нет (страница, Server Component).

### Данные

Получает данные профиля через API-вызов `GET /api/profile/[id]` на клиенте.

### Условный рендеринг

| Условие | Отображаемое |
|----------|--------------|
| Пользователь не авторизован | Редирект на /auth/login?redirect=/profile |
| Пользователь авторизован | ProfileForm + ThemeToggle |
| Загрузка данных | Spinner |
| Ошибка загрузки | Alert с ошибкой |

## 3. Примеры использования

```tsx
// URL: /profile
// Server Component проверяет сессию
// Если нет сессии → redirect на /auth/login?redirect=/profile
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `ProfileForm` | Form Client | Форма редактирования профиля |
| `ThemeToggle` | UI Client | Переключение темы |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `next-auth` | ^5.x | `getServerSession` |

## 5. Стилизация

- Двухколоночный макет: аватар слева, форма справа
- Mobile: одноколоночный (аватар сверху)
- Card-контейнер для формы

## 6. Доступность (a11y)

- `<main>`, `<section>` семантика
- `aria-label` для секций профиля
- Фокус на первом поле формы при редактировании

## 7. Адаптивность

- Mobile: одна колонка, аватар сверху
- Desktop (lg): две колонки
