# UI Component: LoginPage

## Статус: На обсуждении

---

## 1. Описание

Страница авторизации. Содержит форму входа по email/password, ссылку на сброс пароля. Поддерживает редирект обратно на предыдущую страницу после успешной авторизации.

## 2. Публичный API

### Props

Нет (страница, Server Component).

### URL Parameters

| Параметр | Тип | Описание |
|----------|-----|----------|
| redirect | string | URL для редиректа после успешной авторизации |

### Логика редиректа

1. Проверить query-параметр `redirect` в URL
2. Если `redirect` есть — сохранить в `sessionStorage` для использования после входа
3. После успешной авторизации — редирект на URL из `sessionStorage` или на главную

## 3. Примеры использования

```tsx
// URL: /auth/login?redirect=/profile
// После успешной авторизации → редирект на /profile

// URL: /auth/login
// После успешной авторизации → редирект на /
```

## 5. Стилизация

- Центрированная форма на странице
- Фоновый градиент с садовой тематикой
- Адаптивная ширина формы (max-w-md)

## 6. Доступность (a11y)

- `<main>` для контента
- `aria-label="Форма входа"` для формы
- Focus management: автофокус на поле email

## 7. Адаптивность

- Mobile: форма на всю ширину с отступами
- Desktop: форма по центру с max-w-md
