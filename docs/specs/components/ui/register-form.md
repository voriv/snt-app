# UI Component: RegisterForm

## Статус: На обсуждении

---

## 1. Описание

### 1.1 Назначение

Форма регистрации нового пользователя. Содержит поля email и пароль, валидацию на клиенте, отправку данных на `/api/auth/register` и отображение статусов (загрузка, ошибка, успех).

### 1.2 Границы ответственности

| Входит | НЕ входит |
|--------|-----------|
| Отображение формы регистрации | Серверная логика регистрации |
| Клиентская валидация (Zod) | Создание сессии |
| Отображение ошибок API | Роутинг/редирект |
| Состояния загрузки | Управление темами |

---

## 2. Публичный API

### Props

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|----------|-----|--------------|--------------|----------|
| onSuccess | `() => void` | нет | — | Callback после успешной регистрации |
| redirectTo | `string` | нет | `/` | URL для редиректа после регистрации |

### Состояния

| Состояние | Отображаемое | Поведение |
|-----------|--------------|-----------|
| idle | Форма с пустыми полями | Ожидание ввода |
| loading | Spinner + disabled кнопка | Отправка запроса |
| error | Красный Alert с текстом ошибки | Ошибка API или валидации |
| success | Редирект на redirectTo | После успешной регистрации |

### Events (Callbacks)

| Событие | Параметры | Описание |
|---------|-----------|----------|
| onSuccess | `()` | После успешной регистрации |

## 5. Клиентская валидация (Zod)

```typescript
const registerSchema = z.object({
  email: z.string().min(1, 'Email обязателен').email('Неверный формат email'),
  password: z.string().min(6, 'Пароль должен содержать минимум 6 символов'),
});
```

### Правила валидации

| Поле | Правило | Ошибка |
|------|---------|--------|
| email | Обязательное | "Email обязателен" |
| email | Валидный email формат | "Неверный формат email" |
| password | Обязательное | "Пароль обязателен" |
| password | Мин. 6 символов | "Пароль должен содержать минимум 6 символов" |

## 6. API вызов

```typescript
async function register(email: string, password: string): Promise<{
  user: { id: string; email: string; role: string };
}> {
  const response = await fetch('/api/auth/register', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password }),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.error.message);
  }

  return response.json();
}
```

## 7. Стилизация

- Центрированная форма, max-w-md
- Поля с label и placeholder
- Кнопка "Зарегистрироваться" на всю ширину
- Ссылка "Уже есть аккаунт? Войти" → `/login`
- Ошибки отображаются в красном Alert над формой

## 8. Доступность (a11y)

- `aria-label="Форма регистрации"` для формы
- `aria-describedby` для ошибок валидации
- `aria-invalid` для невалидных полей
- `role="alert"` для сообщений об ошибках
- Enter для отправки формы
- Label для каждого поля input
