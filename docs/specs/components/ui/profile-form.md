# UI Component: ProfileForm

## Статус: На обсуждении

---

## 1. Описание

Форма редактирования профиля пользователя. Позволяет изменить имя, телефон, URL аватара и данные участника (Member).

## 2. Публичный API

### Props

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|----------|-----|--------------|--------------|----------|
| profile | `ProfileDetail` | да | — | Текущие данные профиля |
| onSubmit | `(data: UpdateProfileInput) => Promise<void>` | да | — | Обработчик сохранения |

### Events (Callbacks)

| Событие | Параметры | Описание |
|---------|-----------|----------|
| onSubmit | `(data: UpdateProfileInput)` | Сохранение изменений |

### Состояния

| Состояние | Отображаемое |
|-----------|--------------|
| view | Данные профиля в режиме просмотра, кнопка "Редактировать" |
| editing | Форма с полями для редактирования |
| loading | Spinner + disabled поля |
| error | Alert с текстом ошибки |
| success | Toast "Профиль обновлён" |

## 3. Примеры использования

```tsx
<ProfileForm
  profile={profileData}
  onSubmit={async (data) => {
    await fetch(`/api/profile/${profileData.id}`, {
      method: 'PATCH',
      body: JSON.stringify(data),
    })
  }}
/>
```

## 4. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `Button` | UI Client | Кнопки "Сохранить", "Отмена", "Редактировать" |
| `Input` | UI Client | Текстовые поля |
| `Avatar` | UI Client | Отображение аватара |
| `Alert` | UI Client | Отображение ошибок |
| `Toast` | UI Client | Уведомление об успехе |
| `Spinner` | UI Client | Индикатор загрузки |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `react-hook-form` | ^7.x | Управление формой |
| `zod` | ^3.x | Валидация |
| `@hookform/resolvers` | ^3.x | Zod resolver для RHF |

## 5. Стилизация

- Card-контейнер
- Поля в две колонки на desktop
- Avatar крупно слева (desktop) или сверху (mobile)
- Кнопки действий внизу формы

## 6. Доступность (a11y)

- `aria-label="Форма редактирования профиля"` для формы
- `aria-describedby` для ошибок валидации
- `aria-invalid` для невалидных полей
- Tab-навигация по полям формы

## 7. Адаптивность

- Mobile: одна колонка полей, avatar сверху
- Desktop (lg): две колонки полей, avatar слева
