# UI Component: RegisterPage

## Статус: На обсуждении

---

## 1. Описание

### 1.1 Назначение

Страница регистрации нового пользователя. Отображает `RegisterForm` и обеспечивает редирект авторизованного пользователя.

### 1.2 Границы ответственности

| Входит | НЕ входит |
|--------|-----------|
| Отображение формы регистрации | Серверная логика регистрации |
| Проверка авторизации | Управление сессией |
| Редирект авторизованных | Настройка middleware |

---

## 2. Публичный API

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Авторизованный пользователь | Редирект на `/` |
| Неавторизованный пользователь | Отображение `RegisterForm` |

---

## 3. Примеры использования

```tsx
export default function RegisterPage() {
  return (
    <div className="flex min-h-screen items-center justify-center">
      <RegisterForm onSuccess={() => router.push('/')} redirectTo="/" />
    </div>
  );
}
```

---

## 4. Маршрут

| Параметр | Значение |
|----------|----------|
| Path | `/register` |
| Method | GET (отображение страницы) |
| Public | Да (в middleware) |

---

## 5. Зависимости

### Внутренние (проект)

| Компонент | Тип | Описание |
|-----------|-----|----------|
| `RegisterForm` | UI Client | Форма регистрации |
| `SessionWrapper` | Provider | Сессия NextAuth |

### Внешние (пакеты)

| Пакет | Версия | Что используется |
|-------|--------|-------------------|
| `next` | ^14.x | Роутинг, router |
| `next-auth` | ^5.x | `useSession()` |

---

## 6. Middleware конфигурация

Добавить `/register` в публичные маршруты `src/middleware.ts`:

```typescript
const publicRoutes = [
  '/login',
  '/register',
  '/api/auth/',
  '/api/public/',
];
```
