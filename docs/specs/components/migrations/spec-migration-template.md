## 4. Обработка ошибок

### 4.1 Потенциальные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Deadlock | Конкуренция транзакций | Повторить транзакцию с backoff |
| Constraint violation | Нарушение ограничений | Проверить данные перед миграцией |
| Out of memory | Большие объёмы данных | Обрабатывать батчами |

### 4.2 Стратегия отката

| Сценарий | Действие |
|----------|----------|
| Ошибка миграции | Откатить транзакцию |
| Частичное выполнение | Ручной rollback |
| Данные повреждены | Восстановление из бэкапа |

## 6. Развёртывание

### 6.1 Требования перед развёртыванием

- [ ] Миграция протестирована на staging
- [ ] Данные перенесены на staging
- [ ] Обратно совместимость обеспечена
- [ ] Резервная копия базы данных создана
- [ ] Команда уведомлена о развёртывании

### 6.2 Порядок развёртывания

| Шаг | Действие | Описание |
|-----|----------|----------|
| 1 | Создать бэкап | `pg_dump` основной базы данных |
| 2 | Применить миграцию | `pnpm db:migrate` |
| 3 | Проверить схему | `pnpm db:studio` |
| 4 | Проверить миграцию данных | Скрипт проверки |
| 5 | Развернуть приложение | Обновить сервисы |
| 6 | Проверить работу | Smoke тесты |

### 6.3 Rollback план

```bash
# Откат миграции
pnpm db:migrate:revert {{migration-name}}

# Восстановление из бэкапа
pg_restore --dbname={{database}} {{backup-file}}
```
