# User

## Описание

Пользователь системы — основной субъект аутентификации. Пользователи могут быть членами СНТ (иметь связанные записи в таблице `members`) или гостями (без членства). Полномочия пользователя определяются набором назначенных ему ролей (отношение M:N через таблицу `user_roles`).

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| `id` | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| `email` | String | Да | Email для входа | Уникальный в системе, приводится к lowerCase |
| `name` | String? | Нет | Отображаемое имя пользователя | Может быть null |
| `password` | String | Да | Хеш пароля (bcrypt) | Хранится только хеш, никогда не возвращается |
| `avatar` | String? | Нет | URL аватара | Опциональное |
| `created_at` | DateTime | Да | Дата создания учётной записи | Генерируется автоматически |
| `updated_at` | DateTime | Да | Дата последнего обновления | Обновляется при каждой записи |

> Поле `role` (enum Role) **удалено**. Роли пользователя определяются через таблицу `user_roles` (M:N). Один пользователь может иметь несколько ролей.

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| Member | has_one | Пользователь может иметь одну запись в Members (член СНТ) |
| UserProfile | has_one | Профиль пользователя содержит расширенные данные |
| Role | has_many через `user_roles` | Пользователю назначаются роли (M:N) |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| `email` | unique | Уникальный email |

## Бизнес-инварианты

- Email уникален в системе
- При регистрации новая учётная запись создаётся без ролей (роли назначаются отдельно)
- Пароль никогда не передаётся в откликах API
- Роли пользователя хранятся в `user_roles`, не в поле `users`
- При удалении пользователя удаляются все его назначения ролей (CASCADE)

## Конвенции именования

- **БД (PostgreSQL):** `users`, `id`, `email`, `name`, `password`, `avatar`, `created_at`, `updated_at`
- **Prisma:** `User`, `id`, `email`, `name`, `password`, `avatar`, `createdAt`, `updatedAt`
- **TypeScript домен:** `UserData`, `id: string`, `email: string`, `name: string \| null`, `avatar: string \| null`, `createdAt: Date`, `updatedAt: Date`
