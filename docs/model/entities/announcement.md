# Announcement

## Описание
Объявление в СНТ — официальный способ информирования членов сообщества о важных событиях, изменениях и новостях. Объявления создаются администраторами, публикуются для всех пользователей и могут архивироваться.

## Поля
| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| id | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| title | String | Да | Заголовок объявления | Максимум 200 символов |
| content | String | Да | Полное содержание объявления | Текст без ограничений |
| author_id | String | Да | ID автора (Foreign Key) | Ссылка на users.id |
| published_at | DateTime? | Нет | Дата публикации | NULL = черновик |
| archived_at | DateTime? | Нет | Дата архивации | NULL = не архивирован |
| status | AnnouncementStatus | Да | Статус объявления | DRAFT, PUBLISHED, ARCHIVED |
| is_important | Boolean | Да | Важное ли объявление | По умолчанию false |
| view_count | Int | Да | Количество просмотров | По умолчанию 0 |
| created_at | DateTime | Да | Дата создания | Генерируется автоматически |
| updated_at | DateTime | Да | Дата последнего обновления | Обновляется автоматически |

## Связи
| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| User | belongs_to | Объявление создается пользователем (автором) |

## Индексы
| Поля | Тип | Описание |
|------|-----|----------|
| (status, published_at) | composite | Для быстрой фильтрации по статусу и сортировки по дате |
| author_id | index | Для поиска объявлений по автору |

## Бизнес-инварианты
- Объявление может быть в одном из трех статусов: DRAFT, PUBLISHED, ARCHIVED
- Черновик (DRAFT) не отображается в публичном списке
- При публикации `published_at` устанавливается в текущее время
- При архивации `archived_at` устанавливается в текущее время
- Счётчик просмотров увеличивается при каждом просмотре деталей объявления
- Важные объявления выделяются визуально бейджем "Важно"

## Конвенции именования
- **БД (PostgreSQL):** `snake_case` (например, `author_id`, `published_at`, `view_count`)
- **Prisma:** `camelCase` с `@map()` (например, `authorId @map("author_id")`)
- **TypeScript домен:** `camelCase` (например, `authorId`, `publishedAt`, `viewCount`)
