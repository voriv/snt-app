# DocumentTag

## Описание

Тег документа — метка для классификации и поиска документов. Теги создаются автоматически при назначении метаданных документу (US-22-04): если тег с указанным именем не существует, он создаётся автоматически. Один тег может быть привязан к нескольким документам (M:N через junction table).

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| id | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| name | String | Да | Название тега | До 50 символов, уникально в системе |
| created_at | DateTime | Да | Дата создания | Генерируется автоматически |

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| Document | has_many через document_tags | Один тег может быть привязан к нескольким документам (M:N) |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| name | unique | Уникальное название тега в системе |

## Бизнес-инварианты

- name уникально в системе: нельзя создать два тега с одинаковым именем
- Теги создаются автоматически при назначении метаданных документу (upsert)
- Удаление тега из документа не удаляет сам тег из БД (если он используется другими документами)
- Тег не удаляется, если он привязан хотя бы к одному документу (защита на уровне сервиса)
- Поиск по тегам выполняется через junction table (BR-11)

## Конвенции именования

- **БД (PostgreSQL):** document_tags, id, name, created_at
- **Prisma:** DocumentTag, id, name, createdAt
- **TypeScript домен:** DocumentTagData, id: string, name: string, createdAt: Date
