# DocumentCategory

## Описание

Категория документов — единица иерархической структуры для организации документов в системе. Поддерживается вложенность категорий (подкатегории) через self-referencing связь parentId. Категории создаются администратором для классификации документов (договоры, протоколы, справки и т.д.).

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| id | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| name | String | Да | Название категории | До 100 символов, уникально в рамках одного родителя |
| description | String? | Нет | Описание категории | Опционально, до 500 символов |
| parent_id | String? | Нет | Ссылка на родительскую категорию | Self-reference -> DocumentCategory.id. Null = корневая категория |
| created_at | DateTime | Да | Дата создания | Генерируется автоматически |
| updated_at | DateTime | Да | Дата последнего обновления | Обновляется при каждой записи |

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| DocumentCategory (parent) | has_many через parent_id | Одна категория может содержать несколько подкатегорий (дерево) |
| DocumentCategory (children) | belongs_to через parent_id | Подкатегория относится к одной родительской категории |
| Document | has_many | В категории может храниться несколько документов (1:M) |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| (name, parent_id) | unique | Уникальное название категории в рамках одного уровня (родителя) |
| parent_id | index | Ускорение запросов на получение подкатегорий |

## Бизнес-инварианты

- name уникально в рамках одного родителя: две категории с одинаковым именем не могут иметь одного родителя (включая parent_id = null как отдельный уровень)
- Категории образуют древовидную структуру без циклов (runtime-валидация на уровне сервиса)
- При удалении категории документы переносятся в родительскую категорию (или categoryId = null для корневых), а подкатегории привязываются к родителю удаляемой категории (US-22-02)
- Глубина вложенности не ограничена на уровне БД

## Конвенции именования

- **БД (PostgreSQL):** document_categories, id, name, description, parent_id, created_at, updated_at
- **Prisma:** DocumentCategory, id, name, description, parentId, createdAt, updatedAt
- **TypeScript домен:** DocumentCategoryData, id: string, name: string, description: string | null, parentId: string | null, createdAt: Date, updatedAt: Date
