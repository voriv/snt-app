# Payment

## Описание

Платёж — финансовая операция члена СНТ, связанная с уплатой взносов, платежей за услуги или других обязательных платежей.

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| `id` | String | Да | Уникальный идентификатор платежа | Генерируется автоматически (cuid) |
| `amount` | Decimal | Да | Сумма платежа | Точность: 10,2 (рубли) |
| `date` | DateTime | Да | Дата платежа | По умолчанию: текущая дата |
| `description` | String? | Нет | Описание платежа | Опциональное поле |
| `status` | PaymentStatus | Да | Статус платежа | PENDING (по умолчанию), PAID, OVERDUE, PARTIAL |
| `member_id` | String | Да | Ссылка на члена СНТ | Внешний ключ |
| `plot_id` | String? | Нет | Ссылка на участок | Опциональный внешний ключ |
| `created_at` | DateTime | Да | Дата создания записи | Генерируется автоматически |
| `updated_at` | DateTime | Да | Дата последнего обновления | Обновляется при каждой записи |

## Типы статусов

| Значение | Описание |
|----------|----------|
| `PENDING` | Ожидающий оплаты |
| `PAID` | Оплачен |
| `OVERDUE` | Просрочен |
| `PARTIAL` | Частично оплачен |

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| Member | belongs_to | Платёж привязан к члену СНТ |
| Plot | belongs_to | Платёж может быть привязан к участку |
| Agreement | has_many | К платежу может быть привязан договор |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| `member_id` | index | Индекс для поиска по члену СНТ |
| `plot_id` | index | Индекс для поиска по участку |
| `status` | index | Индекс для поиска по статусу |
| `date` | index | Индекс для поиска по дате |

## Бизнес-инварианты

- Сумма платежа должна быть положительным числом
- Статус PENDING автоматически переходит в OVERDUE при просрочке
- Частичная оплата требует обновления статуса на PARTIAL
- Платёж может быть привязан к члену СНТ или к участку

## Конвенции именования

- **БД (PostgreSQL):** `payments`, `id`, `amount`, `date`, `description`, `status`, `member_id`, `plot_id`, `created_at`, `updated_at`
- **Prisma:** `Payment`, `id`, `amount`, `date`, `description`, `status`, `memberId`, `plotId`, `createdAt`, `updatedAt`
- **TypeScript домен:** `Payment`, `id: string`, `amount: number`, `date: Date`, `description: string \| null`, `status: 'PENDING' \| 'PAID' \| 'OVERDUE' \| 'PARTIAL'`, `memberId: string`, `plotId: string \| null`, `createdAt: Date`, `updatedAt: Date`
