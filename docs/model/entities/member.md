# Member

## Описание

Член СНТ — физическое лицо, состоящее в садовом некоммерческом товариществе. Связан с пользователем системы через одну учётную запись.

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| `id` | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| `user_id` | String | Да | Ссылка на пользователя | Уникальный внешний ключ |
| `first_name` | String | Да | Имя члена СНТ | Обязательное поле, не пустое |
| `last_name` | String | Да | Фамилия члена СНТ | Обязательное поле, не пустое |
| `birth_date` | DateTime? | Нет | Дата рождения | Опциональное поле |
| `phone` | String? | Нет | Телефонный номер | Опциональное поле |
| `email` | String? | Нет | Email для связи | Опциональное поле |
| `is_active` | Boolean | Да | Статус членства | По умолчанию: true |
| `note` | String? | Нет | Примечание | Опциональное поле |
| `created_at` | DateTime | Да | Дата создания записи | Генерируется автоматически |
| `updated_at` | DateTime | Да | Дата последнего обновления | Обновляется при каждой записи |

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| User | belongs_to | Член СНТ связан с пользователем |
| Plot | has_one | Член СНТ может иметь один участок |
| Agreement | has_many | Член СНТ может иметь несколько договоров |
| Payment | has_many | Член СНТ может иметь несколько платежей |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| `user_id` | unique | Уникальный пользователь |
| `email` | index | Индекс для поиска по email |

## Бизнес-инварианты

- Каждый член СНТ обязан иметь связанную учётную запись
- Запись о членстве может быть активна или неактивна
- Email и телефон могут быть null, но должны быть уникальны, если указаны

## Конвенции именования

- **БД (PostgreSQL):** `members`, `id`, `user_id`, `first_name`, `last_name`, `birth_date`, `phone`, `email`, `is_active`, `note`, `created_at`, `updated_at`
- **Prisma:** `Member`, `id`, `userId`, `firstName`, `lastName`, `birthDate`, `phone`, `email`, `isActive`, `note`, `createdAt`, `updatedAt`
- **TypeScript домен:** `Member`, `id: string`, `userId: string`, `firstName: string`, `lastName: string`, `birthDate: Date \| null`, `phone: string \| null`, `email: string \| null`, `isActive: boolean`, `note: string \| null`, `createdAt: Date`, `updatedAt: Date`
