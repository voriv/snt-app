# Message

## Описание

Сообщение в диалоге (конверсациии). Каждое сообщение принадлежит конкретному диалогу и отправляется конкретным пользователем. Поддерживает цитирование (ответ на другое сообщение) и мягкое удаление (soft-delete).

## Поля

| Поле | Тип | Обязательное | Описание | Бизнес-правила |
|------|-----|-------------|----------|----------------|
| `id` | String | Да | Уникальный идентификатор | Генерируется автоматически (cuid) |
| `conversation_id` | String | Да | ID диалога | Внешний ключ на conversations.id |
| `sender_id` | String | Да | ID отправителя | Внешний ключ на users.id |
| `content` | String | Да | Текст сообщения | Обязательно, не пустое |
| `reply_to_id` | String? | Нет | ID цитируемого сообщения | Ссылка на другое сообщение в том же диалоге |
| `is_deleted` | Boolean | Да | Флаг мягкого удаления | По умолчанию: false |
| `deleted_by` | String? | Нет | ID пользователя, удалившего сообщение | Заполняется при мягком удалении |
| `deleted_at` | DateTime? | Нет | Время мягкого удаления | Заполняется при мягком удалении |
| `created_at` | DateTime | Да | Дата отправки | Генерируется автоматически |
| `updated_at` | DateTime | Да | Дата последнего редактирования | Обновляется при редактировании |

## Связи

| Сущность | Тип связи | Описание |
|----------|-----------|----------|
| Conversation | belongs_to | Диалог, в котором отправлено сообщение |
| User (sender) | belongs_to | Отправитель сообщения |
| User (deleted_by) | belongs_to (опционально) | Пользователь, удаливший сообщение |
| Message (reply_to) | belongs_to (опционально) | Цитируемое сообщение |

## Индексы

| Поля | Тип | Описание |
|------|-----|----------|
| `(conversation_id, created_at)` | index | Для эффективной загрузки сообщений диалога |

## Бизнес-инварианты

- Сообщение не может быть отправлено без текста
- Цитируемое сообщение должно принадлежать тому же диалогу
- Мягко удалённые сообщения не отображаются в потоке (is_deleted = true)
- При удалении диалога все сообщения удаляются автоматически (CASCADE)
- Отправитель сообщения может отредактировать его после отправки
- Администратор диалога может мягко удалить чужое сообщение
- **Отображение отправителя в личных сообщениях:**
  - Для текущего пользователя: всегда отображается «ВЫ»
  - Для собеседника: отображается «Имя Фамилия» из `UserProfile`
  - Если имя и фамилия отсутствуют: отображается `User.email`
  - Если отправитель удалён (`senderId` не ссылается на существующего пользователя): отображается «Удалённый пользователь»
- **Отображение имени и фамилии в карточке сообщения:**
  - Над текстом сообщения отображается «Имя Фамилия» отправителя
  - Для текущего пользователя отображается «ВЫ»
