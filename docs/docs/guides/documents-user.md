# Руководство пользователя: Управление документами

> **Модуль:** Документы
> **Дата обновления:** 2026-07-22

---

## Обзор

Модуль «Документы» позволяет загружать, хранить, просматривать и управлять юридическими и информационными документами СНТ: договорами, протоколами собраний, справками и другими важными материалами.

### Кто может что делать

| Действие | Администратор | Член СНТ | Гость |
|----------|---------------|----------|-------|
| Просмотреть список документов | ✅ | ✅ | ✅ |
| Просмотреть документ | ✅ | ✅ | ✅ |
| Скачать документ | ✅ | ✅ | ✅ |
| Загрузить новый документ | ✅ | ❌ | ❌ |
| Редактировать документ | ✅ | ❌ | ❌ |
| Архивировать документ | ✅ | ❌ | ❌ |
| Управлять категориями | ✅ | ❌ | ❌ |

---

## 1. Просмотр списка документов

Для перехода к списку документов откройте раздел **«Документы»** в навигации дашборда (`/dashboard/documents`).

### Что отображается в списке

- **Название** документа — кликабельная ссылка для перехода к деталям
- **Тип** — категория типа: Договор, Протокол, Справка и т.д.
- **Категория** — рубрика, к которой относится документ
- **Дата** — дата публикации
- **Статус** — значок статуса (опубликован, архивирован)

### Фильтрация

Над списком документов находятся фильтры:

| Фильтр | Описание |
|--------|----------|
| **Категория** | Выберите категорию из выпадающего списка. Отображаются документы выбранной категории и всех её подкатегорий |
| **Тип** | Выберите тип документа: Договор, Протокол, Справка и т.д. |

### Поиск

В поле поиска введите текст для поиска документов по:
- Названию
- Описанию
- Тегам

Результаты появляются автоматически по мере ввода (с задержкой 300 мс). Если ничего не найдено, отобразится сообщение «Документы не найдены».

### Пагинация

При большом количестве документов список разбивается на страницы. Используйте навигацию внизу списка для перехода между страницами.

---

## 2. Просмотр деталей документа

Кликните на название документа в списке, чтобы открыть страницу деталей (`/dashboard/documents/:id`).

### Информация о документе

На странице отображается:

| Поле | Описание |
|------|----------|
| **Название** | Полное название документа |
| **Описание** | Краткое описание содержания |
| **Тип** | Тип документа (Договор, Протокол и т.д.) |
| **Категория** | Рубрика документа |
| **Дата создания** | Дата загрузки документа |
| **Автор** | Кто загрузил документ |
| **Теги** | Метки для классификации |
| **Статус** | Текущий статус: опубликован или архивирован |

### Предпросмотр

В зависимости от типа файла, доступна встроенная визуализация:

- **PDF** — встроенный просмотр в окне браузера
- **Изображения** (JPG, PNG, GIF, BMP, WEBP) — отображение изображения на странице
- **DOCX** — предпросмотр недоступен, только скачивание

### Скачивание

Нажмите кнопку **«Скачать»**, чтобы загрузить файл на свой компьютер. Файл сохранится с его оригинальным именем.

### Отсутствие доступа

Если у вас нет прав просмотра конкретного документа (например, документ доступен только администраторам), отобразится сообщение:

> **У вас нет доступа к этому документу**

## 3. Загрузка нового документа (для администраторов)

Администраторы могут загружать новые документы через страницу **«Загрузка документов»** (`/dashboard/documents/upload`).

### Шаг 1: Загрузка файла

1. Перетащите файл в зону загрузки или нажмите **«Выбрать файл»**
2. Выберите файл на вашем компьютере

**Поддерживаемые форматы:**
- PDF (.pdf)
- Word (.docx)
- Изображения: JPG, PNG, GIF, BMP, WEBP

**Максимальный размер файла:** 100 МБ

Если файл не подходит по формату или превышает размер, отобразится сообщение об ошибке.

### Шаг 2: Заполнение информации о документе

После загрузки файла заполните форму метаданных:

| Поле | Обязательное | Описание |
|------|-------------|----------|
| **Название** | ✅ | Полное название документа (например, «Протокол общего собрания от 15.03.2026») |
| **Описание** | ❌ | Краткое описание содержания документа |
| **Категория** | ❌ | Выберите из дерева категорий (или создайте новую) |
| **Тип** | ✅ | Выберите тип: Договор, Протокол, Справка, Решение и т.д. |
| **Кто может видеть** | ✅ | Выберите роли пользователей, которые смогут видеть документ |
| **Теги** | ❌ | Добавьте метки для поиска (максимум 10 тегов) |

### Шаг 3: Публикация

Нажмите **«Опубликовать»**, чтобы сохранить метаданные и сделать документ доступным для выбранных ролей. После этого документ получает статус **«Опубликован»**.

## 4. Категории документов (для администраторов)

Категории позволяют организовать документы в иерархическую структуру. Например:

```
📁 Договоры
  📁 Договоры аренды
  📁 Договоры обслуживания
📁 Протоколы
📁 Справки
📁 Решения правления
```

### Создание категории

1. Откройте страницу **«Категории»** (`/dashboard/documents/categories`)
2. Нажмите **«Создать категорию»**
3. Заполните поля:
   - **Название** — уникальное в пределах одного уровня
   - **Описание** — необязательное
   - **Родительская категория** — выберите для создания подкатегории (или оставьте пустым для корневой)
4. Нажмите **«Сохранить»**

### Удаление категории

1. Нажмите **«Удалить»** рядом с категорией
2. Подтвердите удаление в диалоговом окне

**Важно:** При удалении категории:
- Документы переносятся в родительскую категорию (или «Без категории», если это корневая)
- Подкатегории привязываются к родителю удаляемой категории

## 5. Редактирование документа (для администраторов)

Для редактирования документа откройте его детали и нажмите **«Редактировать»** (`/dashboard/documents/:id/edit`).

### Что можно изменить

| Поле | Описание |
|------|----------|
| **Название** | Новое название документа |
| **Описание** | Обновлённое описание |
| **Категория** | Переместить в другую категорию |
| **Тип** | Изменить тип |
| **Кто может видеть** | Изменить роли доступа |
| **Теги** | Добавить или удалить теги |
| **Статус** | Архивировать документ |

### Архивация

Для архивации измените статус на **«Архивирован»**. Архивированный документ:
- Доступен для просмотра и скачивания
- **Недоступен для дальнейшего редактирования**

---

## 6. Статусы документов

| Статус | Описание | Видят |
|--------|----------|-------|
| 📝 **Черновик** | Файл загружен, но информация ещё не заполнена | Только администраторы |
| 📄 **Опубликован** | Документ готов и доступен пользователям | Пользователи с доступом по роли |
| 📦 **Архивирован** | Документ сохранён, но больше не редактируется | Пользователи с доступом по роли |

---

## 7. Роли и доступ

Администратор при загрузке документа выбирает, какие роли пользователей смогут его видеть:

| Роль | Описание |
|------|----------|
| **ADMIN** | Администраторы — видят все документы |
| **MEMBER** | Члены СНТ — видят документы, доступные для членов |
| **GUEST** | Гости — видят открытые документы |
| **ACCOUNTANT** | Бухгалтерия — видят финансовые документы |

Можно выбрать несколько ролей одновременно. Например, «Протокол общего собрания» может быть доступен и членам СНТ, и гостям.

## 8. Часто задаваемые вопросы

### Почему я не вижу какой-то документ?

Документ может быть скрыт по одной из причин:
1. Он находится в статусе **«Черновик»** (видят только администраторы)
2. Ваша роль не включена в список «Кто может видеть»
3. Документ был удалён или архивирован администратором

### Можно ли загрузить Excel-файл?

Нет, в настоящее время поддерживаются только PDF, DOCX и изображения. Для табличных данных используйте DOCX или экспортируйте в PDF.

### Можно ли загрузить файл больше 100 МБ?

Нет, максимальный размер файла — 100 МБ. Для больших файлов рекомендуется сжать или разделить документ.

### Что произойдёт, если я удалю категорию?

Ваши документы не удалятся — они будут перемещены в родительскую категорию или в раздел «Без категории».

### Как найти документ, если я забыл название?

Используйте поиск в верхней части списка документов. Поиск работает по названию, описанию и тегам.
