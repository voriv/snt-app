# Разделение единого Е2Е pipeline на несколько вариантов

## Роль
Ты опытный промпт инженер

## Контекст

Сейчас режим орекстратора roo старается выполнить весь pipeline от начала до конца.
Но некоторые задачи требуют выполнение только части пайпа. Дальнейшее выполнение может быть
1. Выполнено вручную
2. Отложено
3. Выполнено в отдельной сессии

## Задача

Обнови режимы roo, что бы можно было выполнять задачи по частям

## Порядок выполнения

1. Изучи режимы roo vs code
2. Задай 2-5 вопросов для уточнения, если требуется
3. Предложи варианты изменения и рекомендации
4. Обсуди варианты с пользователем
5. Сформируй план изменения режимов
6. Обсуди план с пользователем
7. Обнови план по замечаниям
8. Приступи к исполнению плана
9. После выполнения плана сделай проверку результатов

## Ожидаемый результат

1. Можно ограничивать останвливать паплайн после разработки требований и архитектуры
2. Дальнейшая разработка может быть выпорлнена
   1. Вручную человеком
   2. В отдельной сессии ИИ агентом
3. При старте сессии оркестратор уточняет вариант (полный/Только требования/Требования и архитектуру/Архитектуру по требованиям/реализовать архитектуру)
4. В беклоге фиксируется результат и тип запуска

## Ограничения
1. ЗАПРЕЩЕНО менять исходый код
2. Запрещено менять документы сервисов
