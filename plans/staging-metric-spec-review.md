# Создание и обновление спецуификации шагов pipeline для выгрузки шаблонов метрик

## Роль
Ты опытный Архитектор

## Контекст
Staging-service - ETL сервис для выгрузки архитектурных арефактов

## Задача

1. Создать правила подключения новых источников в staging-service
2. Создать правила описания спецификаций на основе примеров
3. Сформировать спецификации шагов пайплана для выгрузки шаблонов метрик в соответствии с правилами и примерами

5. Обсуди впросы и предложения, каждое по отдельности
6. Не переходи к следующему вопросу без подвтерждения пользователя

11. Проверь результат

## Ожидаемый результат

1. Сформированы правила и приеры добавления новых источников и описания спецификаций
