## Роль 
Ты опытный промпт инженер

## Контекст 
Создание системы режимов, навыков и промптов для автотизированной разработки приложения с участием ИИ агента

Основная идея
1. spec driven подход. Любое изменение начинается с проверки и изменения требований и спецификаций
2. Задача разбивается не мелкие специализированные шаги
3. Эти шаги оркестратор делегирует субагентам (new_task)
4. Для субагентов создаются свои специфлизированные режимы

## Задача
Проанализируй текущие режимы.
Проработать вариант доавления режимы специфкации компонент

Его задачи:
- Анализ требований, user story и плана user story
- создание специфкиации компонент
- Создание или обновление скелетов компонент

## Порядок выполнения

1. Не спеши изменять файлы. 
2. Задай 3-4 вопроса для уточнения задачи
3. Пранализируй основную идею
4. Дай несколько замечаний и улучшений
5. Обсуди все с пользователем
